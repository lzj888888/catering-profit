### 2.1 读：`api.call('getMaterial', {})`
按既有返回结构渲染列表；列表每行显示：名称 / 品牌规格 / 采购单位 / 采购单价 / 净料单位成本。

### 2.2 写：`api.call('saveMaterial', {...})` —— **入参契约已实读，照抄**
```
{
  shop_id: <当前店铺 id>,
  material: {
    id: string,                 // '' = 新增；非空 = 编辑（传原料的业务 id）
    name: string,               // 必填、非空
    brand_spec: string,         // 可空
    purchase_unit: string,      // 默认 '斤'
    purchase_price_fen: number, // 🔴 必须是非负**整数分**，JSON number，**字符串一律报 INVALID_PARAM**
    convert_factor: number,     // >0（换算到克：1 斤 = 500）
    yield_rate: number,         // (0,100] 百分数
    is_virtual: false           // 前端手建的普通原料一律 false
  },
  client_request_id: string     // 幂等键，如 'mat_' + Date.now()
}
```
证据：`cloudfunctions/saveMaterial/validate.js:6-47`、`cloudfunctions/saveMaterial/index.js:23-112`。
🔴 **前端的"元"输入必须自己转成"分"整数**（`Math.round(元 * 100)`）—— 后端不收字符串、不收小数元。

### 2.3 新增三个字段（v1.2 §M3.30）—— **必须同时改三处，缺一即半成品**
| 字段 | 类型 | 默认 | 用途 |
|---|---|---|---|
| `category` | string | `''` | 枚举：`meat`/`veg`/`dry`/`season`/`pack`/`other` |
| `aliases` | string | `'[]'` | JSON 数组字符串，如 `'["鲜味生抽","生抽"]'`，**仅用于检索** |
| `remark` | string | `''` | 备注 |

三处改动：
1. `cloudfunctions/saveMaterial/validate.js` —— 在返回的 `material` 对象里**放行**这三个字段
   （各自带类型兜底：字符串取字符串、否则用默认值）。**不许把它们设成必填**。
2. `cloudfunctions/saveMaterial/index.js` —— 新增分支与编辑分支的写库对象里**加上**这三个字段
   （新增时写入；编辑时一并 update）。
3. `pages/material/edit` —— 表单加上对应的输入控件（分类=下拉 6 项；别名=逗号分隔输入；
   备注=文本域），并做"逗号分隔 → JSON 数组字符串"的转换。

🔴 **硬约束**：
· `category` 是**原料的采购视角分类**，**绝不允许**与 M1 的 `ITEM_TAGS`（利润归属体系）混用或建映射。
· `aliases` **只用于检索建议，绝不自动替换**原料名 —— 自动替换会让成本**静默变错**。
· **不新增集合、不新增索引**（原料量级小，按 `shop_id` 拉回后前端过滤即可）。

### 2.4 其他
· 搜索框：**名称 or 别名**合并检索（前端过滤即可）。
· 分类筛选：按 `category` 过滤。
· 删除 = **软删除**（`is_deleted=true`）；被成本卡引用时**提示但允许删**，已保存卡快照不受影响。
· 🔴 **虚拟原料**（`is_virtual=true`）在列表里**只读**：不可手动编辑、不可手动删除
  （它只能由半成品成本卡级联产生/删除）。
