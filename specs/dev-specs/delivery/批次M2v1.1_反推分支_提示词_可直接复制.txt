## 1. 本批要解决的问题（一段话）

M2 现在只有"**他填数 → 咱们出保本点**"（正算）。但老板真正的问题是反向的：
「**我想月赚 2 万，房租最多能出多少？需要多少客流？翻台要几轮？**」
锁定规范 §M2.12 早就规划了"反推"，但**从未实现**（`calcSandbox` 只有正算）。
本批把反推落地：**同一页加一个「目标反推」Tab**，输入目标利润与约束条件，输出所需营收 / 房租上限 / 客流 / 翻台 / 面积上限。

---

## 2. 反推口径（**核心，务必逐字照做**）

### 2.1 关键洞察：反推 = 一次**入参变换**，引擎零改动

房租在正算是**固定成本**；但在反推里，「房租 = R × 目标租金率」使它变成**随营业额变动的项**
（与外卖佣金同性质）。⇒ 把「目标租金率」当成一项**挂钩费率**喂进 `var_items`，房租自动从固定成本消失，
方程与正算**完全同形**。

**变换公式（第一步）**：

```
fixed_items' = fixed_items.filter(x => x.key !== 'rent')            // 剔除房租
var_items'   = var_items.concat([{ key: 'rentRate', pct: target_rent_rate }])   // 追加租金率
```

然后把 `fixed_items'` / `var_items'` 连同其余入参喂给**既有** `calcSandbox`，取 `target_monthly_fen` = **R**。

### 2.2 派生量（在 R 之上算）

```
目标日均营收 = R ÷ open_days                      → 四舍五入到**分**
房租上限     = R × 目标租金率 ÷ 100               → 四舍五入到**分**
月客流       = R ÷ 客单价                          → 保留 **2 位小数**
日均客流     = 月客流 ÷ open_days                  → 保留 **2 位小数**
翻台         = 月客流 ÷ (座位数 × open_days)        → 保留 **2 位小数**
面积上限     = 房租上限 ÷ 坪效                      → 保留 **1 位小数**；坪效 ≤ 0 或缺省 ⇒ **null**
```

🔴 **先算后取整**：派生量一律用**未取整的中间值**继续算，**只在输出时**取整。
🔴 **不做整数进位**（74.07 人就写 74.07，不要截成 74）。
🔴 浮点容差：保留小数必须用 `Math.round(n * 100 + 1e-9) / 100`（本仓既有纪律，`25 × 1.15` 的坑）。

### 2.3 红警

边际贡献率 ≤ 0（即 `(100 − 毛利率) + Σ挂钩费率 + 目标租金率 ≥ 100`）⇒ `red_alert = true`，
**R 与全部派生量返回 `null`**（不编造；同正算纪律）。

## 3. 精确需求（逐文件，照做）

### ① `cloudfunctions/calcSandbox/validate.js`

| 入参 | 校验 |
|---|---|
| `mode` | 缺省 / `'forward'` ⇒ 正算（**向后兼容**）；`'reverse'` ⇒ 反推；其它 ⇒ `INVALID_PARAM` |

| `pixel_eff_fen` | 选填：整数分，**≥ 0**（缺省 0） |

🔴 **硬约束**：`mode === 'reverse'` 且 `fixed_items` 含 `key === 'rent'` ⇒ 直接 `INVALID_PARAM`，
msg 写：「反推模式下房租由目标租金率导出，请勿在固定支出中重复填写房租」。
（`clean` 里把反推字段一并返回，`mode` 也放进 `clean`。）

### ② `cloudfunctions/calcSandbox/service.js`

- 🔴 **既有 `calcSandbox` 一行不动。**
- **新增** `function calcSandboxReverse(clean)`：
  1. 做 §2.1 的入参变换；
  2. 调 `calcSandbox(变换后的 clean)` 得 `fwd`；
  3. 若 `fwd.red_alert` ⇒ 返回 `{ mode:'reverse', red_alert:true, target_monthly_fen:null, ...  全 null, warn_keys:[] }`；
  4. 否则按 §2.2 算派生量，返回：
     ```js
     {
       mode: 'reverse',
       target_monthly_fen, target_daily_fen, rent_cap_fen,
       monthly_traffic, daily_traffic, turn_rate, area_cap_sqm,
       rent_rate_pct, rev_price_fen, seats, open_days,
       red_alert: false,
       warn_keys: turn_rate > 8 ? ['turnOverHigh'] : []
     }
     ```
     （`turn_rate > 8` 的阈值 **8** 是**自定值**，**不参与计算**，只决定是否给提示句。）
- `module.exports` 增加 `calcSandboxReverse`（**别动既有导出名**）。
