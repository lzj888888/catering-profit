## 2. POC 喂投（核心，按顺序，每份全绿再进下一个）

> **复制包**：桌面 `POC喂投包_综合版.html` —— 打开网页，每段一个「复制」按钮，点一下粘到 inscode。

### 顺序：POC3 → POC1 → POC2（由易到难、依赖由少到多）

| 顺序 | POC | 验证什么 | **验收锚点（错一个即返工）** |
|---|---|---|---|
| **①** | **POC3 双利润口径锁** | 毛利铁律 / 双利润 / 库存倒轧 / **口径锁** | S1 双 **9,160**｜S2 经营参考 **9,160** + 全要素 **3,476.67**｜差异 **5,683.33**（选做 2-R **5,476.67**）|
| **②** | **POC1 摊销边界与尾差残值** | 区间含两端 / 终止残值 / **末月尾差倒挤** | 残值 **9,333.36**｜招牌满摊 **6,000.00**｜2026-08 合计 **4,683.33**｜装修末月 **3,333.45**（不是 3,333.33）|
| **③** | **POC2 BOM 两层与循环拦截** | 单份/批量/2层/虚拟原料/循环拦截/快照刷新 | 宫保鸡丁 **9.75**｜红油底料 **4.48**｜麻辣香锅 **12.35**｜反算 **24.38**｜刷新 **12.09** |

### 每份喂投 SOP
1. 打开复制包 → 复制对应 POC 全文（含「提示词开始/结束」之间）
2. 粘进 inscode 对话 → 发送
3. inscode 产出云函数 + 自测结果表 → **对照上表锚点逐行核对**
4. 全部 ✅（误差 ≤0.01 元）才算过；任一 ❌ → 把"常见错误对照"贴回 inscode 让它改，直到全绿
5. 全绿后 → 提 PR 合入 `main` → 进下一份

**阶段 1**：POC 三复杂逻辑已验证，进全量骨架
**阶段 2**：M1 月度盈利（双利润引擎 + 摊销 + 储值双栏 + 专业模式重算）
**阶段 3**：M2 选址沙盘（正算 + M2.12 反推）
**阶段 4**：M3 菜品成本卡（BOM 2 层 + 循环拦截 + 快照只 INSERT）
**阶段 5**：Module A 收入费用 + 付费墙（权限只读 `expire_at`）+ 红线复核 11 条

**铁律（写码必守，详见 01 架构 12 条 + 06 工程治理 G1~G13）**：
- 金额分(INT) / 重量克 / Unix毫秒 / YYYY-MM；百分比 DECIMAL 禁浮点比
- 所有查询强制 `shop_id`；计算下沉云函数，前端结果一律不采信
- 归档月(`is_archive`)禁改，错账只新增调整记录；软删 30 天不占配额
- 配置读表禁硬编码；必留痕(audit_log 只 INSERT)；待结算不进利润
- **M1 专业模式 = 订阅付费墙**：v1.0 开关默认开放，商业化改配置即切（不阻塞开发）
