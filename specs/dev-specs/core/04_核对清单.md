## C. 红线复核表（一票否决，任一不符即打回）

| 红线 | 检查方法 | 不符后果 |
|---|---|---|
| 金额整数分，禁浮点 | 全局搜索 `float` / `double` / `Number(` 参与金额运算 | 全面返工 |
| 计算下沉云函数 | 检查前端代码是否出现利润/成本计算 | 全面返工 |
| 毛利仅扣食材 | S1 毛利 = 42,000 | 核心数据错误 |
| 双口径锁 | S2 经营参考 = 9,160（开库存后不变） | 核心数据错误 |
| 辅料同损耗口径 | S3 总成本 = **9.75**（非 9.73） | 核心数据错误 |
| 成本卡只 INSERT 不 UPDATE | 改卡后查旧版本是否仍可读 | 数据治理失效 |
| 循环引用拦截 | 构造 A→B→A 是否报错 | 数据可能死循环 |
| 待结算不进利润 | 改待结算数，利润是否变化 | 利润虚增/虚减 |
| 限额读配置禁硬编码 | 改 `subscription_plan` 数值，行为是否随之变 | 违反架构铁律 |
| M2/M3 不读 M1 | 清空 M1 数据，M2/M3 是否仍正常 | 隔离失效 |
| 归档不可改 | 归档月尝试修改是否被拦截 | 账目可信度失效 |
| 操作必留痕 | 关键操作后查 `audit_log` | 无法追溯 |

## D. 人工验收脚本（你可以照着一步步点）

### 第 1 步 · M1（最重要）
1. 新建门店 → 进入月度核算 → 选 **2026-07**
2. 按 S1 录入收入（堂食 43,000 / 外卖 20,000 / 其他 1,000）
3. 录入成本 22,000、费用四项合计 32,840
4. **看两个数**：经营参考利润 和 全要素真实利润 是否都 = **9,160**
5. 切到 2026-08，开库存开关，录期初 5,000 / 采购 25,000 / 期末 7,000
6. **关键**：经营参考利润是否**仍是 9,160**（不是 8,160）；全要素是否 = **3,476.67**
7. 录 3 条摊销资产 → 当月摊销合计是否 = **4,683.33**

### 第 2 步 · M3
1. 录入 11 种原料（按 S3.1 单价与出成率）
2. 建「宫保鸡丁」单份卡 → 总成本是否 = **9.75**、毛利率 **65.18%**

### 第 3 步 · M2

## E. 常见错误对照（发现这些数，说明哪里写错了）

| 现象 | 实际值 | 应为 | 错在哪 |
|---|---|---|---|
| S3 宫保鸡丁成本 | 9.73 | **9.75** | 辅料没按 (1−损耗率) 放大 |
| S2 经营参考利润 | 8,160 | **9,160** | 违反双口径锁，用了倒轧消耗 |
| S4 保本日均 | 1,250.00 | **1,290.91** | 按当月实际天数除，不是 ÷30 |

| 改卡后旧版本没了 | — | 旧版在 | 用了 UPDATE 而非 INSERT 新版 |
| 待结算大额时利润飙升 | — | 不变 | 待结算错误计入了利润 |
