## M1.0 总铁律（写码必须遵守）

1. **双利润口径并存**：经营参考利润（不含摊销、用直接填消耗）与全要素真实利润（扣库存倒轧+摊销）同时输出，二者差异 = 库存差 + 摊销额。
2. **精度**：金额统一整数分（Decimal/INT，禁 JS Number 原生运算）；除法 `Math.round()` 四舍五入 2 位。
3. **时间**：Unix 毫秒时间戳；记账年月用 `YYYY-MM`（字符串索引）。
4. **shop_id 隔离**：所有查询/写入强制带 `shop_id`，复合索引。
5. **归档不可改**：`is_archive=true` 后禁 update 主记录金额；错账只新增"往期业务调整"记录。
6. **计算下沉云函数**：毛利率 / 摊销 / 重算逻辑放云函数 Service 层，**禁前端算毛利**（AI 宪法）。
7. **开关纪律（原文保留）**："收入的开关""其他方面接触的开关"等用户配置项必须原貌保留，不得清理/合并/删减。

## M1.1 双利润计算引擎

### 输入（来自 Module A 已锁字典）
- 收入三分法：堂食 / 平台外卖 / 其他业务
- 成本：库存开→倒轧真实消耗；库存关→直接填总消耗
- 费用：门店运营费 / 人工总成本 / 营销推广费 / 其他支出（各大类合计自动算）

### 公式
```
真实食材消耗 = 期初存货 + 本期采购 − 期末盘点        // 库存开关开
// 库存开关关：直接填「当月食材耗材总消耗」

菜品毛利 = 营业收入 − 食材成本（只扣食材，房租/人工绝不算进成本）
毛利率   = 毛利 ÷ 营业收入 × 100

🟢 经营参考利润 = 营业收入 − 总费用 − 直接填总消耗（不含摊销）
🔵 全要素真实利润 = 营业收入 − 总费用 − 真实消耗 − 当月摊销总费用

两利润差异 = (真实消耗 − 直接填消耗) + 当月摊销
```

> **⚠️ 口径锁（铁律，测试 S2 验证）**：即使开启了库存开关，**经营参考利润仍用"用户直接填的总消耗"**，不改用倒轧值；只有全要素真实利润改用倒轧值。两者差异必须 = 库存差 + 摊销。

### 储值双栏（M1.3 联动）
- 储值**充值**进 `储值负债` 不进营收；储值**消费**确认营收（堂食-储值消费）。
- 双栏输出：① 营收口径（不含充值）② 现金口径（含充值）。坏账/未消费沉淀单独标注。

## M1.2 摊销（直线法 + 边界规则）

### 适用对象
一次性花出、受益跨多月的资本性支出：装修（24/36 月）、设备（36–60 月）、加盟费（按合同）、招牌/制作等。
- 二次装修不覆盖旧账（旧资产继续摊完，新资产新开一条）。
- 租约短于寿命取 `min(寿命月数, 租约剩余月数)`。

### 每月摊销额
```
月摊销 = round(原值 ÷ 总月数, 2)
末月摊销 = 原值 − 前(N-1)期合计          // 尾差倒挤，总和严格=原值
```
> 测试 S2：装修 120,000/36=3,333.33；加盟费 30,000/24=1,250；冰柜 6,000/60=100。

### 边界规则（已拍板 15:20「含两端」）
```
实际摊销区间 = [摊销开始月, 截止月]  两端都含，区间内每月摊，区间外=0
截止月 = 若设 `终止年月` 且早于自然到期 → 取 `终止年月`
         否则 = 摊销开始月 + 总月数 − 1（自然到期月）

推论（统一、老板好懂）：
  ① 摊销开始当月即摊
  ② 终止当月仍摊（最后一次）
  ③ 到期当月仍摊（最后一次）
  ④ 次月起停止
```

### `shop_amortize` 关键字段（#6 待补项已落）
| 字段 | 类型 | 说明 |
|---|---|---|
| `asset_id` | string | 资产主键 |
| `total_value` | int(分) | 原值 |
| `start_month` | string(YYYY-MM) | 摊销开始月 |
| `total_months` | int | 总月数 |
| `end_month` | string | 自然到期月 = start+months−1（系统算，只读） |
| `terminate_month` | string\|null | **资产终止年月**（提前报废），填则截止取此 |
| `monthly_amount` | int(分) | 月摊销额 |
| `residual_loss` | int(分) | 终止时未摊残值（转处置损失） |

### 中途终止残值处理
- 设 `terminate_month` 后，截止月 = 该月；次月起摊销=0。
- 未摊余额 `原值 − 已摊合计` 作为 **「资产处置/报废损失」** 一次性计入当期（或由老板选择留置），**不继续摊**。
- 测试 2b：旧空调 12,000/36，终止 2026-08 → 已摊 8×333.33=2,666.64，残值 9,333.36 转处置损失（2026-09 起=0）。

### 系统行为
- 每月 1 号定时任务生成当月摊销（即使当月未录单也照扣）。
- 到期/终止自动停摊（测试 2b：招牌自然到期 2026-12，2027-01 起=0；装修 2029-01 起=0）。

## M1.4 专业模式 + 归档解锁 + 自动重算连锁（D-专业模式重算 已拍板 14:52）

### 模式分层
- **基础模式**：归档不可解锁；错账只能用"往期业务调整"（只影响当月，不连锁）。
- **专业模式**：允许解锁归档月修改历史数据 → 触发自动重算。

### 重算规则（写码必须遵守）
1. 解锁修改某归档月（如改摊销台账 / 收入费用 / 库存）后，**自动重算该月及之后所有月份**（期初结转链式依赖）。
2. 重算前弹确认：「本次修改将影响 X 月 ~ Y 月共 N 个月利润，是否确认重算？」
3. 重算留痕：`audit_log` 记 谁 / 时间 / 改了哪月 / 影响几月。
4. 重算顺序：先改月 → 按时间向后逐月（后月依赖前月期末结转）。
5. **基础模式不触发**。

> 测试 2-R：改 2026-07 期末存货 5,000→3,000 → 2026-08 期初变 3,000 → 真实消耗 23,000→21,000 → 全要素 3,476.67→**5,476.67**；2026-07 历史快照保留不可覆盖。

| 红线 | 阈值 | 说明 |
|---|---|---|
| 房租占比 | ≤15% | 超则黄/红 |
