## 0. 命名决策（修正项 A）

- **对外模块名**：`M2 选址盈利沙盘`（与 INDEX、数据库表名 `shop_sandbox` 对齐）。
- **为什么不是豆包写的"选址沙盘"**：我方原始规划（单独版本 L5/L19/L63）定位是"选址**反推**"，INDEX L23 已约定为"选址**盈利**沙盘"。豆包版把"盈利"和"反推"都丢了，仅叫"选址沙盘"，语义变窄，故回退到"选址盈利沙盘"。
- **代码表名不变**：`shop_sandbox`（已定，勿改）。
- **"反推"降级为子功能名**：本模块原始定位含"反推客流/翻台/租金上限/面积"（见 M2.12），正算是 v1.0 主体，反推是核心增强，**不可永久砍掉**，否则名不副实。

## M2.1 定位与数据隔离

- 沙盘 = **纯假设测算**，不读取 M1 任何真实核算数据（营收/费用/库存/摊销台账均不碰）。
- "从 M1 复制"动作 = 仅把 M1 最近月份的**固定费用 4 项**（房租/物业/工资/其他杂费）快照复制进本方案，**复制后两处彻底断开**（改 M1 不影响沙盘，改沙盘不影响 M1）。
- 沙盘结果**不可**回写 M1、不可参与任何盈利计算。

## M2.2 方案管理

- 多套方案并存，每套独立参数与结果。
- **免费版上限 3 套**（对应单独版本 L100 "盈利/选址未来可能收费" + `feature_permissions` 表 + `checkFeatureAccess` 门禁）。超过弹升级提示。
- 复制：复制整套参数生成新方案（名称自动加"副本"）。
- 删除：**二次确认弹窗** + **软删除 30 天**（见 M2.9），30 天内可恢复。
- 未保存切换方案：提示"有未保存修改，是否放弃"。

## M2.3 固定成本字段（粗算 4 项）

| 字段 | 类型 | 说明 |
|---|---|---|
| 月房租 | Decimal | 含租金、物业管理分摊 |
| 物业费 | Decimal | 独立拆出，便于小店填 |
| 固定人工成本合计 | Decimal | 含固定底薪+社保+宿舍+员工餐等固定人工支出；**不含提成/奖金等变动部分** |
| 其他固定杂费 | Decimal | 执照/摊销外固定支出 |
| 包含模拟摊销（开关） | Bool | 关：不含摊销；开：手填"模拟月摊销额" |
| 模拟月摊销额 | Decimal | **手动填假设数**，不自动带 M1 摊销台账（新店无实际摊销） |

> **固定人工成本口径（澄清项，与豆包对齐）**：本模块"固定人工成本合计"= 固定底薪 + 社保 + 宿舍 + 员工餐等**每月固定**支出；**提成 / 奖金属变动部分，不计入**。豆包原描述"仅固定底薪"过简，已按此口径补全（选址测算时社保/宿舍/员工餐均为每月固定支出，应计入固定成本）。

> 设计原则：沙盘是粗算，**不拆十几项**（不同于 M1 的门店运营费 7 项）。输入快 > 精细。

## M2.4 变动成本字段 + 红警（修正项 C）

| 字段 | 类型 | 说明 |
|---|---|---|
| 菜品综合变动成本率 | % | 食材/包装等随营收变动部分 |
| 营销综合费率 | % | 外卖佣金+推广综合占比 |
| 其他变动费率 | % | 刷卡/平台其他变动 |

- **红警（唯一强制指标）**：`综合变动成本率 = 菜品+营销+其他`。**≥ 100% 直接红色提示"当前结构无法盈利"，不计算负数保本营业额**。
- 等价：边际贡献率 ≤ 0 即红警。
- ⚠️ **红绿灯口径裁定**（消除单独版本 L56 的"待决"）：原规划提过"保本线 <70%绿/70–100%黄/>100%红"，但沙盘是假设测算、**无实际营收对比对象**，该红绿灯无意义。故**废弃原保本线红绿灯**，统一采用"综合变动成本率 ≥100% 红警"为唯一红警。记录在案，不再待决。

## M2.5 核心计算引擎

```
综合变动成本率 = 菜品 + 营销 + 其他
边际贡献率     = 1 − 综合变动成本率
保本月营业额   = 固定成本合计 ÷ 边际贡献率
保本日均营业额 = 保本月营业额 ÷ 30          ← 固定÷30，不按当月实际天数
目标利润月营收 = (固定成本合计 + 目标利润) ÷ 边际贡献率
目标利润日均   = 目标利润月营收 ÷ 30
（含模拟摊销时：固定成本合计 = 4项固定 + 模拟月摊销额）
```

- 全部 **Service 层计算**，Controller 只展示。
- 精度：金额 Decimal 分存储，除法四舍五入至分（同 M1/M3 红线）。

## M2.6 输出展示 + 动态解读（#8 已落）

- 双指标卡片：①保本营业额（含日均）②目标利润营业额（含日均）。
- **动态解读文案（#8 沙盘日均解读）**：根据结果自动生成人话，例如：
  - "按当前结构，你每天至少要做 **1,290.91 元** 营收才不亏。"
  - "想月赚 15,000，日均需 **2,200 元**。"
  - 变动成本率 ≥100% 时："当前成本结构下无法盈利，请下调变动成本率。"
- 解读文案存字典、按参数拼装，不硬编码。

## M2.7 交互规则

- **实时重算**：任意参数变更立即重算，无需点"计算"按钮（S4 验收点）。
- 输入校验：百分比 0~100、金额 ≥0；非数字拦截。
- 未保存切换提示（见 M2.2）。

## M2.8 导出 PDF

- 单套方案导出为 PDF（固定成本/变动成本/双指标/解读文案）。
- 免费版：导出带水印或限次（与 `feature_permissions` 联动）。

## M2.9 安全校验

- **Service 层二次重算**：前端展示值须经 Service 重算校验，防篡改。
- **软删除 30 天**：`is_deleted` + `delete_at`，30 天后物理清理。
- **操作日志**：方案增删改、复制、导出均留 `audit_log`（操作人/时间/动作），不可改。

## M2.12【修正新增·反推测算子功能】（原始规划核心，不可砍）

> **修正项 B**：豆包 11 节结构里**完全缺失"反推"**，仅做了正算（保本/目标/日均）。但本模块原名"选址**反推**"，原始定位（单独版本 L64）明确要求"给定目标月盈利/客单价/毛利率，反推所需客流、翻台、租金上限、面积"。此功能必须保留，列为 v1.1 增强，但**规范层面锁定其存在**，防止被永久删除。

**输入（反推模式）**：在正算参数基础上，额外输入 `客单价`、`预估毛利率`、`座位数`、`每月营业天数`、`目标租金率`。
**输出与公式**：
```
目标月营收 R        = (固定F + 目标利润P) ÷ (1 − 综合变动率v)   [同M2.5]
所需月客流          = R ÷ 客单价
所需日均客流        = 月客流 ÷ 30
所需翻台次数        = 月客流 ÷ (座位数 × 每月营业天数)
租金上限            = R × 目标租金率
面积上限(可选)      = R ÷ 坪效(营收/㎡)   [坪效为可选假设]
```
**交付节奏**：v1.0 先交付正算（S4 已测）；**v1.1 必须补 M2.12 反推**，否则模块名"选址盈利沙盘"丧失"反推"内核。

## 数据库 Schema（修正项 D：补全 shop_sandbox 表）

```sql
shop_sandbox (
  id              STRING PK,
  shop_id         STRING,                 -- 关联门店
  name            STRING,                 -- 方案名
  fixed_rent      INT(分),               -- 月房租
  fixed_property  INT(分),               -- 物业费
  fixed_labor     INT(分),               -- 固定人工成本合计(含工资+社保+宿舍+员工餐,不含提成/奖金)
  fixed_other     INT(分),               -- 其他固定杂费
  include_amort   BOOL,                  -- 含模拟摊销
  sim_amort_amt   INT(分),               -- 模拟月摊销额
  var_food_rate   DECIMAL(5,2),          -- 菜品变动率%
  var_mkt_rate    DECIMAL(5,2),          -- 营销费率%
  var_other_rate  DECIMAL(5,2),          -- 其他变动率%
  target_profit   INT(分),               -- 目标月利润
  -- 反推字段(v1.1)
  rev_price       INT(分),               -- 客单价
  gross_margin    DECIMAL(5,2),          -- 预估毛利率%
  seats           INT,                   -- 座位数
  open_days       INT,                   -- 每月营业天数
  target_rent_rate DECIMAL(5,2),         -- 目标租金率%
  is_default      BOOL,
  created_by      STRING,
  created_at      BIGINT,                -- Unix毫秒
  updated_at      BIGINT,
  is_deleted      BOOL DEFAULT false,
  delete_at       BIGINT                 -- 软删时间戳,30天后清理
)
-- 计算结果(break_even/target_revenue等)实时算,不落库;如需审计可落 audit_log
```
