# 05 · 审计单（留痕规范 + 过程记录模板）

> 交付包文件 5/5
> 创建：2026-09-09
> 用途：规范 `audit_log` 怎么记，并提供变更/缺陷/发布的记录模板，保证全过程可追溯。

---

## 5.1 `audit_log` 统一表结构

```sql
audit_log (
  id                STRING PK,
  shop_id           STRING,          -- 门店隔离
  operator_openid   STRING,          -- 操作人
  action            STRING,          -- 操作类型（见 5.2 事件字典）
  module            STRING,          -- A / M1 / M2 / M3 / SYSTEM
  target_type       STRING,          -- 对象类型：account / cost_card / sandbox / amortize ...
  target_id         STRING,          -- 对象 ID
  target_month      STRING,          -- 影响记账月 YYYY-MM（可空）
  affected_months   STRING,          -- 连锁影响的月份列表（如 2026-08,2026-09）
  before_snapshot   TEXT,            -- 变更前快照（JSON）
  after_snapshot    TEXT,            -- 变更后快照（JSON）
  reason            STRING,          -- 变更原因（专业模式重算必填）
  create_time       BIGINT           -- Unix 毫秒
)
-- 索引：(shop_id, create_time)、(shop_id, target_type, target_id)
```

### 硬约束

- ✅ **只 INSERT，不可 UPDATE、不可 DELETE**
- ✅ 不可被任何业务代码清理（区别于业务表的 30 天软删）
- ✅ `before_snapshot` / `after_snapshot` 必须能完整还原变更前后关键数值
- ✅ 运营后台可查询、可导出，**不可修改**

## 5.2 必留痕事件字典

| 模块 | action | 何时记 | 必填字段 |
|---|---|---|---|
| **M1** | `MONTH_CREATE` | 新建月度账 | target_month |
| | `MONTH_UPDATE` | 修改收入/费用/库存 | target_month, before, after |
| | `MONTH_ARCHIVE` | 归档 | target_month |
| | `MONTH_UNLOCK` | 专业模式解锁归档月 | target_month, reason |
| | `RECALC_CHAIN` | 连锁重算 | target_month, affected_months, reason |
| | `ADJUST_ADD` | 新增往期业务调整 | target_month, before, after |
| | `AMORTIZE_ADD` / `AMORTIZE_TERMINATE` | 新增/终止摊销资产 | target_id, after |
| | `INVENTORY_CHECK` | 库存盘点 | target_month, after |
| | `STORED_VALUE_ADJUST` | 储值调整 | target_month, before, after |
| **M2** | `SANDBOX_CREATE` / `SANDBOX_UPDATE` / `SANDBOX_COPY` / `SANDBOX_DELETE` / `SANDBOX_EXPORT` | 方案增删改复制导出 | target_id |
| **M3** | `COST_CARD_CREATE` | 新建成本卡 | target_id, after |
| | `COST_CARD_NEW_VERSION` | 编辑/另存新版本 | target_id, version, before, after |
| | `COST_CARD_COPY` | 复制 | target_id, after |
| | `COST_CARD_RESTORE` | 恢复历史版本 | target_id, version |
| | `COST_CARD_SYNC_PRICE` | 同步原料最新价（单张/批量） | target_id, before, after |
| | `COST_CARD_DELETE` | 删除 | target_id |
| | `MATERIAL_CREATE` / `MATERIAL_UPDATE` / `MATERIAL_DELETE` | 原料档案变更 | target_id |
| | `COST_CARD_EXPORT` | 导出 PDF/Excel | target_id |
| **SYSTEM** | `PLAN_CHANGE` | 套餐变更 | reason |
| | `SWITCH_CHANGE` | 开关变更（收入开关等） | after |
