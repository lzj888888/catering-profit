## 三 能力定义

### 3.1 费用项「行内说明」放开到全部费用组

- **单源**：`miniprogram/i18n/terms.js::ledger.expenseItemNotes`（键 = 费用项**显示名**，与 `SEED_EXPENSE_ITEMS.item_name` 一致）。
- **装配点**：`pages/month/input.js::decorateRows(g, rows)` —— 行的**唯一装配口**。
  组对象带 `notesOn`（费用组 `true` / 收入组 `false`，由 `initGroups::mk()` 与 `rebuildFromItems()` 注入）⇒
  初始化 / 读回后端 / 复制上月 / 加行 / 删行 / 铺常规科目 **六条路径自动全挂**，不需要逐处补。
- **派生字段**：`r.note`（说明文字）、`r.promo`（推广费专用高亮）。
  🔴 **均为页面派生字段，不进 `saveLedger`**（与 v1.1 的 `tag` / `needCheck` / `recurring` 同性质）。
- **改名即换注 / 摘注**：`updateRow()` 在 `patch.subItem !== undefined` 时重挂 ——
  命中不了就**摘掉旧注**（否则老板改名后，上一项的解释会留在新名字底下，比"没注"更误导）。
- **渲染**：`pages/month/input.wxml` 的判据由 `g.category === 'marketing' && r.note` 改为 `r.note`。

### 3.2 运营类 7 条行内注（首补）

| 费用项 | 行内注要点 |
|---|---|
| 房租 | 只填本月应摊（总额÷月数）；**一年或两年会调价，涨了记得改**（B2） |
| 物业费 | 和房租一起收的留空/删行 |
| 水费 / 电费 | 按账单填；充值制填本月实际用掉的，或按近 3 个月取平均（M2 经验下沉，V4） |
| 燃气费 | **用电 / 电磁炉的店留空或删掉这一行** |
| 垃圾清运费 | 按季交的填本月应摊 |
| 宽带网费 | 年付先除以 12 |

### 3.3 保存前缺项软提示（C1+C2）

- **触发**：`onSave()` 且 `missingRecurringNames().length > 0` 且本月未提示过。
- **判据**：运营组里 `missingWarnItems` 的项**没有行、或行有名字但金额为空** ⇒ 记为缺项（填 `0` 算填过）。
- **交互**：`wx.showModal`，标题 `missingWarnTitle`，正文 `missingWarnBody(项名)`，按钮 `去填`（2 字）/ `仍保存`（3 字）。
  - `去填` ⇒ **不保存**，把运营费用组展开（`revealMissingExpense()`）。
  - `仍保存` ⇒ 照常走归档宽限期二次确认（原逻辑不变）。
  - 弹窗 `fail` ⇒ 记标记后**照常保存**（绝不因提示失败而阻断）。
- **🔴 绝不硬拦、绝不改金额、绝不参与计算**。

## 五 锚点与守卫

- **引擎零改动 ⇒ 锚点零漂风险**：不触碰 `calcMonthlyProfit`，M1 口径锁（开库存后参考利润 9160 等）不受影响。
- **新增守卫 E7**（`tools/check_expense_item_seed.js`）——盯「项名当机器键」这个静默失效族：
  - E7-① 四处名单（`recurringFixed` / `recurringVariable` / `expenseItemNotes` 键 / `missingWarnItems`）可解析且非空；
  - E7-② 预置名单 ⊆ 种子项名（**改 item_name ⇒ 铺行静默少一行**）；
  - E7-③ 行内注键 ⊆ 种子项名（**改名 ⇒ 文案永不显示**）；
  - E7-④ 缺项提示名单 ⊆ 种子项名（**改名 ⇒ 提示静默失效**）；
  - E7-⑤ **判据自证**：影子样本（假项名报 1 条 / 真项名报 0 条）⇒ 防"判据恒真"假绿；
  - E7-⑥ 运营类行内注覆盖 ≥ 6（实测 7 的保守下沿）⇒ 防本轮新补的可见说明被整段删回去。
- 相关性自查（同轮已跑）：
  - `selftest_r85` 引用的两条营销注键**未改**（回归通过）；
  - `check_modal_button_len`：新按钮 `去填` / `仍保存` 均 ≤4 字符；
  - `check_suite_assert_counts`：声明行 `check_expense_item_seed` 11 → 17（**套件数不变，故 §1 第 2/4/5 处不动**）；
  - 双副本 `miniprogram/i18n/terms.js` ≡ `specs/dev-specs/i18n/terms.js`（md5 一致）。
- 🔴 新守卫文件/改动**必须先 `git add` 再跑门禁**（`suite-tracked` R92 扫 `git ls-files`）。
