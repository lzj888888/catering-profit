## 2 一条被推翻的前提（真缺口在这）

李老师说"有些数据是调用前面填写的"——**对了一半**。已有店铺进矩阵页时，`goMatrix()`（R366）
确实带了 **房租 / 人数 / 毛利率 / 目标利润**（扫描档位种子），所以"档位"是有的。

但「装修费 / 设备费 / 加盟费 / 转让费 / 面积 / 人均工资 / 人工总额 / 管理费」**8 项一个都没带**
（连 4 个摊销年限也没带）⇒ 老板在首页填完，进矩阵页全是空的，要重填一遍。**这才是真缺口。**

⇒ 定案：**不加"导入"按钮，进页时一并自动带过来**（零操作）。
若加按钮，老板不知道该不该点、点了会不会覆盖已经手改过的档位。
⚠️ **年限必须一起带**：只带金额不带年限 ⇒ 年限回落默认 ⇒ 月摊销变、保本线跟着变（口径双轨）。

## 3 我对豆包的两处修正

### 3.1 采纳结论、推翻理由：目标利润不是冗余列

豆包说「目标利润是全局统一参数，所有行数值完全一致，属冗余展示」。
**不成立**：默认档位就是 `[0, 10000, 15000]` 三档（已有店铺时 `[0, 他填的目标]` 两档），它是**变量**。

但结论仍可采纳，换个理由：表里已经有「目标月营收」这一列承载了"目标"信息，
与其重复显示档位，不如把位置让给「淡季安全垫」。

### 3.2 推翻结论：现金卡不做"改造"，直接隐藏

豆包建议不隐藏、改成「现金流安全垫测算」（复用公式、换字段与话术）。
**不采纳**，三条：
1. 换字段换话术实际是**新功能**，不是它说的"改造成本极低"；
2. 已有店铺要算"手上的钱能扛几个月"，**正解在月度核算里**（那里是他记的真实账），不该在沙盘里再估一次；
3. 矩阵页已经够重（8 个投入框 + 4 组档位 + 结果表），再塞一块是加负担。

⇒ 定案：**已有店铺直接隐藏**；抗风险需求用**already 存在的「淡季安全垫」列**满足
（`cushionPct = (目标月营收 − 保本月营收) / 目标月营收`，即"营收还能掉多少仍保本"），
提为默认列，**零新增字段**。找铺子场景保留原卡。

## 4 默认列重排（两场景各恰好 6 列）

| 场景 | 默认 6 列 |
|---|---|
| 已有店铺 | 毛利率 / 人工人数 / 月人工费 / 保本月营收 / 目标月营收 / 淡季安全垫 |
| 寻找铺面 | 月租金 / 毛利率 / 人工人数 / 月人工费 / 保本月营收 / 目标月营收 |

- **毛利率必进默认列**（豆包揪出，我原方案漏了）：它是组合变量，之前收在「更多列」⇒
  老板分不清营收差异来自成本端还是毛利端。
- **月人工费进默认列**：人工是餐饮第二大刚性付现成本，只给人数对不上真实支出；列名由「人工/月」改「月人工费」（原词歧义）。
- **房租只 1 档时不占列**：每行都一样 = 冗余，固定值已写在副标题里（已有店铺正是 1 档）。
- 目标利润 / 回本月数收进「更多列」。
- ⚠️ 「淡季安全垫」必须写成**一个**条目（`colsOpen || mode === 'forward'`）——
  拆成两个 `wx:if` 会让页面列数变 15，撞 R349「导出列数 ≡ 页面列数」对齐全。

## 5 守卫反向改写（R322 → R548）

R322 原判据守「`advOpen` 初值必须 false（高级维度收起）」——**它把"折叠"当成正确实现来守**。
而折叠不只是 UI：它还让 `onGenerate` 里人工/毛利率**只取第 1 档**，等于把两个维度悄悄关掉。

新判据（`check_m2_matrix` 181 → **184**）：
- 折叠机制**零残留**（`advOpen` / `onToggleAdv` / `buildAdvNote` / `adv-toggle` 一律不许出现，**先 stripSrc 剥注释**）
- 四维**一律全量参与**（`const laborUse = labor || [];` 这种形态，退回 slice 即红）
- 四个档位块都在 + 全文不许出现「高级维度」字样
- 顺手修一处守卫自身的假阳性：R349 列数用 `/t\.\w+/g` 会把 `{{dims.rent.length>1}}` 里的
  **`t.length`** 数成一列 ⇒ 收紧为 `/\{\{t\.\w+\}\}/g`（只数真正的列绑定，更准、不是放宽）

## 8 踩坑三条（本轮都真踩了）

1. 🔴🔴 **Python `io.open(p,'w')` 直写会把文件截断成 0 字节**：变异器写回时抛 `TypeError`
   （字节写进文本模式），`open(w)` 已先截断 ⇒ **`matrix.js` 变 0 字节、本轮改动全丢**，只能 `git checkout` 后手工重做。
   ⇒ 定式：**写临时文件 + `os.replace` 原子替换**；还原一律按**原始字节**。
2. 🔴🔴 **行尾是逐文件不同的**：`subpkg/tools/sandbox/index.js` 在 HEAD 里是**纯 CRLF**（2238 处），
   而 matrix.* / terms.js 是 **LF**。我按"统一改 LF"处理 ⇒ `index.js` 整文件翻写（2253/2238），
   并且**从体积里偷回 2.2 KB**（假绿）。⇒ 定式：改完必须按 **HEAD 的行尾约定**逐文件比对，
   且 `git diff --numstat` 出现接近文件总行数的增量 = 整文件翻写，立即回退重做。
3. 🔴 **守卫判据"只看 ❌ 行"会漏判**：失败详情是**不带 ❌ 的缩进行** ⇒ 我第一版变异器把 4/4
   全判成"仍绿"。⇒ 判据要读**守卫全文**再匹配关键字。
