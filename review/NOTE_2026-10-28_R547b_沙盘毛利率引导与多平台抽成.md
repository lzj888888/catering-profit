# R547b · 沙盘页两块引导改造（毛利率引导去按钮 + 多平台抽成怎么填）

日期：2026-10-28 · 触发：李老师当面反馈 + 豆包商议

## 1 起因

李老师反馈：经营盈亏沙盘「③ 菜品毛利率」下面的**「去建成本卡」按钮做不到闭环** ——
填表填到一半被按钮叫到成本卡那边，**他没办法继续填表**。要求这块不要做引导，改成文字。

我自己复核还发现**第二层错**（R545 是我做的，得认）：
原文案写的是「这个数在「菜品成本毛利核算」里建一张成本卡**就自动算出来了**」—— **这是假承诺**。
一张成本卡只给**一道菜**的毛利率，而这个滑块要的是**整店**毛利率（成本卡 + 各菜销量加权），
且那个算法在 M3 菜品复盘页里、还得先导销量表。
⇒ 就算他真跳过去建了卡，回来这个滑杆**也不会自动变成那个数**。按钮兑现不了它写的东西。

## 2 豆包商议结论（两问）

### 2.1 毛利率引导：同意去按钮，并补一条「入口后置」

- 保本沙盘是**轻量测算**，核心目标是让他先走完流程拿到参考结果，中途跳转必然打断闭环。
- 更优补充：**不要砍掉精准核算的路，把它后置到结果页**（算完之后），既不打断填写又承接后续需求。
- 成稿（采用）：
  > 先按大概数填就行：估差多少，保本线就偏多少。
  > 要算准得凑齐成本卡和销量，去「菜品成本毛利核算」算，现在不用停。

逐句作用：
| 句 | 解决什么 |
|---|---|
| 先按大概数填就行 | 降低门槛，消除"没准确数就填不了"的焦虑，敢往下填 |
| 估差多少，保本线就偏多少 | 讲清估算偏差的直接代价，不隐瞒误差 |
| 要算准得凑齐成本卡和销量 | 纠正原句"建一张卡就出数"的假承诺，讲明算准的两个前提 |
| 现在不用停 | 明确禁止中途跳转，保住主流程闭环 |

### 2.2 多平台抽成：不拆行，但补「怎么合成一个数」+ 一条固定费用红线

- **不按平台拆行成立**：所有按流水/单量比例计提的费用，加权合并 ≡ 拆开再合并（R544 已证），
  不改变保本结果，只增加填表量。
- **关键补充（我漏了的）**：老板手上有 2~3 个平台的抽成，**他不会加权平均**。缺的正是这段说明。
- 🔴 **最值钱的一条**：**固定金额类收费不能和比例类抽成加权** ——
  平台年费 / 月度保底佣金 / 达人固定坑位费 / 固定系统服务费，这类**不管卖多少都要交**的钱
  属固定成本，填进比例框会算错 ⇒ 必须指回「每月固定支出」。
- 抖音团购**不另开一类**：券核销与美团团购同一回事，归「团购比原价便宜 + 团购平台抽成」两行；
  达人按销量分佣也算抽成；只有**固定坑位费**才走固定成本。
- 可合并进现有比例框的：商家承担的满减/补贴、自贴配送费、按单保底佣金（按客单折算）、
  包装费、达人按单分佣、核销服务费、扫码/提现手续费。

## 7 踩坑两条（都是我自己踩的）

1. 🔴🔴 **折叠键登记错集合**：`check_hint_fold` 有**两套期望集** —— 全局 `EXPECT` 只服务 `F.wxml`，
   沙盘页的键必须登记在 `PAGE_CASES[].keys`。我第一次登记进 `EXPECT` ⇒ **A6 + S2 + F2 三条同时转红**。
   （R546 已踩过一次，本轮又踩 —— 已在两处注释里钉死。）
2. 🔴🔴 **变异器用 Python 文本模式写回会把行尾整文件翻写**：`io.open(p,'w',encoding='utf-8')`
   把 LF 全翻成 CRLF（`terms.js` 0 → 3140 处、`index.wxml` 0 → 750 处），
   直接后果是**术语双副本 md5 不一致**。修法：跑完变异**必须**按字节核 CRLF 并 `b'\r\n'→b'\n'` 还原，
   然后 `git diff --numstat` 确认无整文件翻写。
