## 1 段 · M1 月度核算（这是老板每周真会用的）

| # | 操作 | 预期 | 不合格 |
|---|---|---|---|
| 1.1 | 首页 → 新建一个月度账（选月份） | 建成功，进入录入页 | 建不了 / 建完看不到 |
| 1.2 | 录入页：填营收（如 `12,000` 带千分位逗号） | **必须提示"读不出金额"并指名哪一栏**，不能按 0 算 | 静默当 0 ⇒ 后面利润全错（R415/R425 那一类） |
| 1.3 | 改填 `12000` → 继续填房租、人工、水费、电费 | 输入区下方**实时出现"每月固定支出合计"**，边填边变 | 不出现 / 数字明显不对（少算一项） |
| 1.4 | 顶部「还差哪几格」提示 | 缺房租/人工/水电气时提示；**全填完自动消失** | 填完了还提示 / 缺着却不提示 |
| 1.5 | 进「库存」页 → 填期初/期末 | 保存成功，返回后数字还在 | 保存后变 0 / 返回没了 |
| 1.6 | 进「摊销资产」→ 加一笔（如装修 6 万 / 3 年） | 月摊销 = **总额 ÷ 月数**（6 万 ÷ 36 = 1,666.67） | 数字对不上 / 填小数年限被拒 |
| 1.7 | 回结果页 | 有**利润、毛利率、保本营业额、现金流"还能撑多久"**；保本额与手填毛利率口径一致 | 空白 / 数字像没算 / "还能撑多久"恒为同一个值（R298 那类恒真） |
| 1.8 | 点**导出/打印** | 有明确反馈（成功给文件/失败说原因），**不是点了没反应** | 点了没反应 / 第一次必失败 |
| 1.9 | 结果页往下滑：行业对比 / 指标 | 有内容或明确"数据不够，暂不评价" | 给了一个没有依据的"优/良/差"评级 |

## 2 段 · M2 开店沙盘（选址/反推）

| # | 操作 | 预期 | 不合格 |
|---|---|---|---|
| 2.1 | 进「开店沙盘」→ 选一个业态（如小面馆） | 关键参数被**预填**（毛利率/人工/客单价），并提示"已按行规预填" | 全空要自己填 / 预填值明显离谱 |
| 2.2 | 填房租、人工、水/电/燃气（三项分开填） | 三项**分开填、都算进合计**；合计实时更新 | 只能填一个合计 / 少算一项 |
| 2.3 | 点计算 | 出保本营业额 + 利润；**费率行（其他/损耗）出现"≈ 多少元/月（估算）"** | 没有估算行 / 给了不带"估算"的裸数字 |
| 2.4 | 改「预计月营业额」 | 上面那条"≈ 多少元/月"**跟着变** | 不变 / 变了但明显倍数不对（基数搞错 = R292 同族） |
| 2.5 | 点「保存方案」→ 进「多方案对比」 | 方案在列表里，保本量与沙盘页**一致** | 两个数对不上 |
| 2.6 | 进「场景矩阵」→ 毛利率填 **150** | **当场提示范围错误、不发请求、不画矩阵** | 照算出一个乱矩阵 / 整页崩 |
| 2.7 | 切「反推（找店）」模式 → 填房租 | 被拒并说明"反推模式下房租由目标租金率导出" | 收了房租却算出矛盾的数 |

## 3 段 · M3 配方侧（成本卡 / 复盘 / 外卖 / 团购）

| # | 操作 | 预期 | 不合格 |
|---|---|---|---|
| 3.1 | 「配方」→ 新建菜品卡 → 选原料 → 填单价/用量/出成率 → 保存 | 保存成功；**成本与毛利率当场算出来** | 保存后成本 0 / 毛利率空白 |
| 3.2 | 出成率填 **150** | 提示超上界（不让你存一个假成本） | 存了 ⇒ 后面全错 |
| 3.3 | 原料库 → 批量粘贴一段表格 → 解析 | 解析出行数正确、字段对得上；解析不了**说明哪一列有问题** | 静默少行 / 只说"失败"不说原因（R434 那一类） |
| 3.4 | 改某个原料单价 → 保存 | 提示"哪些菜的成本会跟着变"并给入口（不是假承诺"已自动更新"） | 说"已自动更新"但卡里还是旧价（R406 那一类） |
| 3.5 | 进「单品复盘」 | 有**两款毛利率口径的说明**（本页=菜品卡现算 / 选址测算=手填） | 没有说明 ⇒ 老板会以为算错了 |
| 3.6 | 复盘页看"覆盖率"与"还差 N 道" | 覆盖率按**金额**算、道数按菜名去重；卡不够时提示"还差 N 道" | 按行数算（被 0 元 SKU 稀释）/ 卡不够也给批量关联按钮 |
| 3.7 | 进「外卖」→ 录一单（含打包费） | 到手额/毛利算得对；**佣金基数不含打包费** | 把打包费算进佣金基数 ⇒ 佣金虚高 |
| 3.8 | 进「到店团购」→ 选卡 → 填团购价/佣金率 → 算到手 | 同时出现**到手率**和**毛利率**，下面有一句"两个数分母不同"的说明 | 只有一个率 / 两个率分母搞混（毛利率分母应是**到手额**） |
