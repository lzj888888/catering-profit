# 体验版真人走查清单（发给老板照着点，2026-11-23）

> 用法：老板用微信扫体验版二维码进来，**照下面的顺序点一遍**，哪一步卡住/看不懂/结果不对，
> 直接在微信里告诉管理员"第几步 + 现象"。不要自由发挥，按顺序走。
> 🔴 现在付费功能关闭（提审期合规态），**只测免费全链路**；付费版等商户号开通后另测。

---

## 第 0 步：能不能进
- [ ] 扫码后能打开小程序首屏，不白屏、不报错。
- [ ] 底部三个入口在：**核算 / 成本 / 我的**。

## 第 1 步：建店铺 + 录一个月账
- [ ] 首页顶部能填店铺名，能保存。
- [ ] 进「月度盈利核算」，录一个月：房租、水电、食材、人工等。
- [ ] 能看到**参考利润**（算出来的数对不对自己心里有数即可）。

## 第 2 步：菜品成本
- [ ] 进「菜品成本毛利核算」，建一张菜品成本卡（填售价 + 原料成本）。
- [ ] 能看到这道菜**赚多少 / 该卖多少钱**。

## 第 3 步：开店试算（沙盘）
- [ ] 进「经营盈亏沙盘」，填投入和每月固定支出。
- [ ] 能看到**保本营业额**。

## 第 4 步：诊断报告
- [ ] 找一个入口进**深度诊断**（有结论等级、一句话、风险信号的那个页面）。
- [ ] 结论是否看得懂？有没有"被咒店倒"的感觉？（我们刻意用事实句，不该吓人）
- [ ] 拉到页面最底下，有**「联系客服」「意见反馈」**两行 → 点一下看能否拉起会话/反馈页。
      （拉不起=后台还没绑客服，告诉管理员，不算你操作错）

## 第 5 步：订单 / 有效期
- [ ] 进「我的」→「我的订单 / 有效期」，能打开不报错。
- [ ] 页面最下方也有**「联系客服」「意见反馈」**两行。
- [ ] 现在未付费，看到空订单列表是正常的。

## 第 6 步：客服与反馈（重点）
- [ ] 「我的」→「联系客服」，点一下：能不能进客服会话？
- [ ] 「我的」→「意见反馈」，点一下：能不能打开反馈页？
- [ ] 客服/反馈入口有没有哪个点了没反应？记下来。

## 第 7 步：账号与安全
- [ ] 「我的」→「查看隐私协议」，能打开完整条款。
- [ ] 「我的」→ 头像/昵称能改并保存。
- [ ] （不要点「注销账号」，那个会真删数据，测试别碰。）

---

## 反馈怎么写（发给管理员）
按这个格式，一条一行：
```
第X步 · 现象：（卡住/报错/看不懂/数字不对）
       · 手机型号：（如 iPhone 15 / 华为 P60）
       · 截图：（有的话发一张）
```

## 特别说明
- 测试数据进的是**测试环境**，不会污染正式数据，放心填真实店铺数字。
- 遇到"暂未开放""客服暂未开通"这类提示是**当前阶段的正常状态**，不是 bug，但请告诉我们是在哪一步看到的。
- 一个微信号测完想换人测：让管理员在后台把你加为**体验成员**再扫，名额有 60 个。
