# R760 · 全局底色调暖米黄（2026-11-26）

## 触发
李老师给两张「功夫 Harness」网页参考图，反馈「原来 M3 整体进来底色太过于青白色，看着不舒服」，问有无可借鉴。

## 机器取色（不凭肉眼）
- 参考图（授权页）页面主色：`#F7F2E6`（全图最常见色 216604 像素）。
- 参考图（下载页）主色 `#F7F1E6` / `#FEFBF6`，同属暖米黄系。
- 原底色：`#F6F3EC`（RGB 246,243,236）；新版 `#F7F2E6`（RGB 247,242,230）——**蓝通道 −6**，青白感来源。

## 关键判断（先审后做）
1. 底色是**全站单源**（`app.wxss page{}`），首页/M3/我的共用。上轮机器核对已证两页底色值完全相同——「首页好看、M3 青白」是 M3 满屏白卡把底色露得更多所致，不是色值不同。
2. 因此**不搞页面级覆盖**（R680 明确：留第二份底色 = 下一个漂移点）。一处改、三处同步：
   - `page { background:#F7F2E6 }`
   - `.sb-page { background:#F7F2E6 }`
   - `.sb-badge.na { background:#F7F2E6 }`（徽标灰底，不改会在新底上显脏）
   - 头部色板注释同步 + 注明来源/理由。
3. 守卫 `check_theme_color.js` A5-② 判据是「page 必须显式写死 hex」，**不绑死具体色值**（R680 已把绑死的旧色松掉），故换色不撞红。

## 对比度实算（诚实登记）
| 文字色 | 旧底 #F6F3EC | 新底 #F7F2E6 | 结论 |
|---|---|---|---|
| #776C5E（文字下限） | 4.63 | 4.59 | ≥AA |
| #2B2620（正文） | 13.53 | 13.42 | ≥AA |
| #6B6157（次要） | 5.46 | 5.41 | ≥AA |
| #b45309（付费橙） | 4.53 | **4.50** | 仍 ≥4.5，但余量收窄到悬崖边 |
| #1e3a5f（深蓝强调） | 10.38 | 10.30 | ≥AA |

- **未动 `#b45309`**：它全仓十几处，且 `utils/marginBand.js` 的毛利分档语义色被 `check_m3_margin_bands.js` 按字面量锁死。为换底色去动语义色是越界；4.50 仍达标。
- 登记风险：将来若再调暗底色，需一并加深 `#b45309`。

## 验证
- `check_theme_color` / `check_text_contrast` / `check_line_endings` 单跑全绿；全套 verify_all 后台跑（结果见交付）。
- 模拟器实拍 `review/evidence/r760_m3_hub.png`：M3 页正常渲染、底色暖调、8 图标与徽标无重叠溢出。
- 首页那张 `r760_home.png` 是 loading 态白屏（数据在加载、`wx:if` 未渲染内容），**不作底色证据**，仅留档。

## 诚实登记
