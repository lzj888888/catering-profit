1. 「经营结果里 **导出月度报表**，点击后显示 **导出完成**，然后没有反馈了，不知道去哪里看导出的文件，格式也不知道。」

## 二、根因（不是没生成，是**用户永远拿不到**）

| 层 | 现状 | 后果 |
|---|---|---|
| 云函数 `exportData` | 默认 `format='excel'` ⇒ 落 **CSV**（带 BOM） | 内容其实生成成功 |
| 前端三处 | `wx.openDocument({ fileType: 'csv' })` | 🔴 微信 `fileType` 合法值 **只有** doc/docx/xls/xlsx/ppt/pptx/pdf —— **csv/json 一律打不开** ⇒ **必走 fail** |
| fail 回调 | M1/M3 都是 `fail: () => {}`（空） | **零反馈**，用户只看到「导出完成」 |
| 文件落点 | 小程序沙箱 `wx.env.USER_DATA_PATH` | 手机文件管理器里**根本看不到** |

⇒ 一句话：**功能没坏，交付链断了**；且断得**完全静默**（不报错、不崩溃）。

补充（用户问的第 3 点，一并排查）：一共 **4 个**导出入口

| 入口 | 页面 | 修前 | 修后 |
|---|---|---|---|
| 导出月度报表 | `pages/month/result` | CSV + 空 fail | 真 xlsx + 单源投递 |
| 导出 / 打印（菜品成本卡） | `pages/card/index` | CSV + 空 fail | 真 xlsx + 单源投递 |
| 对比表 · Excel | `pages/sandbox/list` | **复制到剪贴板**（用户拿到一串字，不知往哪粘） | 真 xlsx + 单源投递 |
| 对比表 · 图片 | `pages/sandbox/list` | canvas → `wx.previewImage` | ✅ 本来就有反馈（可长按保存），**未动** |

⚠️「导出 / 打印」是**同一个按钮**（`TERMS.buttons.export = '导出 / 打印'`），仓内**没有独立的打印功能**。

## 三、改动（commit `42300f8`）

1. **`cloudfunctions/exportData/index.js`**：新增 `xlsxBase64()`（SheetJS，`bookType:'xlsx'`，`type:'base64'`）；
   **不传 format 时默认 `xlsx`**（`excel`=CSV 降为旧兼容通道）；出参新增 `encoding`（`base64` / `utf8`）；
   🔴 依赖缺失必须 `fail(SYSTEM_ERROR)` **响亮失败**，**禁止静默回退 CSV**（那正是本轮事故的原点）。
2. **`cloudfunctions/exportData/package.json`**：声明 `xlsx ^0.18.5`（与 `importSalesBill` 同版本；由 `check_fn_deps` 守「require ⊆ deps」）。
3. **新增 `utils/exportFile.js`（投递单源）**：
   - `OPENABLE` = 微信官方 7 个合法值，**不含 csv/json/txt**；
   - 写盘（base64 走 `wx.base64ToArrayBuffer` + `binary`）→ `wx.openDocument({ fileType, showMenu: true })`；
   - **打不开 ⇒ `wx.showModal` 说清文件叫什么 + 「转发」走 `wx.shareFileMessage`**（发给自己/文件传输助手）；
   - 不在白名单的类型（json 等）**直接走转发**，不调 openDocument（调了也是白调）。
4. 三处调用点全部改走单源，`format:'xlsx'`；页面按钮下**常驻一行**：「导出为 Excel(.xlsx)，打开后点右上角『…』可保存或转发到微信」。
5. 新守卫 **`tools/check_export_delivery.js`**（25 断言，S/A/B/C/D 五组）挂为第 165 个套件。

## 六、顺带回答（用户第 4 问：外卖导入）

- 「数据导入」tab 里的 **「选择账单文件」按钮**：**入口正常**，但**文案过时**——
  R259 已把**外卖账单（订单级）**暂停展示，该按钮现在实际承载的是
  **形态 A 堂食《菜品销售统计》/ B 套餐明细 / C 外卖《商品销量》**三种表；
  下方提示行写的是「支持堂食《菜品销售统计》与外卖《商品销量》；账单导入正在打磨，暂不开放」。
  ⇒ 按钮文案应从「选择账单文件」改成「选择销量文件」（**下轮做**，本次未改，避免与 R259 的守卫面交叉）。
- **支持几天 / 整月吗**：支持。形态 C 按**行内「日期」列**分组（一表多天 ⇒ N 组，不补零行），
  已实测导入淘宝闪购 `商品下载_*.xlsx`（7 天 × 51 商品 = 355 行）；
  预览页会显示**天数**与**日期区间**（`groupCount` / `dateRangeText`），跨月也会分月归集。
  ⇒ 「7 天账单」「一个月账单」都能导；**没有**「必须先按天拆表」这种限制。
