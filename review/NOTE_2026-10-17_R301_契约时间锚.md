## 0 一句话

把 **契约里一直声明、却从未实现**的 `getDishReview` 入参 `biz_date_from` / `biz_date_to`
**补上实现**，并让期间**可见**。此前复盘榜把该店**历次导入的多个月份全部累加**成一份榜、
页面却按"当前月"呈现 ⇒ **「这道菜这个月卖过」是错的**（静默错数；真样本就是 **7 天表**，
"一段"冒充"整月"）。连带面（堂食榜 / 覆盖率 A+C / 自助餐块）随之变化，已一并回归。

**这不是加需求，是补实现** —— 契约 `specs/dev-specs/core/10_云函数清单与接口契约.md:69` 原文即
`入参 { shop_id, biz_date_from, biz_date_to, platform?, client_request_id }`。

## 1 缺陷（回源码取证）

| 项 | 事实 |
|---|---|
| 实现 | `cloudfunctions/getDishReview/index.js:56` `da.listAll('external_sales_daily', { shop_id: shopId })` —— **只按店过滤** |
| 落库主键 | `SALE_<shop>_<platform>_<biz_date>_<seq>` **含日期** ⇒ **多月数据并存** |

## 2 修法（设计取舍留痕）

| 决策 | 选择 | 理由 |
|---|---|---|
| 入参形态 | **按契约原样** `biz_date_from` / `biz_date_to`（不加 `month`） | 补实现不加概念；顺带白送"自定义区间" |
| 过滤落点 | **service 纯函数层**（`filterByRange`），不在 `where` 加范围条件 | `common/dataAdapter.js` 的 `where` 只支持**等值**；加范围支持要动全仓 **51 份** `cx_dataAdapter.js` 派生副本（跑 `sync_common`）⇒ **改动面与风险不成比例**；而**在内存里过滤与在库里过滤结果逐行等价**（`listAll` 本来就读全量，读的量不变） |
| 缺省行为 | **任一端缺 ⇒ 不过滤**（与改动前**逐行等价**）＋ 出参 `range.from=''` 如实回报 | **不 fail-closed**：现网旧客户端调 `{}`，一旦硬拒会**页面打不开**（可用性风险）；改为"如实回报 + 前端明说不是单月" |
| 单边区间 | **不做** | 半开区间算出的榜既不是本月也不是全部，**比不过滤更糟** |
| 月→区间换算 | 下沉 `utils/ui.js::monthRange`（**单源**） | 各页各写必然漂（本仓既有红线）；月末天数用 `Date.UTC(y,m,0)` 取"下月第 0 天"⇒ **零月长硬编码** |
| 期间可见 | 页面顶部：月份选择器（系统 `<picker fields="month">`）+ 期间文案 | 期间口径决定下面每个数怎么读，**不能埋在末尾**；`days` 直接把"这个月只有 7 天数据"暴露出来 |

## 7 边界与未闭环（如实）

1. **`platform?` 入参仍未实现**（契约声明了可选 `platform`，实现不按平台过滤）⇒ 已由新守卫**自动纳管**（它出现在契约里且实现未引用…）。
   ⚠️ 但本次实测它**未报红** ⇒ 说明实现里**某处**出现了 `platform` 字样（`splitSales` 读 `s.platform`）⇒
   **判据只能证"名字出现过"，不能证"按契约语义用了它"** ⇒ **这是本守卫的粒度边界，如实登记**。
2. **历史数据无法回填期间**：已落库的"7 天段"与"整月"混在一起，只能靠 `biz_date` 推断 + **期间如实标注**。
3. **契约出参已在本次校正**，但 `getPlan` / `calcBom` / `adminRevokeToken` 三处契约仍待更正（已登记）。
4. C 线冻结；`manageShop` 加性出参**待重新部署**；**`getDishReview` 本次也改了云函数 ⇒ 同样需重新部署**
   （未部署时旧前端仍可用：不传区间 ⇒ 不过滤 ⇒ 页面显示"全部期间，不是单月" —— **诚实降级**）。
5. 🔴 **本轮踩到的**判据保留词坑（**已踩实，值得记住**）：契约表行里的「**未实现**」是**保留标记词** ——
   `check_fn_inventory` **F3 反向**用 `docLines[ln-1].includes('未实现')` 判「标记了却已落地」。
   我在该行写说明时用了这个词（本意是叙述历史），⇒ 该行被**误认成"带未实现标记"** ⇒ F3 反向判红。
   **⇒ 契约表行的任何说明文字都不得含该 4 字标记词**（要表达"没做"请换措辞，如「只声明、未落地」）。
   ⚠️ 同类风险：`F3 正向`也靠它 ⇒ **多写一处就会把"未落地"的行悄悄放行**。判据是**整行子串匹配**，
   粒度粗 —— **如实登记为判据边界**（未改该守卫，避免超出本轮范围）。
