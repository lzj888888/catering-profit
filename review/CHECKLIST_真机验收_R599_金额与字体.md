## A 段 · 今晚新加的五页守卫（最高优先）

> 措辞说明（免得你以为踩到两个不同 bug）：**库存 / 资产 / 矩阵**是**点保存/生成时弹窗**；**成本卡 / 外卖**是**页面常驻横幅 + 点按钮时再弹窗**。三套话术讲的是**同一件事**（读不成 → 拦住、不出数），只是各页落点不同。文案尚未全部统一进 `terms.js`（库存/资产仍是硬编码），已登记为技术债，不在今晚强改。

### A1 库存页（R594）— 预期「保存前弹窗点名哪一栏 + 拦住不入库」

> 弹窗标题是「**金额读不成数字**」，正文会点出**页面上那三个字**：`期初库存` / `本月采购` / `期末盘点`（不是"期初/采购/期末"这种简称——按这个字面对，才算验到点名）。

| # | 操作 | 预期（什么算对） | 不合格的样子 |
|---|---|---|---|
| A1.1 | 进库存页 → 期初填 `12,000` → 保存 | 弹窗**写明「期初库存」**，点确定后**没保存进去** | 静默保存 ⇒ 期初被按 0，倒轧真实消耗全错 |
| A1.2 | 换成采购 / 期末分别填 `１２０００` | 同样弹窗、分别写明「本月采购」「期末盘点」 | 只提示「读不成」但不说哪一栏 / 照样存了 |
| A1.3 | 三栏都改回纯数字 `12000` → 保存 | 正常保存，返回后数字还在 | 改回纯数字仍被拦 |

### A2 一次性投入/资产页（R594）— 预期「拦住 + 保留必须 >0 校验」

| # | 操作 | 预期 | 不合格 |
|---|---|---|---|
| A2.1 | 进摊销资产页 → 加一笔，金额填 `12,000` → 保存 | 弹窗标题「**金额读不成数字**」（这页只有一格金额，所以不点名哪栏）、拦住不存 | 静默按 0 进台账 |
| A2.2 | 金额填 `0` 或留空 → 保存 | 走**原有**「金额必须大于 0」提示（不是新弹窗） | 0 被存进去 |

### A3 场景矩阵页（R595）— 预期「点生成前弹窗点名，含『第几档』」

| # | 操作 | 预期 | 不合格 |
|---|---|---|---|
| A3.1 | 矩阵页 → 装修金额填 `12,000` → 点「**生成矩阵**」 | 弹窗指名「装修」+ 拦住**不出数** | 静默按 0 ⇒ 投入/月摊销少算、保本偏低 |
| A3.2 | 「你现在月营收」填 `１２０００` → 生成 | 弹窗指名该栏 + 拦住 | 「我差多少」整块不显示却不给原因 |
| A3.3 | 租金**第 2 档**填 `12,000` → 生成 | 弹窗里出现「租金第 2 档」这种**指名到档位**的说法 | 那一档被悄悄跳过、矩阵少一行且无提示 |
| A3.4 | 改成纯数字 → 生成 | 正常出矩阵 | 改对了还被拦 |

### A4 外卖每单试算页（R596 + R598）— 注意**两条不同横幅**

| # | 操作 | 预期 | 不合格 |
|---|---|---|---|
| A4.1 | 外卖页 → 佣金率填 `12,000` → 点「**测算结果**」 | **弹窗**（"有金额栏填的内容读不成数字…"）+ 页面**金额横幅** + **不出数** | 点了完全没反应（只有横幅、无弹窗）/ 静默按 0 ⇒ 佣金归零、到手虚高 |
| A4.2 | 同上，改点「**反算**」 | 同样被拦（弹窗 + 不出数；反算按 0 会把人带向**亏本定价**） | 反算出一个偏低挂牌价 |
| A4.3 | 某道菜的**份数**填 `1,000` → 计算 | 出现**另一条份数横幅**（"这一行会按 0 份算、金额变 0"）+ 弹窗也讲份数 + 不出数 | 行还在但金额变 0、无任何提示 |
| A4.4 | 金额栏与份数栏**同时**填错 → 计算 | **两条横幅都出现**；弹窗里**两句都写**（金额一句、份数一句），各讲各的 | 只提示一条 / 混成一句让人改错格 |

### A5 成本卡页（R597）— 用量「整行被跳过」，比按 0 更隐蔽

| # | 操作 | 预期 | 不合格 |
|---|---|---|---|
| A5.1 | 成本卡编辑页 → 某原料「用量」填 `1,000` → 保存 | 出现**独立用量横幅**（"这一行会被当成没填、不参与成本计算"）+ 拦住 | 那行悄悄不进成本 ⇒ 毛利虚高、零提示 |
| A5.2 | 同时把某金额栏填 `12,000`、用量填 `1,000`、模式 B 出货量留空 → 保存 | **三路提示各自出现**：金额 / 出货量 / 用量，各改各的格 | 只弹一句 / 提示让人改错地方 |
| A5.3 | 全改回纯数字 → 保存 | 正常保存 | 改对了还被拦 |
