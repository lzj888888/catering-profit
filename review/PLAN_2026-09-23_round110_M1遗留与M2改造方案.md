## 2.3 你的 6 条需求 → 逐条落位

### ① 菜品变动成本率 → **毛利率**

| | 现在 | 改后 |
|---|---|---|
| 问法 | 「菜品综合变动成本率 35%」 | 「**菜品毛利率 65%**」 |
| 用户心理 | 要反着想（越小越好） | 餐饮人天天挂在嘴上的数（越大越好）✅ |

- **换算**：边际贡献率 = 毛利率 −（其他随营收变动的费用率）
- **必须配一句对照提示**：「毛利率 65% = 食材成本占售价 35%」—— 否则老用户会以为换了口径。
- ⚠️ **要你拍板口径**：毛利 = 收入 − **食材成本**（只扣食材，房租人工绝不进成本）—— 这条与 M1 的毛利铁律一致，建议直接沿用。

### ② 营销费用率 + 其他变动率 → **去掉**，改成"可选费用类型 + 自填细项"

- 你的诉求（原话）：「客户不理解这个率里面有什么，不如直接加一些可选择的费用类型，就像月度盈利核算一样，自己去选、去添加细项目」✅ 明确。
- ⚠️ **但这里有一个口径陷阱，必须你拍板**（我的建议在下面）：

| 费用性质 | 例子 | 本质 |
|---|---|---|
| **每月固定** | 房租、人工、管理费、加盟费摊销、装修摊销 | 与营业额**无关** → 填**金额** |
| **跟营业额挂钩** | 外卖平台佣金、团购佣金、刷卡手续费 | 与营业额**成正比** → 本质是**率** |

- 🔴 **如果全部改成"填金额"**：外卖佣金会被当成固定成本 ⇒ **保本点被算低（偏乐观）** ⇒
  对"这店能不能开"的决策是**危险方向**（真实情况是流水越高佣金越高，永远不会"越做越省"）。
- ✅ **我的建议（方案 A）**：费用清单**分两类**，填法各随其性质 ——
  - **A 类「每月固定支出」**：房租 / 物业 / 人工 / 管理费 / 一次性投入摊销 … → 填**金额**（+ 可选参考区间）
  - **B 类「跟营业额挂钩」**：外卖佣金 / 团购佣金 / 刷卡手续费 … → 填**占比 %**，**并给推荐区间**
    （例如"外卖佣金一般 15~20%，跟平台与品类有关"）
  - 好处：小白面对的**还是"选类型、填个数"**，不是抽象的三个"率"；**但口径不跑偏**。
- 备选（方案 B）：全部填金额 + 每项加一个"其中多少跟营业额挂钩"的副标注 —— 更复杂，**不推荐**。
- **待你选 A 还是 B**（我不代选）。

### ③ 加盟费 / 装修 / 固定资产摊销 / 管理费 —— 要有体现

⚠️ 这四项**性质不同**，不能混成一栏：

| 项 | 性质 | 建议落位 |
|---|---|---|
| **加盟费** | 一次性（可能还有每年续约费） | 进「**建店一次性投入**」，可按年限摊到月度 |
| **装修** | 一次性 | 同上（通常按租期摊） |
| **固定资产（设备/家具）** | 一次性 | 同上 |
| **管理费** | **每月固定** | 直接进月度固定成本 |

- ⇒ 需要新建一条链「**一次性投入 → 摊到每月**」：填**总额 + 摊销年限** ⇒ 自动算出 **月摊销额** ⇒ 进固定成本。
- 这正好补上现有「含模拟摊销（**手填月摊销额**）」的短板 —— 现在要用户自己心算，改成**填总额+年限、自动摊**。
- 📌 规范 M2.11 已定过相关口径（可直接用）：
  - **建店投入（一次性口径）** = 转让费 + 加盟费 + 装修 + 设备 + 押金 + 证件开办费 + 首期房租
  - **押金**：可退 ⇒ 提供「押金可退（不计入回收口径）」勾选，**默认计入**（保守）
  - **收回投入期(月) = 建店总投入 ÷ 目标月利润**，对外软展示为「**约 X 个月收回投入**」（不叫"回本周期/ROI"）
- **要你拍板**：摊销年限是用户自己填，还是给默认值（如按租期 3/5 年、加盟期）？

### ④ 餐饮指标对照（房租占比 / 人工占比 / 水电气…推荐占比）

- **M1.6 已有现成阈值**（房租 ≤15% / 人工 ≤20% / 菜品毛利率 ≥55% / 食材损耗 ≤5%）⇒ **直接复用，不另立一套**。
- 建议展示形态：一行一项，左边你的值、右边参考区间 + 判定色块 ——

  | 指标 | 你的情况 | 餐饮参考 | 判定 |
  |---|---|---|---|
  | 房租占比 | 8,000 ÷ 38,727 = **20.7%** | ≤15% | 🔴 偏高 |
  | 人工占比 | 12,000 ÷ 38,727 = **31.0%** | ≤20% | 🔴 偏高 |
  | 菜品毛利率 | **65%** | ≥55% | 🟢 健康 |

- ⚠️ **要你拍板**：占比的**分母**用哪个？
  - (a) **保本营业额**（最保守 —— 刚够保本时占比最高，压力测试）
  - (b) **目标利润营业额**（贴近你真正打算做的生意）
  - (c) **两个都算**（最直观，但一屏四行变八行）
- ⚠️ 另外：**水电气/能耗**的参考区间 M1.6 里**没有**。要不要我们补一套（需要你给行业经验值或我去查）？

### ⑤ 页面风格：毛利率用**滑动**调节

- 金额类 → 输入框（要精确）；**比率类 → 滑块 + 数字双显**（好调、能"玩"）
- 滑动时结果**实时跳** ⇒ 正好把 2.2 的差距 ①（去掉"计算"按钮）一并解决。
- ⚠️ 规范 M2.7 已定死实现方式：前端实时反馈必须**与云函数共用同一份纯函数**（不许前端另写一套算法），
  保存时由云函数二次重算作权威 —— 这条照做即可。

### ⑥ 「更多演示不同场景下毛利及盈亏平衡点的变化」（你说的核心）

建议分三层，按成本从低到高：

| 层 | 内容 | 依赖 |
