# 客服自动回复文案模板（可直接粘贴到客服工作台）

> 用途：在「小程序客服助手」（手机）或 `mpkf.weixin.qq.com`（网页端，客服本人扫码）的
> **设置 → 自动回复 / 欢迎语 / 关键词回复** 里，逐条复制粘贴。
> 依据：`PLAN_2026-11-23_客服售后直达与未上线测试.md` §2.3 三句话口径 + 全站话术合规红线。
> 🔴 三条铁律：① 不承诺机制做不到的事（不承诺改数据/退钱时限）② 不报价格、不说"会员/订阅/付费解锁"
> ③ 不说"食材成本率"，说"毛利率"。

---

## 一、欢迎语（用户首次进入会话自动发送）

```
您好，这里是餐饮智算客服。
请直接说遇到的问题，例如：怎么录一个月账 / 菜品成本怎么填 / 导入 Excel 报错 / 订单与有效期。
我会尽快回复。也欢迎用「我的 → 意见反馈」留言。
```

## 二、离线回复（客服不在线时自动发送）

```
您好，现在不在线，看到消息会尽快回复。
急的话可以先在「我的 → 意见反馈」里留言，同样会有人看。
```

## 三、关键词自动回复（按关键词匹配，逐条添加）

### 1. 关键词：`退款` `退钱` `退`
```
退款分两种：安卓/鸿蒙订单可联系我们处理（7 天内未使用可全额退）；苹果内购订单需您在 App Store「报告问题」里申请，我方无法代为操作。退款成功后，对应报告访问权会一并收回。
```

### 2. 关键词：`发票` `开票` `凭证`
```
当前为内测阶段，暂不支持自动开票。您把订单号留在这里，我们统一登记处理。
```

### 3. 关键词：`怎么用` `使用` `教程` `不会用`
```
四步上手：① 首页顶部建店铺 ② 进「月度盈利核算」录一个月账 ③ 进「菜品成本毛利核算」建菜品卡 ④ 进「经营盈亏沙盘」算保本营业额。
详细说明在「我的 → 使用指引」。
```

### 4. 关键词：`导入` `excel` `表格` `报错`
```
导入方法：堂食进收银系统后台导出「菜品销售统计」；外卖导出「商品销量」表。
如果找不到对应报表，按导入页给的三列模板自己做一张 Excel，一样能算。具体路径见导入页说明。
```

### 5. 关键词：`美团` `京东` `外卖平台`
```
目前外卖导入支持淘宝闪购和其他平台的通用表。美团、京东的报表口径常与账单对不上，暂未做专门适配。用通用 Excel 模板导入，效果一样。
```

### 6. 关键词：`有效期` `到期` `权益` `换了手机` `换微信`
```
权益按微信号计算：一个微信号一份额度，换微信号不迁移，同一店铺多个员工不共享。
有效期在「我的 → 我的订单 / 有效期」查看。
```

### 7. 关键词：`隐私` `数据安全` `删除` `注销`
```
您的经营数据只存在您自己账号下（微信云开发，境内），不向任何第三方提供。
注销账号后，经营数据会在 15 天内彻底删除；支付记录按法规保留 3 年。
```

### 8. 关键词：`收费` `多少钱` `价格` `开通` `付费`
```
当前为内测阶段，相关功能暂未开放。开放后会在小程序内公告，不会在会话里单独收款。
```
> ⚠️ 提审期内核：不要说价格、不要引导私下转账（会被判"诱导交易"）。

### 9. 关键词：`算错` `不准` `数字不对` `结果不对`
```
计算结果来自您录入的数据，某一项填错会连带结果偏。请您告诉我具体是哪一项、哪个数字，或发张截图，我帮您看是哪一步的口径问题。
```
> ⚠️ 不承诺"帮您改数据"——客服改不了，承诺了反而失信。

### 10. 关键词：`客服` `人工`
```
您已经在和我对话了 🙂 请把问题说具体些（哪一步、什么现象），我这边直接答。
```

## 四、快捷回复（手动一键发送，放在工作台"快捷回复"里）

| 场景 | 文案 |
|---|---|
| 收到反馈后确认 | `收到，我记下了。如果是能复现的问题，会尽快修；如果是数据口径问题，我告诉您怎么调整。` |
| 需要用户补信息 | `麻烦补一下：①手机型号 ②在哪一步 ③看到什么提示（有截图最好）。` |
| 转人工/升级 | `这个我需要核对后回复您，最迟明天给您答复。` |

## 五、配置位置速查

| 端 | 路径 |
|---|---|
| 手机 | 微信搜「**小程序客服助手**」→ 进入「餐饮智算」→ 开消息提醒 → 状态设「在线」→ 设置里配自动回复 |
| 网页 | `mpkf.weixin.qq.com` → **客服本人微信扫码** → 设置 → 欢迎语 / 关键词回复 / 离线回复 / 快捷回复 |

> 🔴 官方硬限制：人工**48 小时内回复、用户发消息后最多 5 条**，无法取消。
> 所以自动回复不是"锦上添花"，是**补空窗的必需品**。
