## 一、发现

`utils/takeawayDerive.js`：
```js
const qty = Number(it && it.qty) || 0;   // items
const lineAmount = priceFen * qty;
const lineCost   = costFen * qty;
// packs:
const qty = Number(pk && pk.qty) || 0;
total += upf * qty;
```

份数填「1,000 / １０ / 1 0」→ `NaN` → `|| 0` → **qty=0** → 该行收入与成本都变 0。
与成本卡用量（R597）的区别：**行还在结果里**（qty=0、金额 0），不是整行消失；但仍会少算该单收入/成本，且无任何提示。
