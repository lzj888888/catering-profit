## 0 会诊定了三件事，方案必须照办

| 会诊结论 | 对方案的约束 |
|---|---|
| 现有数据只能算「耗用比标准多了多少」，**不能直接叫"浪费"** | 必须把「正常损耗」从「异常」里剥出来，否则冤枉人 |
| **非销售耗用不剔除，会把正常经营损耗当舞弊** | 这是最高优先级缺口 |

## 1 老板最终看到的应该是一张「损耗体检单」

目标形态（不是一堆数字，是一句话结论 + 要查什么）：

```
本月食材账
  按你卖的菜，本该用掉        ¥12,000
  账上实际用掉（期初+采购−期末） ¥17,000
  ────────────────────────────
  差额                        +¥5,000
  减去：员工餐/试吃/报损        −¥800
  ────────────────────────────
  真正说不清的                +¥4,200   ← 要查这个
```

**为什么必须拆这一步**：老板开门做生意，员工餐、试菜、报废一定存在。
不扣掉，这 800 元会被算成"浪费"，等于**系统在说他在被偷**——这是会诊里豆包点出的致命漏洞。

## 2 分两期执行（每期都能独立交付价值）

### 第一期（本轮执行）· 把「差额」拆干净
- 增加**非销售耗用**输入（员工餐 / 试吃 / 报损，一个金额）
- 输出「真正说不清的金额」
- **不碰云函数、不需要部署**（存本地按月，与库存页草稿同机制）
- 门槛沿用现有（覆盖率 + 三栏非空），结论口径不改

### 第二期（下一轮）· 定位到具体原料
- 5~8 个高值原料：**采购数量 + 期末盘存数量**
- 输出：每个原料「理论用量 vs 实际用量」偏差率
- 需要改 `shop_inventory` 字段 + 云函数 → 要部署窗口

### 第三期 · 单价留痕
- `shop_material.purchase_price` 从「覆盖式」改「留痕式」
- 实现单价异动提醒（查回扣）
- ⚠️ 会诊明确：**没有入库数量，单价留痕无效**，所以排第三

## 3 第一期的具体设计

### 3.1 非销售耗用怎么填（关键：口径必须说清）

**只算「用店里食材做的」，不算「发给员工的现金餐补」。**

| 要算 | 不算 |
|---|---|
| 员工在店里吃饭用掉的食材 | 每月发 300 元餐补（那在人工费用里） |
| 试菜/研发用掉的食材 | 请客人吃饭（那是招待费） |
| 变质报废扔掉的食材 | 外部采购的盒饭 |

**为什么强调**：支出科目里已有「员工餐」（`TERMS.ledger.expense` labor 组），
但它记的是**费用**（可能是现金补贴），而这里要的是**被吃掉的食材成本**。
直接挪用会重复/错位，所以**单独输入，并写明口径**。

### 3.2 存哪里（不碰云函数）

- 按月存本地：`wx.setStorageSync('nonsales_' + shopId + '_' + month, fen)`
- 理由：不改云函数 = 不用部署 = 上线前零风险
- 代价：换手机/重装会丢，下次要重填（可接受，因为算账是低频动作）
- 第二期做进云函数时再迁

### 3.3 输出口径（必须标明"说不清"而不是"浪费"）

| 显示 | 不显示 |
|---|---|
| 真正说不清的 | 浪费/损失/被偷 |
| 建议核查：员工餐与报损是否漏填 | 你的员工在偷东西 |

会诊共识：**产品一律说"异常，建议核查"，不做定性**。

### 4.1 🔴 本轮实际踩到并修掉的两个坑

**坑 1：切月份不读回 → 输入框显示上月数、计算却用 0**
`onMonthChange` 原来只调 `calc(month, savedDishCount)`，不重读该月的非销售耗用。
⇒ 抽出 `loadNonsales(month)` 统一读取，`onMonthChange` 必须调它。
**这类纯函数 selftest 抓不到**，所以补了 5 条**源码级接线断言**（读页面源码判正则）：
① 切月必须调 `loadNonsales` ② 计算必须传 `nonsalesFen` ③ 输入框必须绑 `onNonsales`
④ 必须走 `ss.shopKey`（按店隔离，不能裸 key）⑤ 反恒真：不传参的写法必须被判红。

**坑 2：用 node 脚本改 wxml 时把属性引号吃掉了**
`<view class="field">` 被写成 `<view class=field>` —— 而 `check_wxml_structure` **照旧判绿**（它不查属性引号）。
⇒ 已用 Edit 精确修复，并额外用 `grep -nE '(class|wx:if|bindtap|bindinput|value|placeholder|type)=[^"]'` 全量复扫确认为空。
**教训：改 wxml 一律用 Edit，不要用 node 字符串替换（引号层数太多）；改完必须扫一次"无引号属性"。**

## 5 诚实边界（写进页面文案）

1. 这一步**只是把账算干净**，不能告诉你"被偷了"还是"浪费了"
2. 若月末库存是**估的**，全部结论都不可信（页面已提示"请确认为实际盘点"）
3. **成分原料看不出来**——要等第二期加数量维度
4. 非销售耗用是**老板自己估的**，估小了"说不清的"就变大，估大了就变小
