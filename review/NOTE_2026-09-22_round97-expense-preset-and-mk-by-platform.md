## §2 T2 为什么证伪，T1 的设计为什么是这三层

### T2（快速模式自动带出外卖活动补贴）——**数学上不成立**

- `utils/takeaway.js::syncSubsidyCarry` 首行即 `if (this.data.takeoutMode !== 'detail') return;`（`input.js:783`）
  ⇒ **补贴源只在分项模式**；快速模式用户只填「每平台一个总额」，**根本没有补贴数据**。
- A.11.4 的配平等式**依赖 `subsidy`**（`utils/takeaway.js:249`）⇒ 在快速模式硬套，等式右侧恒为 0 而左侧有值
  ⇒ **稳定误报**（不是偶发，是必然）。
- ⇒ 结论：**不是「没做」，是「做不了」**。把限制做成需求 = T3′（零依赖判据）。

### T1 的三层设计（李老师原意：收入侧分 4 平台、费用侧却要人工把 4 份账单加起来）

| 层 | 规则 | 判据承载 |
|---|---|---|
| ① **只回显不入库** | 小计区是**录入加速器**，入库仍只有一个佣金数，不动库结构与会计口径 | `batch8b A6-⑥`：`buildItems` 不含 `twMkByPlat` |
| ② **接管即转只读** | 任一平台填过 ⇒ 把合计**就地写进**佣金行，且该行金额框 `disabled`（两个来源不打架） | `batch8b A6-⑥`：`twMkByPlatActive && gi === twMkRowGi && ri === twMkRowRi` |
| ③ 🔴 **全空一个字都不碰那一行** | **第一红线**：一进页面小计区必然是空的，若判「填过」⇒ 每次进页都会把库里已存的佣金清零 | `r85 A25` 三条边界 + `A25 页面` 早退 |

- 纯函数 `mkByPlatFilled(list)` 承载第 ③ 条：`String(v ?? '').trim() !== ''` ⇒ 填 `0` **算填过**、空串/未填**不算**。
  实测边界：`[]` → `false`、全空 → `false`、`'0'` → `true`；`mkByPlatTotal([10,20.5,'',5])` = **35.5**。
- 平台名单源 = `takeoutPlatforms()`（与收入侧同一单源），进出页面 / 切模式**按名回填** ⇒ 不丢值。
- 装配走 `decorateRows(g, rows)` **同一装配口**（`input.js:475`），不新增第三套。

## §5 本轮新入册的坑（5 条）

1. 🔴 **node `execSync` 在 Windows 上走 `cmd.exe`，而 `^` 在 cmd 里是转义符**
   ⇒ `node -e "execSync('git show 7d3960e^:path')"` **静默**变成 `git show 7d3960e:path`
   ⇒ **拿提交自己跟自己比**，得出「两版一模一样、没有变化」的**错误结论**（我本轮真踩了，先误判「T4 没加那 3 项」）。
   **处置**：取历史版本一律走 **python `subprocess`（不经 shell）**，或先 `git rev-parse REV^` 落到 sha 再用。
2. 🔴 **门禁入口在仓根 `verify_all.js`**（第 2 行自己写着「运行：node verify_all.js」），**不在 `tools/` 下**。
   写成 `tools/verify_all.js` ⇒ 19 行 `MODULE_NOT_FOUND`；而 `> review/evidence/gate_*.txt` 是**覆盖式重定向**
   ⇒ **把上一份真证据冲掉**。**处置**：跑门禁后**先看行数与 RC**，别默认「文件在 = 跑过了」。
3. 🔴 **「在锚点行之后插入」的脚本语义，被误用于「结构性边界行」**（段落标题 / 声明行 / 单行数据）
   ⇒ 或**静默截断段落**（R66 判红）、或**静默拆行**（断言数守卫判红）。**处置**：改「数 / 标题」一律用**就地替换**，
   插入前先问「这个锚点是不是结构边界」。
4. 🟡 **新写 wxss 字号必须 ≥28rpx**（AD 铁律，`selftest_ad_gates` G1 守卫，0 残留）。本轮我犯了一次，被当场抓住。
5. 🟡 **`{{t.xxx}}` 取自 `input.js` 的 `data.t` 映射** ⇒ 新增可见文案**必须三处同步**
   （`terms.js` + `specs` 镜像 + **`data.t` 映射**）。只改前两处会渲染**空串**，而 K11 只比双副本一致、
   **不管消费者**（`A6-②` 就是为这条补的判据）。
