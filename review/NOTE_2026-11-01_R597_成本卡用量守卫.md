## 一、怎么发现的

前几轮扫的是"金额/转分"面（`yuanToFen`、`Number(v)||0`）。本轮扫**数量/用量**面：
`Number(qty)` → `units.toBase()` → `if (!(qtyBase > 0)) continue;`。

## 二、为什么是真漏网

`utils/units.js::toBase()`：
```js
const n = Number(qty);
if (!isFinite(n)) return 0;   // 「1,000」→ NaN → 0
```
`card/edit.js::buildCalcLines()`：
```js
if (!l.qty) continue;
const qtyBase = units.toBase(l.qty, l.qty_unit);
if (!(qtyBase > 0)) continue;   // ← 读不成的用量：整行被静默跳过
```

后果：用量填「1,000」「１０００」「1 000」⇒ 那一行**不参与成本计算** ⇒ 成本少算、毛利虚高。
提示只在整个 `out.length === 0`（所有行都被跳过）时才出现 ⇒ **只要还有一行正常，坏行就无声消失**。

套餐子卡同理：`comboLines[].qty` 走 `Number(l.qty) || 0`，读不成 ⇒ `continue` 跳过该子卡 ⇒ 套餐成本少算。

与 R595 矩阵「档位被静默跳过」同族：不是按 0 参与计算，而是**整条记录消失**。
