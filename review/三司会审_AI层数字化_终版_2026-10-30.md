# 三司会诊 · AI 层 + 餐饮常见问题数字化 — 可行性与方案（终版）
> 2026-10-30 · workbuddy + 豆包（直连桥）+ DeepSeek（API 直连，本轮首次参与成功）
> 输入材料：豆包对话「店算小程序 AI价值判断」观点汇总（剑哥聊餐饮→知识库→常见问题题库→轻智库路线）
> 附：`豆包对话观点汇总_店算AI价值判断_2026-10-30.md` / `doubao_会审_AI层数字化.md` / `deepseek_会审_AI层数字化.md`

## 一句话总结
**三司一致：现在就能做，且必须"规则引擎先行、LLM 只做受控润色"——AI 层本质是给 M1/M2/M3 的锁定数字配一个"说人话、指方向"的诊断层，不是做聊天机器人。**

## 一、可行性（workbuddy ✅ / 豆包 ✅ / DeepSeek ✅ 三方一致）
- 底座已齐：M1/M2/M3 锁定口径输出 + `anomalyRules` 版本化规则范式 + `aiGate` 四态授权闸门 + `cx_indicatorRef` 分业态参考带。缺的只是「结论层」，不缺模型。
- 两大风险（豆包 & DeepSeek 各自独立点出，完全重合）：
  1. **口径漂移**：LLM 一"顺手补个行业均值/损失金额"就破坏"数字可复现"口碑 → 必须物理隔离数字来源。
  2. **合规/数据出境**：接模型即触发经营数据出境，必须走 `aiGate` 授权四态，fail-closed（无授权→纯规则输出，完整可用，不得用 AI 胁迫授权）。

## 二、架构（三司同构）
```
M1/M2/M3 锁定口径数值（DTO：指标ID/值/期间/业态/库存场景/口径版本）
  → diagnosisRules 规则匹配（纯函数，版本化，复用 anomalyRules 范式）
  → 模板渲染（结论句 + 数字占位符全部来自单源 + 边界声明）
  → [可选，付费+授权后] LLM 润色：只做措辞同义改写
       数值白名单校验：出现模板外数字 → 整段丢弃回退模板（fail-closed）
  → 输出三层：诊断定性 → 可控动作 → 工具测算入口（M2 沙盘/M3 四象限）
```
- **数字唯一解释权归规则引擎**；LLM 只是"表达润色"，不参与计算、不许新增任何数值。
- 无 LLM 也能完整跑通；LLM 开关默认关。留痕：规则版本、命中规则、授权状态、模型版本。

## 三、第一期（1–2 周，MVP）
**做：** 指标字典 + `diagnosisRules` schema（JSON 配置化、版本化可回滚）+ M1 结果页诊断卡 + 跳转 M2/M3 + 边界声明 + **首批 5–8 条规则**：
| # | 规则 | 判定依据（全部现有数据） | 联动 |
|---|---|---|---|
| 1 | 结构性营收不足 vs 原生流量不足 | GPC（客单价×销售毛利率）vs 每客固定成本（M2 平衡客流） | M2 沙盘 |
| 2 | 利润负向归因 | 毛利正/净利负 → 固定成本或规模；毛利负 → 成本或定价结构 | M1 |
| 3 | 毛利率本店历史异常 | 只比本店历史中位数（复用 anomalyRules，minHistoryMonths=2 fail-closed） | M1 |
| 4 | 盈亏平衡缺口 | M2 反算差额，定性"差在量还是差在价" | M2 |
| 5 | 菜品四象限失衡 | M3 高销低利/低销高利占比（只定性，不报损失额） | M3 |
| 6 | 外卖渠道侵蚀 | 渠道扣点后单均毛利 vs 堂食（BOM 缺失则不判定） | M3 渠道层 |
| 7 | 库存双口径差异提示 | 库存开/关双场景利润并列展示，禁选一个当"真实利润" | M1 口径锁 |
| 8 | （可选）储值/现金流录入提示 | 只提示录入，不判定 | M1 |

**明确不做（三司一致的排除清单）：** 聊天/多轮问答、RAG/向量库、博主观点入库、跨店聚合 chainMerge、扩张/撤店/选址自动结论（只给清单+测算入口）、"保证提升客流/利润"类表达、复购/淡旺季/储值必填化、任何新指标采集。

## 四、商业模式咬合（三司收敛）
- **免费层**：常见问题题库入口、定性结论 + 边界声明、单条最高优先级提示、M2 矩阵导出（有意免费，不动）。
- **付费层**：M1 完整利润解读、套餐/外卖/全菜单诊断、M3 毛利榜、动作清单与数字推演（与现有付费墙同一刀口，不开旁路）。
- **LLM 润色不单独收费**（避免"为措辞付费"观感），放在付费报告内作体验增强；拒绝授权不影响算账核心。
- **咬合原则（DeepSeek 提出，workbuddy 采纳）**：AI 层只做"指路牌"；一条合格规则 = 免费定性能自然导向一个付费动作。
