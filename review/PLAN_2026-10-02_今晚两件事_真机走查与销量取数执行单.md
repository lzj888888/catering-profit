## B. 销量样例（阶段② 的前置 · 堂食 + 外卖各 1~2 份）

**一句话**：要的是**菜品级销量表**（有菜名 + 卖了多少份），**不是**结算账单 —— 你之前给的美团/淘宝闪购账单**不含菜名**，已核实过（证据 `review/evidence/r183_m331_gap/probe_r183_billcols.out.txt`）。

### B-1 堂食（✅ 你确认本店用**美团收银 / 美团管家**）

后台 `https://pos.meituan.com/`，**必须 PC 端才导得出**（POS 端和手机 APP 只能看）。

| 要什么 | 路径 |
|---|---|
| **① 菜品销售统计**（单品+套餐合计） | 报表中心 → 菜品报表 → 菜品销售统计 → 选日期 → 查询 → **导出** |
| **② 单品销售统计** | 报表中心 → 菜品报表 → 单品销售统计 → 查询 → **导出** |
| 🔴 **③ 套餐销售统计**（最关键的，外卖卖爆的常是套餐） | 报表中心 → 菜品报表 → 套餐销售统计 → 统计方式选「**套餐明细**」→ 查询 → **导出** |

> ①②③ 都给最好；**至少要 ①+③**。

### B-2 外卖（美团 / 饿了么 / 淘宝闪购商家后台）

- 商家后台 → 经营/数据 → **商品销售明细 / 菜品销量** → 选日期 → **导出**。
- 🔴 要**含套餐**的那份（套餐在外卖占比高，漏了它单品毛利排名会看不懂）。

### B-3 四条注意（照做省一次返工）

1. **统计方式「套餐明细」必须选** —— 选「套餐」只给套餐整体销量，出不来套餐内的子菜品。
2. **导出前清一遍筛选残留**（营业日期 / 菜品分类 / **销售方式：单品 or 套餐**）—— 残留会让数目对不上。
3. 导出的**日期区间选一整个月**（或最近 30 天），别只导一天 —— 单天样本没法算单品毛利复盘。
4. 份数：**1~2 份就够**（同一后台模板统一，摸一份通吃一类），**不是越多越好**。
5. 🟢 **导不出就用截图**：我要的是**表头长什么样 + 行结构**（几行表头 / 有无标题行·小计行·合计行 / 规格是否独立行 / 多 sheet / 日期格式），
   **金额和份数可以全 0 或脱敏** —— 实在导不出，**把后台那个报表页面截几张图发我就够**（能看清列名和前几行即可）。
   （🔴 缺的是**结构**不是数据；列「名」不用你猜，映射是我这边做、由你点选。）
