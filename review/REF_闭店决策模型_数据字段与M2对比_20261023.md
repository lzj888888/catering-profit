## 一、它采集什么（6 节 40+ 字段）

### 1 基本信息（7）
店名 / **业态** / **城市层级** / 经营面积(㎡) / 餐位数 / **开业时长(月)** / 主营模式

### 2 财务数据（近 3 个月平均，元/月）
| 字段 | 口径 |
|---|---|
| 月营业收入 | 含外卖实收 |
| 食材/原料成本 | 进货成本含损耗 |
| 人工成本 | 后厨+前厅+店长+社保奖金 |
| 房租 | 含物业，季付/年付折算月均 |
| 水电燃气 | 月均 |
| 营销/平台抽佣及杂费 | 推广费+平台佣金+耗材 |
| 折旧摊销与其他固定 | 装修/设备分摊+加盟管理费 |
| 月净利（自动） | 营收−各项成本，负数为失血 |
| 净利率（自动） | 净利/营收 |
| **连续亏损月数** | 从最近一次单月转正后算起 |
| **账面可动用现金** | 活期+备用金 |
| **月刚性现金支出（自动）** | 人工+房租+水电 = 最低存活线 |
| **现金可撑月数（自动）** | 账面现金 ÷ 月刚性支出 |

### 3 经营与口碑（9）
日均客流 / 客单价 / 估算营收校验（客流×客单×30 与营收对账）/ **近 3 月客流同比变化** / 营收趋势 / 综合评分(5 分制) / 差评投诉趋势 / **外卖占比** / 会员复购

### 4 市场与合同（6）
**剩余租期(月)** / 下次续租预期涨幅 / 周边人流变化 / 同品类竞争变化 / 周边施工撤店拆迁 / 商场街区空置情况

### 5 风险信号（4）
**借贷/垫资维持程度** / 食安处罚或重大客诉 / 核心人员稳定性 / 老板投入度

### 6 本店适用基准（自动，按业态×城市切换）
食材成本率健康上限/红线、人工成本率警戒、房租负担警戒……

## 二、它怎么评（11 项加权 100 分 + 6 条红线一票否决）

| # | 维度 | 权重 | 得分规则（摘要） |
|---|---|---|---|
| 1 | 盈利能力(净利率) | **15** | ≤−5% 得 0；−5%~12% 线性；≥12% 得 100 |
| 2 | 亏损持续性 | 10 | 0 月得 100；超可扛上限后每多 1 月递减 |
| 3 | **现金流(现金可撑月数)** | **15** | <1 个月刚性支出得 0（红线）；≥安全下限得 100 |
| 4 | 客流与营收趋势 | 10 | 客流同比 ≥0 得 100；达下滑警戒得 20 |
| 5 | 食材成本率 | 8 | ≤健康上限 100；超红线降 0 |
| 6 | 人工成本率 | 7 | ≤警戒 100；超 2 倍警戒降 0 |
| 7 | 房租负担 | 10 | 按城市调整警戒，超警戒线性降 |
| 8 | 口碑与差评 | 5 | 4.8 以下线性；差评恶化 −20/略增 −8/改善 + |
| 9 | 商圈与竞争环境 | **10** | 人流：增长 100/平稳 85/小降 70/明显降 45/**结构性流失 0** |
| 10 | 租约稳定性 | 5 | 剩余 ≥24 月 100；<3 月 … |
| 11 | 资金链独立性 | 5 | 无借贷 100；少量 60；大量持续 10 |

**6 条红线（命中任一 ⇒ 直接"必须闭店/立即止损"）**
- R1 **现金枯竭**：现金可撑 <1 个月刚性支出
- R2 **长期亏损仍失血**：超可撑上限且当前净利率 ≤0
- R3 **商圈结构性流失**：人流结构性流失 / 拆迁封路 / 商场明显空置
- R4 **食安重大事件**
- R5 **借贷输血失控**：大量且持续，且现金 <3 个月刚性支出
- R6 **租约断崖**：租期 ≤3 月 + 续租涨 ≥20% + 当前仍亏损

## 三、M2 现在覆盖了哪些（对比）

| 维度 | 权重 | M2 现状 |
|---|---|---|
| 盈利能力 | 15 | ✅ 有（毛利/利润/保本额） |
| 食材成本率 | 8 | ✅ 有（食材内嵌在毛利率里） |
| 人工成本率 | 7 | ✅ 有（人工合计/人数×工资 + 指标带） |
| 房租负担 | 10 | ✅ 有（房租 + 城市系数 + 指标带） |
| **现金流（可撑月数）** | **15** | ❌ **完全没有** |
| **亏损持续性** | 10 | ❌ 无（M1 有月度账，但没"连续亏几个月"这个判据） |
| **客流与营收趋势** | 10 | ❌ 无（有客单价，无客流、无同比） |
| **商圈与竞争** | **10** | ❌ 无 |
| **租约稳定性** | 5 | ❌ 无 |
| **资金链独立性** | 5 | ❌ 无 |
| **口碑差评** | 5 | ❌ 无 |

⇒ **M2 覆盖约 40 分权重，缺 55+ 分**——而且缺的**全是"能不能活下去"的维度**。

## 四、结论：这是定位问题，不是字段问题

> **M2 回答的是「这家店能不能开（要卖多少才保本）」；**
> **这份模型回答的是「这家店还能不能撑下去（该止损还是续命）」。**

两者是**两种不同的决策**，字段重叠但结论不同：

| | 开店测算（M2 现状） | 存活诊断（该模型） |
|---|---|---|
| 输入 | 预估的数（面积/房租/目标） | **真实经营 3 个月 + 现金 + 趋势 + 商圈** |
| 输出 | 保本营业额 / 预计利润 | **11 项评分 + 红线 + 继续/止损结论** |
| 时机 | 开店前 | 已在经营、且在亏 |

## 五、我的建议（按"最刚需"排序）

| # | 加什么 | 为什么它最刚需 | 成本 |
|---|---|---|---|
| **1** | **现金可撑月数**（账面现金 ÷ 月刚性支出） | 老板最怕的不是亏，是"下个月工资发不出"。这一项**不需要任何历史数据**，填 2 个数就出来 | 小（2 个输入 + 1 个除法） |
| 2 | **连续亏损月数**（M1 已有月度账，可直接算） | 决定"是波动还是趋势" | 中（要读历史月份） |
| 3 | **剩余租期 + 续租涨幅** | 决定"能不能撑到转机" | 小（2 个输入） |
| 4 | 客流同比 / 营收趋势 | 判断"在恶化还是在好转" | 中（要比较期） |
| 5 | 商圈变化（结构性流失） | 这是"努力也没用"的唯一情形 | 小（下拉） |

**红线机制值得直接照搬**：6 条红线一票否决，比"打 60 分但不知道该怎么办"有用得多。

**但要注意定位冲突**：M2 现在是"免费引流工具"。加"闭店诊断"要么：
- (a) 并进 M1（月度盈利 → 经营体检，有真实数据）
- (b) M2 新增一个「我已在经营」入口（和"想开店"并列）

**(a) 更顺**：M1 本来就是"月度账"，躺着就有 3 个月数据；M2 的"想开店"场景没有现金和趋势。
