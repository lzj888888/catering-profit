# A6 · B2 前置调研 —— 美团 / 淘宝开放平台的「主体资质」到底卡在哪

> 2026-09-30 立。定位：把 B2（唯一剩下的对外阻塞）**收窄成李老师照抄即可问的一句话**，

## 一、原始问题（B2 原样）

> 个体工商户能否接美团 / 淘宝开放平台 OAuth，拿**自己店铺**的销量数据？

## 二、结论（一句话）

🔴 **「拿自己店铺的外卖订单/销量」这条官方 API 路，对单店/个体户基本是关的** ——
美团外卖侧要求**连锁品牌（门店 ≥30 家 且 日订单 ≥1000 单）+ 软著**，且**官方明写"暂不提供个人开发者对接"**；
淘宝侧 ISV **明确不接受个体工商户**、商家后台系统**仅面向天猫商家**。

🟢 **但出现一条新通道值得实测**：美团技术服务合作中心主站（`developer.meituan.com`）现挂出
**「个人开发者入驻 · 实名认证即开通 · 免费接入 MCP/Skills · <5 分钟」** ——
这是 2026 年新增的入口，**能否授权访问自己门店的订单/销量，官方文档未写明，必须实测/问清**。

## 三、三条通道门槛对照（美团外卖侧）

| 通道 | 主体要求 | 硬门槛 | 能拿什么 | 出处 |
|---|---|---|---|---|
| **连锁品牌商**（自研/委托开发） | **企业**营业执照（须与美团签约主体相符） | **门店 ≥30 家 且 日订单 ≥1000 单**；+ 产品说明书 + **软著证书** | 自己品牌旗下门店的订单/商品/配送 | `developer.waimai.meituan.com/home/guide/3` |
| **三方服务商（ISV）** | **企业** + 独立技术团队 | **Web 应用防火墙** 或 **等保证明（二级+）** 至少一项；+ 官网 + 技术合作合同；部分接口缴保证金 | 取得商家授权后的多商家数据 | `developer.meituan.com/newSettleIn` |
| **个人开发者**（新增） | **个人实名**（手机号 + 身份证） | 无（<5 分钟） | 「接入 MCP / Skills，美团**本地生活数据**服务」—— **是否含商家私有订单：未写明** | `developer.meituan.com/?id=19` |

⚠️ **同一主站两条口径不一致**：外卖子站明写「**暂不提供个人开发者的对接服务**」，
主站首页却挂「个人开发者入驻」。⇒ 极可能是**面向 AI/公开数据的 MCP 通道**，与**商家订单数据**不是一回事。
**这一点必须问清，不能自己推断。**

## 四、淘宝侧（含淘宝闪购）

| 通道 | 主体要求 | 硬门槛 | 说明 |
|---|---|---|---|
| **服务市场 ISV** | 🔴 **企业**（有限责任公司/股份公司）；**个体工商户通常不通过** | 企业支付宝 + **软著** + 保证金 1~5 万 + 经营范围含软件开发/信息技术服务 | 第三方服务商路 |
| **商家后台系统** | 🔴 **仅面向天猫商家** | 入驻**聚石塔** + 企业支付宝 + 软著 + IT 团队信息 | 单店/淘宝集市卖家**不可** |
| **个人开发者** | 个人/个体工商户可注册 | **仅基础权限**；交易类 API（订单查询等）**需企业资质 + 信用审核** + 保证金 | 注册容易、**数据权限拿不到** |

## 五、对项目的影响（关键判断）

🔴 **B2 若为负，不阻塞项目路线** —— 因为规范层早已给出**不依赖官方 API 的替代路径**：

1. **M3.33 菜品毛利复盘（v1.2 §M3.33）**：销量来源**不必是 M1**，可以是
   **用户自己从收银/外卖平台后台导出的销售表**（Excel 导入）⇒ 复盘从"做不了"变成"能做"，
   **不用等任何开放平台资质**。规范里这条正是为这种情形准备的（"销量来源不必是 M1"）。
2. **M3.17 外卖单均（本批已在投喂）**：一单 = 卡/套餐 + 包材 + 平台参数，**手动录入即可算**，
   完全不依赖 API。
3. **R174 入站预留**（`external_sales_daily` / `shop_dish_mapping`）是**接口缝**，不是承诺；
   通道打不通时它保持空集合即可（当前就是"计划新增、尚未落库"以外的独立空集合）。

⇒ **结论：官方 API 是"锦上添花"，不是"堵路石"。** 真正该做的是把**导出表导入**打通（M3.33），
这条路**零资质门槛、当月就能用**。

## 六、照抄即可问的一句话（给李老师）

> **问美团技术服务合作中心（`developer.meituan.com` → 右下角「咨询」/提交工单）：**
>
> 您好，我是**单店餐饮商户**，想通过开放平台把**我自己门店**的外卖订单与销量数据同步到我自己的记账系统
> （**只用自己店铺的数据，不对外提供服务、不做第三方 SaaS**）。请问：
> ① 我这种情形该走哪个通道（个人开发者 / 服务商 / 连锁品牌）？
> ② **个人开发者通道能否授权访问自己店铺的订单/销量数据**？能的话走哪个应用类型、哪些权限包？
> ③ 若必须企业主体，**个体工商户是否可以**？（外卖子站写明"暂不提供个人开发者对接"，主站却有个人开发者入口，想确认二者区别）

> **问淘宝开放平台（`open.taobao.com` 工单/客服）：**
>
> 您好，我是**个体工商户**，只想在自己店铺范围内自动同步自己店铺的交易/销量数据到自有系统，
> 不做第三方服务。请问**个体工商户能否申请交易类 API 权限**？若不能，是否有面向商家自用的通道？

## 七、未核实 / 存疑（如实标注）

- ❓ **美团主站「个人开发者」通道的实际能力边界**：官方只写"接入 MCP/Skills，本地生活数据服务"，
  **未说明是否含商家私有订单**。本文**不推断**，标为待实测。
- ❓ 三条通道的**费率/保证金具体金额**未逐一核实（与本次判定无关）。
- ❓ 淘宝侧"个体户不接受"的来源含**非官方二手文章**（`diantuoyi.com`、`mhpq.cn`），
  官方页面（`open.taobao.com/businessDetail.htm`）只对"商家后台系统"明确写"仅天猫商家"。
  ⇒ **个体户能否入驻 ISV 应以工单答复为准**。
- ❓ 各平台规则**随时调整**（美团外卖子站页面无日期）；正式决策前建议再核一次官方页面。
