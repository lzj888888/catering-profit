## 第 1 条 · 建一道菜，看三个"自己动"

**怎么走**：配方 → 菜品成本毛利 → 新增 → 填菜名 → 加一行料（选原料或填临时原料名+单价+用量）

**该看到三件**
1. 停手约 1 秒，底部横条的成本/毛利率**自己变**（不用点任何按钮）
2. 没填完时，横条会说**缺哪一个数**：「先加一行配料」/「第 2 行还差用量」/「配料齐了，填上售价就能看毛利」
3. 填上售价后保存 → 弹窗里有：成本 / 毛利 / 毛利率 + **「在你 N 道菜里排第 K」**

**不对的样子**
- 数字一直不动 → 自动重算没生效
- 每打一个字就闪 → 刷新太快（要调长）
- 点了「添加」但还没填的空行，报「第 1 行还差用量」→ 空行判据错（设计上不允许）
- 只有一张卡却显示排名 → 应该不显示
- 排名与列表实际高低不符 → 截断保护失效

## 第 2 条 · 一百张卡怎么找（置顶 + 搜索）

**怎么走**：成本卡列表 → 点某张卡名字后面的**淡色「置顶」小标签** → 再在搜索框输「牛肉」

**该看到**
1. 点完，那张卡**跳到最前面**，标签变深色「**已置顶**」
2. 再点一下能取消
3. 搜索「牛肉」能搜出**分类或标签**含牛肉的菜（不只是名字里有的）
4. 点标签**不会**误跳进编辑页

**不对的样子**
- 点标签直接进了编辑页 → 冒泡没拦住
- 标签点了没反应 → 置顶没接上
- 只能搜菜名 → 搜索面没扩上

## 第 4 条 · 导入一张缺列的表，看它说不说缺什么

**怎么走**：渠道营收 → 导入 → 传一张**故意缺列**的表（只有日期和总额，没有现金/扫码两列）

**该看到**
- 弹窗**不是**那句通用的「这张看着不像你记的收款日报」就完事
- 而是明确说：**缺：现金收款、扫码收款** + **表里读到这些列：…**
- 若商品挤在一列，会指名是哪一列，并教您按逗号分列

**不对的样子**：还是那句通用话 → 诊断没接上

## 第 5 条 · 团购价是否已从菜品卡移走

**怎么走**：成本卡 → 打开任一菜 → 切到「**专业**」模式（或点「更多」）→ 找团购相关

**该看到**
- 菜品卡上**没有任何团购价 / 佣金率 / 推广费输入框**
- 只有一行蓝字：「**要算这个上团购到手多少？去团购页算**」，点了能跳到团购页
- 团购页里能选卡 + 填团购价 + 填佣金率 + 出手

**不对的样子**：专业模式下还能填团购价 → 移除没生效
