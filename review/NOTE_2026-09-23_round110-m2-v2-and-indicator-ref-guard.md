## 2 三条口径裁定（关键，都是"填错会算错钱"的地方）

**① 两类输入的分野 = 「每月固定」填金额 vs 「跟营业额挂钩」填占比。**
若把外卖佣金这类**按营业额抽成**的项按"每月固定金额"填，它会**全额进固定成本** ⇒ 保本点被算低、结论偏乐观。
故契约层把两者分开：`fixed_items[{key,fen}]` / `var_items[{key,pct}]`，校验层 `validate.js` 各自白名单（枚举**从单源取**，不手抄）。

**② 城市系数只调"有据可依"的两项。**

## 4 M2 公式 v2（与 v1 的差异）

```
月摊销         = Σ(建店投入_i ÷ (年限_i × 12))        ← 逐项高精度求和，仅最后一步取整到分
固定成本合计   = Σ 每月固定支出 + 月摊销
食材成本率     = 100 − 菜品毛利率
综合变动成本率 = 食材成本率 + Σ 跟营业额挂钩费率
边际贡献率     = 1 − 综合变动成本率 ÷ 100
保本月营业额   = 固定成本合计 ÷ 边际贡献率
保本日均       = 保本月营业额 ÷ 30                    ← 固定÷30，不按当月实际天数
目标利润月营收 = (固定成本合计 + 目标利润) ÷ 边际贡献率
收回投入(月)   = 建店总投入 ÷ 目标月利润              ← 目标利润 ≤ 0 ⇒ 不计算（不编造）
```
v1 → v2：① 综合变动率不再由三个"率"相加，而是 `(100 − 毛利率) + Σ 挂钩费率`；② 固定成本新增**建店投入摊销**（v1 是手填模拟摊销额）；③ 新增**收回投入**与**餐饮指标对照**。

**标准工况锚点**（`calcSandbox/selftest.js` 41 项）：建店 660,000（装修 36万/3年 + 加盟 18万/3年 + 设备 12万/5年）⇒ 月摊销 17,000；含摊销固定 38,000；毛利率 65% ⇒ 食材 35%；佣金 15% ⇒ 综合 50%、边际 0.5 ⇒ **保本 76,000.00 / 日均 2,533.33**；**目标 106,000.00 / 日均 3,533.33**；**收回投入 44 个月**；指标·房租 15.8%（参考带 8~15% ⇒ warn，且超 M1.6 警戒线 15%）、人工 9.2%（低于下限 ⇒ good）。

## 9 待李老师真机验证（6 处）
