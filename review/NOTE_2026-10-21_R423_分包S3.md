## 2. 🔴🔴 最重要的发现：`SKIP_DIRS` 撞上了分包目录名

**这不是迁移造成的，是原本就潜伏的真 bug，被迁移暴露了。**

```js
const SKIP_DIRS = ['node_modules', '.git', '_m3', 'prototype', 'review', 'specs', 'tools'];
// walk 里：
if (SKIP_DIRS.indexOf(e.name) >= 0) continue;   // ← 按【目录名】跳过
```

`'tools'` 的本意是跳过**仓库根**的 `tools/`（守卫脚本目录，不是业务代码）。
但分包路径恰好是 `subpkg/tools/` —— 目录名也叫 `tools` ⇒ **整个 tools 分包被跳过**。

**后果**：`check_money_precision` 把 10 条 sandbox 登记全判成“失效”，因为它压根没扫到那些文件。

**为什么危险**：症状长得像“登记过期”，最自然的修法是**删掉那 10 条登记**——
那就把真断言删了，守卫从此形同虚设。这是“修判据求绿”的典型陷阱。

**修法**：SKIP 只在**根级**生效：
```js
if (SKIP_DIRS.indexOf(e.name) >= 0 && path.relative(ROOT, p) === e.name) continue;
```

已修 2 处：`check_money_precision`、`check_theme_color`（后者本轮没红，但结构与隐患完全相同，一起修）。

**推广纪律**：任何“跳过目录”的名单，只要**按名字**匹配，就会和分包目录名撞车。
已全仓扫过，只有这两个守卫用 `SKIP_DIRS`；其余都是显式列目录（加 `subpkg` 即可）。
