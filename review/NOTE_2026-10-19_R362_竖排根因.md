# R362 · 「场景矩阵测算 → 开店要投多少」文字竖排：根因是全局 `.field input` 的 min-width

> 2026-10-19 · 李老师指认位置后一次定位 · 判据 B16

## 一、现象

场景矩阵页「开店要投多少（押金不算…）」下面四行 ——
**装修（门头、软装）/ 设备（厨房、桌椅）/ 加盟费 / 转让费** ——
文字不是横排，而是**一字一行竖着往下挤**。

## 二、根因（实测数据，不是猜）

在模拟器里用 `createSelectorQuery` 量真实渲染尺寸（窗口 390pt）：

| 元素 | 修复前实测 | 说明 |
|---|---|---|
| `.field` 行宽 | **342px** | 卡片 366px − padding |
| `.inp`（应 240rpx≈125px） | **185px** | 被抬高 |
| `.yr-inp`（应 80rpx≈42px） | **185px** | 同样被抬高，**和上一个一样宽** |
| `.field .label` | **28px 宽 / 100~120px 高** | 28px ≈ 2 个字 ⇒ 一行 2 字、5~6 行 = 「竖排」 |

185×2 = 370px > 342px ⇒ 两个输入框把行撑满，label 只能被压到 28px。

**抬高它的是全局样式** `app.wxss:33`：

```css
.field input { text-align: right; min-width: 320rpx; padding: 14rpx 18rpx; ... }
```

`min-width` **优先于** `width` ⇒ 本页 `.inp{width:240rpx}` / `.yr-inp{width:80rpx}` 全部失效，
两者都被抬到 ≥320rpx（≈166px）+ 内边距 ≈ **185px**。

顺带还有第二处同名冲突：`app.wxss:51` 的 `.inp` 是**另一种东西**（卡片容器：
`padding:24rpx; min-height:88rpx; margin-bottom:16rpx`）⇒ 本页输入框被撑高、行距变大。

## 三、为什么 R296c 没修好

R296c 只处理了 `.card` 那一处（改用 `.mcard`），**没有顺手扫同名族**，
于是 `.field / .label / .inp` 三个冲突原封不动 —— 这就是"修了同类的一半"。

## 四、改法（与 R296c 同一手法）

本页改用**专属类名**，与全局彻底断开：

| 旧 | 新 | 附带 |
|---|---|---|
| `.field` | `.mfield` | 加 `flex-wrap: wrap`（真放不下就换行，永不压成竖排） |
| `.label` | `.mlabel` | 加 `flex: 0 0 auto; white-space: nowrap`（中文不许逐字断行） |
| `.inp` | `.minp` | 加 `box-sizing: border-box`（width 不含 padding，不再溢出） |

`matrix.wxml` 43 处 `class` 属性按 **token 级**重命名（不会误伤 `bd-inp / yr-inp / dim-inp / cash-inp`）。
**只动本页**：另有 7 个页面仍用全局 `.field`，一字未改。

## 五、修复后实测（同一台模拟器、同一批元素）

| 元素 | 修复前 | 修复后 |
|---|---|---|
| `.mlabel` 宽×高 | 28 × 100~120 | **126 / 140 / 154 × 20**（单行） |
| `.minp`（金额） | 185 | **104**（=200rpx，符合设计） |
| `.yr-inp`（年限） | 185 | **41**（=80rpx） |
| `.mfield` 行高 | 66 / 112 / 132 | **34** |
| 整块卡片高 | 1022 / 1016 | **470 / 565** |

OCR 复核：`装修（门头、软装）`、`设备（厨房、桌椅）` 已横向成行。

## 六、判据（`check_m2_matrix.js::B16`，174 → 176）

两条腿：
1. **wxml 侧**：矩阵页 `class` token 里不得出现 `card / field / label / inp`
   （与本页唯一名 `mcard/mfield/mlabel/minp` 区分）。
2. **wxss 侧**：`matrix.wxss` 不得再定义这四个选择器（防"wxml 改了、样式还留着"）。

**变异实测**：把一处 `class="mlabel"` 改回 `class="label"` ⇒ B16 判红并点名；
还原 ⇒ 176/176 复绿。

> ⚠️ 首版判据我把扫描对象写成了**首页** `idxWxmlS` ⇒ 恒绿假通过。
> 已改为矩阵页 `mtxWxml`，并靠变异证明它真的会红 —— 这正是「腿锚错地方」那条老坑。

## 七、如实登记

- 本页**还有两处**用了全局类名：`.dim-row` 系列是唯一名（无冲突），但 `.picker`
  仍继承全局无冲突（app.wxss 无 `.picker`）⇒ 未动。
- 其他页面（`card/edit`、`month/input` 等 7 处）继续用全局 `.field`，
  它们本来就该用那套样式，**不要跟着改**。
- 新增一个通用隐患：**本仓没有"页面 wxss 与 app.wxss 同名类"的全仓守卫**，
  只在 M2 矩阵页钉了 B16。若要全仓守，需先定"哪些同名是允许的覆盖"，否则噪音太大 —— 留给下一轮。
