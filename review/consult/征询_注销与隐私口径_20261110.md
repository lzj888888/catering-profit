# 征询：餐饮小程序「注销账号 / 删除店铺」的数据处置与隐私口径

请以「你是一名同时做过互联网产品合规与财税实务的顾问」的身份回答。我要的是能直接落地的结论，不是选项清单。

## 一、产品背景

- 微信小程序「店算」，餐饮经营财务分析工具：帮餐饮店老板算盈亏平衡、成本率、利润。
- 主体：**个体工商户**（不是公司），规模极小，开发者就 1~2 人。
- 技术栈：微信云开发（腾讯 CloudBase），33 个数据库集合，58 个云函数，1 个环境。
- 用户：餐饮店老板本人，录入的是**自己门店的**经营数据。不是 SaaS 代账，不涉及他人数据。
- 不收集：手机号、地理位置、身份证、通讯录。昵称头像只存在手机本地存储，不上云、无云端读取。

## 二、实际存了哪些数据

| 类别 | 内容 | 敏感度 |
|---|---|---|
| 店铺信息 | 店名、地址、面积、业态、开店时间 | 中（能定位到具体门店） |
| **月度经营明细** | 收入分项、费用分项（食材/房租/人工/水电/推广）、月度合计、利润 | **高（等于把一家店的家底全交出来了）** |
| 库存 | 原料、数量、单价 | 中 |
| 菜品成本卡 | 菜品配方（BOM）、出品率、售价、毛利 | **高（核心商业机密）** |
| 员工 | 姓名、岗位、工资 | **高（含他人个人信息，且是薪酬）** |
| 审计日志 | 每次写操作的留痕 | 低（但合规上要留） |

## 三、当前的删除实现（这是问题的核心）

### 3.1 注销账号

代码 `cloudfunctions/deleteAccount/index.js` 实际做的：

- openid 置为 `anonymous_000000000000`（**不可逆**，这点做了）
- 昵称匿名
- shop / entitlement 打 `is_deleted=true`（软删）
- **经营数据本体（收入 / 费用 / 房租 / 人工 / 利润 / 库存 / 成本卡 / 员工工资）一个字都没动，仍是明文**

但对用户说的是：

- 接口返回：`账号已注销，历史数据已匿名化处理（15 个工作日内完成数据清理）`
- 前端文案：`已提交注销申请，我们将于 15 个工作日内完成数据处理。`

**问题：全仓库没有任何定时清理任务。** 带定时触发器的云函数只有 2 个（`dbBackup` 每日备份、`payExpireNotify` 支付到期提醒），**没有一个是清理**。

⇒ 这句「15 个工作日内完成清理」是**用户可见的空头承诺**，永远不会发生。

### 3.2 删除店铺

代码 `cloudfunctions/manageShop/index.js` 头注原文：

> 软删：删除店铺 / 清空月度账都只写 `is_deleted=true`（**绝不物理删除**），历史数据保留可追溯。

设计意图是好的（老板改错账、事后翻旧账是真实需求）。但用户点「删除店铺」时，心理预期是**数据没了**。

### 3.3 隐私协议

- 点「查看隐私协议」，弹的是一个自写 `wx.showModal` 里的一段话，**不是**微信官方《用户隐私保护指引》。
- 那段话写着「收集昵称头像用于账号识别与数据同步」——**与实际不符**：昵称头像只 `wx.setStorageSync` 存本地，**没有任何云函数读它们**。
- 那段话**完全没提经营财务数据**——而这是本小程序最敏感的一类。
- 微信官方能力 `wx.openPrivacyContract()`（打开在 mp 后台填报的官方隐私指引）**全仓只在一行注释里出现，没有真正调用**。

## 四、请回答这 6 个问题

**要明确结论、给具体数字。不要写「建议根据实际情况评估」。**

1. **注销后，经营数据应该保留多久？** 给具体天数或月数，并说明依据（财税追溯 vs 个人信息删除权，哪个优先、怎么平衡）。注意主体是**个体工商户**，用户是老板本人不是消费者。

2. **删除粒度怎么定？** 逐项给出「物理删除 / 不可逆脱敏 / 保留 / 按年限保留」：
   - 月收入明细、月费用明细、月度合计
   - 库存、菜品成本卡
   - 员工姓名与工资（这里涉及他人个人信息）
   - 审计日志
   - 数据库每日备份（已有备份里也含着这些数据，这个最容易被忽略）

3. **隐私政策必须写哪几条？** 给最小合规集，每条最好给可直接用的中文措辞。特别说明：个体工商户需要在 mp 后台填报腾讯官方的《用户隐私保护指引》，这份和 App 内展示的隐私政策，两者应该怎么写、怎么配合？

4. **「收集昵称头像用于同步」这条声明与实现不符**，应该删掉声明，还是补上实现？哪个更合理？从合规和产品两个角度分别说。

5. **「删店（软删）」和「注销（应彻底）」是两套语义**，怎么跟用户讲才不会误解？文案怎么写？

6. **我漏了什么？** 上面没提到但你认为是风险的，直接说，包括你判断我做错的地方。
