# 支付通道与备案前置 · 官方核实（2026-11-05）

> 触发：李老师质疑「个体工商户应该是支持普通支付的吧」「备案一定要有执照吗」。
> 方法：微信官方文档原文取证 + 豆包独立核对（三司会诊惯例）。
> 结论：**李老师对。上一轮把「主体能不能开」和「货该走哪条通道」混成一句话，是需要纠正的表达错误。**

## 一、四条事实（全部有官方原文，不靠推断）

### ① 个体工商户可以开普通微信支付 —— 是
官方《小程序接入支付》申请材料明列「个体工商户：营业执照 + 对公银行账户/法人对私账户 + 法人身份证」；
《开发接入准备》：「支持申请小程序支付权限的主体类型有：个体工商户、企业、事业单位、政府机关、社会组织」。
⇒ 个体户走 `wx.requestPayment` 完全合规，无需对公账户（可提现到经营者个人卡），费率 0.6%~1%。

### ② 但「卖虚拟商品」必须走虚拟支付 —— 这才是店算的约束
官方《虚拟支付业务运营指南》原文：
> 开发者在小程序内提供的虚拟商品（包括虚拟代币、**解锁功能**、**订阅内容**、**付费功能**、打赏、购买虚拟礼物等），购买和支付**均需接入小程序虚拟支付**。

《小程序运营规范》2.5.13 同上，违规处理为「阶梯封禁 iOS 支付接口 / iOS 搜索 / iOS 打开小程序」。
豁免只有两类：线上问诊（持牌医疗机构/医生实时远程诊疗）、法律咨询（持牌律师/律所实时咨询）—— **餐饮经营咨询不在豁免内**。
⇒ 店算卖「报告解锁 + 会员」= 解锁功能 + 订阅内容 ⇒ **必须虚拟支付**。这不是主体限制，是商品性质限制。

### ③ 个体工商户可以开虚拟支付 —— 是（此点豆包判错，以官方为准）
官方《虚拟支付：企业、个体户》1.1 开通条件表格原文：

| 条件 | 说明 |
|---|---|
| 已认证小程序 | 主体类型需为已认证的小程序 |
| **企业 / 事业单位 / 个体工商户** | 小程序类型需为企业、事业单位或个体工商户 |
| 主体信息完备 | 信息若有缺失，请通过平台提供的修改链接修正 |

文档地址 `developers.weixin.qq.com/miniprogram/dev/platform-capabilities/business-capabilities/virtual-payment.html`
第三方接入指引亦记：「更新：已支持个体户主体申请开通虚拟支付」。
⇒ **个体户开虚拟支付无月限额**（月限 10 万只针对个人主体）。

### ④ 个人主体 2026-11-04 起也能开虚拟支付（新政）
官方《虚拟支付：个人》开通条件：主体为个人 + 服务类目含「工具」+ 已完成认证与备案。
限额月 10 万元；费率 Android 1%（腾讯技术服务费）/ iOS 12%（Apple 佣金）；账期 Android T+3 / iOS 约 45~60 天。
个人可选「工具」二级类目：记账、日历、天气、办公、图片处理、**计算器**、报价/比价、信息查询、预约/报名、健康管理、备忘录、投票。

## 二、备案是否必须执照

| 小程序主体 | 备案所需主体证件 |
|---|---|
| 个人 | 身份证即可，**不需要执照** |
| 个体工商户 / 企业 | 必须营业执照 |

另需分清两件事：
- **小程序备案**（微信公众平台代提交）：不需要域名、不需要服务器。
- **网站 ICP 备案**：需要域名 + 境内服务器。仅当自己做独立 H5 站点才涉及。

⇒ 「备案一定要执照吗」的准确答案：**看主体。你现在是个人主体，用身份证就能备；改成个体户主体后才必须执照。**

🔴 但备案必须与主体一致：主体一变 → 必须做「变更备案」，重走管局审核（1~20 工作日）。
⇒ **用个人主体抢跑备案不划算**，主体变更后要再交一次审核。

## 三、主体变更（个人 → 个体户）可行性

官方社区置顶帖《个人主体的小程序可以变更为企业主体》：
- 条件：已注册、非境外、**目标主体不能是个人类型**、目标主体不能与原主体一致。
- 入口：设置 → 基本信息 → 主体信息 → 小程序主体变更。
- 验证方式**二选一**：上传公证书扫描件 **或 法定代表人（经营者）扫码验证** ⇒ 李老师本人即经营者 ⇒ **不需要公证**。
- 费用 300 元（不退）；审核 7 个工作日；通过后须在 7~15 天内点「确认变更」，超时作废。
- 变更后：**服务类目须用新执照重新提交审核**；商户号须重新绑定；备案须做变更备案。

## 四、豆包核对记录（诚实留痕）

第一轮长 prompt 读超时（`RC=1 The read operation timed out`，脚本 timeout=300s 写死），拆短后 `RC=0`。
豆包四条判定：

| 条目 | 豆包 | 官方原文 | 裁定 |
|---|---|---|---|
| 个体户能否开普通支付 | 能 | 能 | 一致 |
| 卖解锁/订阅必须走虚拟支付 | 必须 | 必须 | 一致 |
| 个体户能否开虚拟支付 | **不能** | **能**（开通条件明列个体工商户） | **豆包错，以官方为准** |
| 备案是否必须执照 | 不必（个人用身份证） | 同 | 一致 |
| 个人→个体户变更 / 扫码替代公证 | 能 / 能 | 能 / 能 | 一致 |

豆包自陈「最想纠正：个体工商户可开通小程序虚拟支付承接虚拟解锁类业务的认知有误」——该判断与官方文档正面冲突，判豆包失效。推测其知识截止早于个体户开放虚拟支付。

## 五、对 #114 / #119 的影响

- #114「虚拟支付接入」的前置从「个人主体专属通道 + 三条硬约束」改为「个体户通道，无月限额，无 plan_auto_subscribe 主体限制的表述需重核」。
- #119「认证 + 备案」仍是硬门槛，但**顺序应为：执照 → 认证 → 主体变更 → 服务类目 → 备案**，备案排在主体变更之后（否则要变更备案，多做一次）。
- 成本订正：个体户微信认证 **30 元/年**（不是 300 元，300 元是企业档）；主体变更另收 300 元。
