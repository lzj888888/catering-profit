# NOTE_2026-11-25 · R758 · M3 枢纽页图标与状态徽标

## 缘起（李老师原话）
> 「我想把 M3 页面样式变动一下，现在每个都是一个字做的页面的一个展示 LOGO，感觉有点单薄，
> 整体页面有点素，全是文字感，你找找技能，看看如何优化？」

## 技能调研结论
加载 `enterprise-ui-optimizer`（企业级 UI 优化技能），核心主张：信息优先、视觉元素要带信息量而非纯装饰、
拒绝花哨。对照 M3 首页诊断：
- **单字图标**（料/卡/外/团/榜/渠/账/促）本身就是文字 ⇒ 「全是文字感」主因；
- 8 张卡一个模子（图标 + 标题 + 一行描述）⇒ 缺视觉锚点、扫描时像一张表；
- hero 是纯文字头图，但它在 `app.wxss` 色值单源里，动它风险最大，本轮不碰。

方案（李老师拍板）：**线性图标替换单字 + 卡片状态徽标**，不改层级结构。

## 实现
| 项 | 做法 |
|---|---|
| 图标 | 8 个线性图标（原料箱/文档卡/外卖袋/双人团购/柱状榜/渠道分流/账本对勾/价格吊牌），PIL 绘制 → PNG 位图，存 `images/hub/` |
| 生成脚本 | `tools/gen_hub_icons.py`（4x 超采样 + LANCZOS 抗锯齿，可复现；不用 SVG/iconfont/emoji：本仓真机踩过 emoji 塌行，webview 对 SVG 支持不定） |
| 接线 | terms 的 8 个 `icoXxx` 值从单字改成 `/images/hub/xxx.png`（**键名不动**，守住 check_page_terms P2 / hub-lead-strip A-⑥）；wxml 用 `<image class="hub-ico-img" src="{{t.icoXxx}}">` |
| 色值 | 图标块渐变底仍在 `app.wxss::.hub-ico-*` 单源；本轮零新增色值 |
| 徽标 | 复用 `app.wxss::.sb-badge`（ok/warn/bad/na 四态单源）。5 个新文案入 terms 双副本 + hub.js 的 `t:{}` |
| 徽标语义 | 全部对应**真实状态/属性**，无一是装饰：`已录/已建/待补`（stepFlags 驱动，fail-closed）、`工具`（纯手填测算器：外卖/团购/活动）、`看数`（用店内数据核对：榜单/渠道营收/对账） |
