## 一、M2 开店沙盘（本轮改动最多，优先验）

### 1. 建店年限（第一轮修复）
- [ ] 进「开店沙盘」→ 填转让费 8 万 / 装修 6 万 / 设备 5 万 → **把摊销年限清空** → 计算
- [ ] **预期**：按月摊销 **4,722.22 元**（= 190000 ÷ 3 ÷ 12 的口径），保本约 **56,186.86 元**
  - ❌ 若显示月摊销 15,833.33 元 / 保本 81,439.39 元 ⇒ 退化回「按 1 年摊」

### 2. 矩阵页维度输入（第二轮修复）
- [ ] 进「场景矩阵」→ 把某一档**毛利率改成 150** → 生成
- [ ] **预期**：当场提示「第 N 档毛利率要在 0~100（现在填了 150）」，**不发请求、不画矩阵**
- [ ] 再把房租档位改成 **-8000** → 预期提示「第 N 档房租要在 0~100000000（现在填了 -8000）」
- [ ] 正常档位（毛利率 60 左右）→ 预期正常出矩阵，且**表格里没有任何"出错"整页崩**

### 3. 保存方案（第三轮修复）
- [ ] 把毛利率改成 **150** → 点「计算」（预期提示毛利率范围）
- [ ] **此时直接点「保存方案」** → **预期：被拦下并提示毛利率范围**（修复前这里会**保存成功**，
      库里留下一个"保本 18,444 元"的假方案）
- [ ] 改回毛利率 60 左右 → 保存 → 进「多方案对比」→ 预期方案保本量与沙盘页一致

### 4. 反推（寻找铺面）模式回归
- [ ] 切到反推模式，固定支出里**填房租** → 预期被拒并提示「反推模式下房租由目标租金率导出…」
