## 一、已修：配平校验式「补贴被抵消」⇒ 恒定误报

### 现象（真值验算，不是推测）

拿 8 月实测账单的真值喂进配平式：

```
商品 6418.08 / 打包 167.00 / 商家承担补贴 2069.70 / 佣金 158.71 / 配送服务费 577.02 / 真实到手 3779.65
```

| 补贴框填 | 收入合计（三框相加） | 配平式算出的 expected | 真实到手 | 差额 | 判定 |
|---|---|---|---|---|---|
| +2069.70 | 8654.78 | **5849.35** | 3779.65 | −2069.70 | miss |
| −2069.70 | 4515.38 | **5849.35** | 3779.65 | −2069.70 | miss |

**无论填正数还是负数，expected 恒为 5849.35，比真实到手多整整一个补贴额。**
⇒ 客户老老实实抄了账单应收款 3779.65，系统永远提示「差 2069.70，可能漏填了某项扣款」—— **改无可改**。

### 根因

收入侧「外卖收入合计」= 三框相加 ⇒ **本身就含补贴框的值**；
配平式 `收入合计 − 补贴 − 佣金 − 配送` 再减一次 ⇒ 两次**互相抵消** ⇒ **补贴一次都没扣**。

规范 A.11.4(b) 的注解原话是「因收入口径含商家活动补贴、费用侧又把同一笔自动带出，**两者相抵**」——
这句话描述的**正是这个缺陷本身**：相抵完，补贴就消失了。
该式子只在「收入合计**不含**补贴」的前提下才成立。

### 修法（两步走 + 取绝对值）

```
优惠前总额 = 收入合计 − 补贴框的值        // 先按原符号把收入里那次抵消掉
应有到手   = 优惠前总额 − |补贴框的值| − 佣金 − 配送服务费 − 配送补贴
```

取绝对值 ⇒ **客户填正数（补贴金额）或照抄账单负数，得到的是同一个正确答案** —— 不再赌客户怎么填。

修复后验算：两种符号都得 **3779.65 / pass**；**真漏填补贴时仍能报 miss**（差 2069.70），漏填检测没被修没。

落点：`utils/takeaway.js::reconcile`；断言 A26-12（5 条）+ 变异回灌 3 条全红。

## 二、🔴 未修（更严重）：利润口径 —— 补贴被抵消 / 双扣

### 现状

- 收入侧：三框相加 ⇒ **含补贴**（A.1 / A.11.2「商品总价 + 打包费 + 商家活动补贴」）
- 费用侧：`外卖活动补贴` 由收入侧补贴合计**自动带出**（A.11.3 sort 30，代码 `syncSubsidyCarry`）

同一笔补贴**两边都记** ⇒ 利润计算里：

| 客户补贴框填 | 收入 | 费用（含带出的补贴） | 算出的利润 | 真实利润 | 后果 |
|---|---|---|---|---|---|
| 正数 2069.70 | 优惠前 + 补贴 | 补贴 + 佣金 + 配送 | 优惠前 − 佣金 − 配送 | 优惠前 − **补贴** − 佣金 − 配送 | **利润虚高 2069.70** |
| 负数 −2069.70 | 优惠前 − 补贴 | 补贴 + 佣金 + 配送 | 优惠前 − 2×补贴 − 佣金 − 配送 | 同上 | **利润虚低 2069.70** |

⇒ **无论客户怎么填，利润都必然错一个补贴额**（本店 2069.70 = 优惠前总额的 31%）。

### 为什么会这样（规范自身的矛盾）

- **A.6 总额法**说：「外卖：账单显式拆出『商家活动补贴』 → 总额法（**补贴计入收入，同时作费用**）」。
  总额法的正确做法是：**收入按交易总额确认（不扣补贴），补贴单独作费用** —— 补贴在收入里是**不出现**的，不是"加进去"。
- 但 **A.1 / A.11.2** 把收入写成「商品总价 + 打包费 + 商家活动补贴」⇒ 补贴**进了收入**。
- 两者一叠加，就变成"收入含补贴 + 费用再记一次" ⇒ 抵消 / 双扣。

**三方一致倒推出的唯一自洽解**：收入 = 优惠前总额（商品总价 + 打包费，**不含**补贴）；补贴只作费用。
（这也正好让 A.11.4(b) 的式子回到字面成立 —— 与 §一 互为印证。）

### 两个修法（**要您拍板**，都影响历史数据）

| | 方案 A（**我推荐**） | 方案 B |
|---|---|---|
| 收入 | = 商品总价 + 打包费（**不含**补贴） | 三框相加（客户抄账单负数 ⇒ 净额） |
| 费用侧补贴 | 保留自动带出 | **取消**自动带出（不许费用侧再记） |
| 会计 | 符合 A.6 总额法 ✓ | 净额法，与 A.6 冲突 ✗ |
| 与 A.11.4(b) 原式 | 字面即成立 ✓ | 需改式子 |
| 改动面 | `subtotalOf` 不含补贴 + 文案 + 快速模式语义 + 配平式回退到字面式 | 只关掉 `syncSubsidyCarry` + 改边界句 |
| 历史数据 | ⚠ 已存的分项小计含补贴 ⇒ **跨月对比会失真**（需一次性说明/迁移） | ⚠ 同样有语义变化 |

**共同影响（无论选哪个）**：已保存月份的小计语义会变 ⇒ 跨月对比可能失真。
按 A.7「整店锁定一种口径，切换提示月度对比会失真」的惯例处理。

**我建议选 A**：会计正确、与配平式原式自洽、且"补贴是费用"符合老板直觉（补贴是我掏的钱）。
