# 豆包对话「店算小程序 AI价值判断」观点汇总
> 来源：桌面豆包同名对话，OCR 逐屏读取（2026-10-20 首问 + 2026-10-29 20:24–23:02 主体）
> 用途：三司会诊（workbuddy + 豆包 + DeepSeek）讨论「AI 层 + 餐饮常见问题数字化」的输入材料

## 一、剑哥聊餐饮 → 知识库（10/20 起，昨天实测）
- **版权红线**：直接扒视频/转录商用 = 侵权（投诉/下架/索赔）。合规 = 拿授权 或 **只参考观点二次原创**。
- **技术实测**（昨天 20:24）：文字抓取**可行**（实测一条《26年餐饮第一课》）；抖音有视频下载防护但知识库要的就是文字；文本夹带导流广告**必须清洗**；一次搜索可批量抓。
- **剑哥账号**：餐饮 30 年，新辣道/锦府盐帮创始人、信良记董事长。核心方法论「**极致单店**」= 收入大大的、成本小小的、利润高高的；选址/房租/人工/菜单等支柱。变现 = 线下课程 + 工具包 + 导流。
- **内容五大板块**：① 预算（26年餐饮第一课：预算=提前推演全年盈亏）② **毛利额 vs 毛利率**（高毛利白忙，看毛利额）③ 菜单设计（四象限/泡泡图/君臣佐使/爆款三要素/N+1 套餐）④ 选址（买流量不买面积）⑤ 极致单店。
- **入库铁律**：店算口径 > 博主观点；涉及计算必须对齐 POC1/POC2/POC3，冲突直接舍弃重写；广告导流剔除；面向中小门店；不传递矛盾引导。
- **入库校验清单**（前置 4 条 + 分项）：纯经营思路可参考重写；毛利率强制区分「销售毛利率（M3 标准）vs 成本毛利率」；毛利额 = 营收 − 食材成本；费用摊销匹配 POC1 规则；利润区分「经营参考利润（免费版）/ 全要素真实利润（付费版）」双口径；M2 选址测算公式必须和沙盘对齐。
- **给止损哥/店算的借鉴**：剑哥选题 = 市场验证过的高流量方向（预算/毛利额/菜单/人工/选址），直接当选题库；「毛利额 vs 毛利率」「菜单泡泡图」「极致单店」是强钩子；计算类条目标「口径风险」标签。

## 二、止损哥原创内容矩阵（昨天 20:31）
- 5 套短视频脚本大纲（口播 60–75s，口径全部对齐 M1/M2/M3）：① 别死盯毛利率看毛利额（绑 M3）② 做预算 ③ 菜单泡泡图/四象限（绑 M3）④ 选址买流量不买面积（绑 M2）⑤ 极致单店爆款三要素。
- 统一人设：止损哥，懂算账、踩过坑、讲实在。结尾引导体验店算小程序。

## 三、原创指标（昨天）
- **客均毛利 GPC** = 毛利总额 ÷ 来客数 = 客单价 × 销售毛利率（数学恒等，非原创公式）。
- **原创点**：绑定「消费能力约束」双重条件 + 面向餐饮老板命名——候选「客均净利贡献」/「**单客盈利锚点**」（推荐，锚=盈利基准线）。
- 延伸：**客利润 vs 每客固定成本**（=月固定成本÷月客数）→ 盈亏平衡打通 M2：客利润 ≥ 每客固定成本才有得赚。
- 行业对标：Contribution per Dish / Average Check / Customer Profitability / Revenue per Seat（均无此组合概念，可占位）。
- 净利口径分摊固定成本可比性差 → **主指标用毛利口径客利润**，净利口径做高级延伸。

## 四、知识库三层理论地图（昨天 20:40 前后）
- 三层建库：**道**（经营思想/理论）→ 只做参考；**术**（POC 确定性计算）→ 只信店算数字，AI 不碰；**参考**（博主实战经验）→ 二次原创补充，不覆盖算法。
- 理论对标：M1 ↔ Prime Cost 主成本法 + 库存倒轧（美式标杆）；M2 ↔ Huff 商圈引力模型（选址实证）；M3 ↔ Menu Engineering 菜单工程（Kasavana&Smith）+ 出成率成本卡。「客利润」是自有创新。

## 五、智库 + AI 问答 = 核心价值判断（昨天 20:40–21:11）
- **轻量结构化智库（现阶段做）**：指标字典 + 条件→结论诊断规则库 + 方案分支。纯结构化，**不上向量检索**，云数据库直接存。入库三类：指标定义 / 诊断规则（最值钱）/ 规则化改写的博主观点。
- **完整 RAG 智库（暂缓）**：长文本向量库成本高、审核重、资质风险同步放大。触发条件（满足其一再启动）：付费用户稳定 200 人且 M2 沙盘高频；或固定规则不够用需品类化案例。
- **存储与费用**：结构化规则库（云数据库，零额外成本）→ 后期向量字段（混元/DeepSeek Embedding，单价低）→ 大模型推理按量（单次解读约 0.01–0.03 元，输入 200 token + 输出 400 token 量级）。厂商自带 RAG 面板只适合测试，不能当主库（数据归属/迁移/版本管理弱）。
- **风险边界**：私有知识库只给自家小程序 RAG 用，不对外公开问答；全部清洗二次原创；prompt 强制「只引用召回智库内容，禁止编造指标公式，计算结果以引擎为准」。
- **核心裁决**：智库专家 vs 老板把数据甩给通用 AI = **护栏 + 标尺 + 行业锚点**的本质区别（通用模型口径随机、毛利率定义混用会直接翻车）。
- **诊断维度框架**（对齐 M1/M2/M3）：盈利健康度（M1 核心）/ 菜单结构（M3 四象限+客利润）/ 选址与保本（M2 沙盘）/ 现金流 vs 账面利润（库存积压、储值预收）/ 扩张判定（连续 3 个月盈亏弹性 ≥ 1.3 + 主成本合理区间 + 复购稳定）。
- **三层输出**：① 诊断定性（先分「结构性营收不足 vs 原生流量不足」——前者是主战场，后者要诚实说是硬短板）→ ② 可控落地动作（菜单/套餐/成本/排班）→ ③ 工具测算（M2 沙盘）。所有输出带边界声明（只评估盈亏底线不保证客流）。

## 六、餐饮常见问题清单（昨天 21:15–21:35，数字化解决的题库）
高频 18+ 条已梳理成「问题 → 智库可承接 → 触发条件 → 联动模块 → 边界」结构：
1. 营业额不好怎么办（先拆结构性 vs 原生流量）2. 该不该扩张（单店模型跑通判定）3. 该不该撤店/止损 4. 如何选址（M2 沙盘）5. 营销活动/代金券满减设置（M2 测临界客流）6. 菜单结构（M3 四象限）7. 毛利率多少合适（区分品类基准+客利润）8. 要不要跟对手降价 9. 账面有利润为啥没钱（现金流 vs 会计利润）10. 储值活动的坑（预收款负债）11. 赚的钱怎么分配 12. 合伙股权（只算利润不做方案）13. 店长提成设计 14. 人工排班/人效 15. 淡旺季怎么扛（跨月平滑）16. 复购怎么看（风险修正因子）17. 套餐引流安全边界（份额上限）18. 储值负债陷阱。
- **外挂校验因子**（非核心变量）：复购（可选面板，不填不影响）/ 淡旺季标记 / 储值负债 / 套餐份额上限。数据来源：美团回头客、收银会员报表、估算值（标注）。
- **坚决剔除**：口味配方、短视频/同城运营、工商法务、预判未来客流。

## 七、整体价值定位（昨天 22 点前后）
- 市场卡位：**带实战咨询标尺的经营测算工具**（避开「记账工具只出数字」红海 ×「博主/课程没量化标尺」红海）。
- 商业闭环：自助工具订阅 + 复杂疑难单引流到一对一咨询。第三条路线差异化极强。
- 上限取决于：① 守住边界（不做流量运营）② 智库规则持续沉淀、输出稳定不空泛。

## 八、旁支：AI 编程 Skill 讨论（昨天 22:18–23:02）
- AI 编程工具擅长需求拆解/小程序页面/文档；POC 金额逻辑只能辅助不能代劳。固定 Prompt 约束：财务金额分存储、先判定规则再写代码、禁止擅改 POC、自动生成测试用例。
