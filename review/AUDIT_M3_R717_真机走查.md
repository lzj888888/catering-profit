## 二、走查当场抓到的两处漏网（都已修）

### 漏网 1 · hub 副标题：四字变体绕过了六字拦截

```
改前：原料、成本卡、销量导入、利润复盘      ← 本页早已没有「销量导入」
改后：原料、成本卡、外卖团购、对账复盘
```

**为什么上一轮的守卫没拦住**：A-① 判的是六字「销量表导入」，而副标题写的是四字「销量导入」。
同一个已撤入口，换个写法就漏了。

⇒ 不再靠"猜变体"，改成**位置白名单**（A-③）：
「销量导入」是外卖页内 tab 的真名，**只允许**出现在 `takeawaySub`（指向那页内部），
出现在任何别处 = 又在说本页有个不存在的入口。

**教训**：按"字面量黑名单"写判据，永远会漏变体。要么按**位置**限定，要么按**结构**判定。

### 漏网 2 · 排行榜空态：同一屏两条互斥的导入指路

```
首屏：  [ 导入销量表 ] 按钮                 ← R707 把入口搬进本页首屏
折叠区：请先在「外卖」页导入《菜品销售统计》  ← 过时文案（写这句时本页还没有按钮）
```

老板站在这个页面上，却被要求跑去另一页导同一份数据。改成：

```
还没有堂食销量 —— 点页面上方「导入销量表」就能导。
```

⇒ 补判据 A-⑤：排行榜空态必须点**本页**的按钮，不许出现别的页名。

## 三、待李老师拍板的一处（未擅自改）

**对账页同时显示「账上算的实际毛利率 100.00%」和红字「请先填写在售菜品数，才能算覆盖率」。**

- 数字本身是真的：本月录了收入、没录成本 ⇒ 账上毛利率 100%。
- 红字说的是另一件事：覆盖率算不出来。
- **逻辑不矛盾，但读起来像"我这月毛利 100%"** —— 这正是「会让人误会」的典型。

现有设计（R712 定的）是"抑制时只显示两个原始数 + 原因，把差值/金额/归因藏起来"。
要不要再进一步（比如 100% 旁边标一句「本月还没录成本」），涉及 `reconDerive` 的抑制口径，
属 R714 登记的「对账三件待拍板」范畴，**本轮不动**。
