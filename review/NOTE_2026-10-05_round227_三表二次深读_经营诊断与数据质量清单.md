## 二 外卖（饿了么）7 天经营诊断

**盘子**：46 单 · 营业额 1,870.28 · 到手 980.86 · 单均营业额 **40.66** · **单均到手 21.32 元**。

### 2.1 钱漏在哪（费用结构 ÷ 营业额）

| 项目 | 金额 | 占营业额 | 备注 |
|---|---|---|---|
| 商家活动成本（含满减） | 702.68 | **37.57%** | 🔴 **最大失血点**，占全部支出的 **79.0%** |
| 履约技术服务费 | 145.71 | 7.79% | |
| 平台技术服务费 | 41.03 | 2.19% | |
| 退单费用 / 其他支出 / 智能满减服务费 | 0 | 0% | |
| **支出合计** | **889.42** | **47.56%** | ⇒ 到手 **52.44%** |

🔴 **结论：每卖出 100 元，平台与活动拿走 47.56 元，其中 37.57 元是自己贴的活动补贴。**
活动总补贴 1,045.53（55.90%）中，饿了么 + 代理商承担 342.85，商家自担 702.68。

### 2.2 流量漏斗（人数口径）

```
曝光 3,246  →  进店 305（9.40%）  →  下单 46（进店→下单 15.08%；曝光→下单 1.42%）
```

- 进店率 9.40%：**正常区间**（外卖行业 8~12%）；
- 进店→下单 15.08%：**偏低**（常见 20~30%）⇒ 卡在**转化**，不是卡在曝光；
- 下单人数中 **新客 18 / 老客 28（老客 60.9%）**。

### 2.3 三个刺眼的事实

1. 🔴 **活动订单占比 100%**（46/46）⇒ **不投活动就没有单**，完全没有自然流量。
2. 🔴 **上架 44~45 个商品，日均只有 6.0 个有交易（区间 1~15）** ⇒ 有交易率约 **13.4%**，
   86% 的 SKU 七天一单未出。**（注：R226 记录的"上架商品数 44"是单日快照，非合计）**
3. 🔴 **复购几乎为零**：近 30 日复购人数逐日仅 19~23 人（均值 21.4），近 7 日复购 0~5 人。
   ⇒ 顾客**来一次就走**，与"活动驱动的羊毛客"特征一致。

### 2.4 履约侧反而干净

差评 1 单 / 投诉 0 / 出餐超时 0 / 商责退单 0 / 拒单 0 / 库存不足 0 ⇒ **问题不在履约质量**。

## 三 堂食（美团收银）7 天经营诊断

**盘子**：265 个 SKU · 销量 3,280.3 · 销售额 33,146.20 · 收入 30,319.70 · 优惠 2,826.50（8.53%）。
✅ 我方逐行聚合与表内「合计」行**四项全部一致**（数量/销售额/收入/优惠）⇒ 解析口径正确。

### 3.1 🔴 单 SKU 依赖到危险程度

| 名次 | 菜品 | 销售额 | 占堂食 |
|---|---|---|---|
| 1 | **快餐15元** | 13,950.00 | **42.09%**（销量占比 28.35%） |
| 2 | 龙凤呈祥硬老龙凤/盒（烟） | 1,275.00 | 3.85% |
| 3 | 旧国宾（酒） | 1,045.00 | 3.15% |
| 4 | 小面 | 1,033.00 | 3.12% |
| 5 | 抄手 | 940.00 | 2.84% |

**一道「快餐15元」= 全部堂食的 42%，比第 2~5 名加起来还多。** 它的优惠率 15.07%（优惠额 2,101.63，
占全店优惠总额的 **74.4%**）⇒ 这其实是**折扣套餐位**，不是普通菜品。

### 3.2 🔴 长尾极长，SKU 严重臃肿

- 帕累托：**前 35 道（13.2% SKU）才到 80%**；前 76 道（28.7%）才到 90%。
  （健康的菜单通常 20% SKU 覆盖 80%。）
- **217 道菜（81.9%）7 天销售额 < 100 元**；
- 末位混入**非菜品 SKU**：鞋刷、洁柔抽纸、真知棒棒糖、旺旺碎冰冰、各色雪糕、康师傅绿茶/冰红茶……
  ⇒ 🔴 **会污染"食材成本率 / 菜品毛利率"口径**，M3 侧必须加白名单过滤。

### 3.3 🔎 招牌菜失灵（本轮最反直觉的发现）

| | 堂食 7 天 | 团购套餐内 |
|---|---|---|
| **耙牛肉（半斤）** | **13 份 / 412.83 元 = 堂食的 1.25%** | **146.83 元 = 套餐销售额的 16.54%** |

⇒ **招牌菜堂食几乎无人单点，全靠团购套餐走量。**
推论：门店的"招牌"目前**只在团购场景被消费**，堂食点单结构（快餐15元 + 面食 + 烟酒）与品牌定位**背离**。

### 3.4 优惠结构：钱主要贴给了酒水饮料

优惠额 Top（除快餐15元外）集中在东鹏系列与国宾：

| 菜品 | 优惠额 | 销售额 | **优惠率** |
|---|---|---|---|
| 东鹏补水啦电解质饮料白桃味1L | 59.00 | 120.00 | **49.17%** |
| 东鹏大咖生椰拿铁咖啡饮料500ml | 56.53 | 119.00 | **47.50%** |
| 国宾罐装 | 83.27 | 210.00 | **39.65%** |
| 东鹏特饮 | 197.97 | 705.00 | 28.08% |

⇒ 饮料最高**打到 5 折**。M3 算这些单品的毛利时必须用**折后收入**，否则毛利虚高一倍。

## 五 🔴 数据质量清单（本轮最可直接落规范的部分）

> 以下 5 条**全部由机器比对得出**，可直接作为 M3.33 阶段② 的解析与清洗规则输入。

1. **近似重复 SKU（同一实物、两种写法，未归并）**
   - 「小料」35.89 元 ↔ 「自助小料」29.55 元
   - 「联系吧员免费停」46.18 元 ↔ 「联系吧员免费停车」26.85 元
   ⇒ 不归并 ⇒ 单品口径被拆散；**归并错** ⇒ 把两个真菜品合成一个。必须走**显式别名表**，不能用模糊匹配自动合。
2. **两平台「销售额」列口径不同**（同规格套餐差 **2 倍**）：
   美团-火锅4人餐 17 行 / **376.00 元**；抖音-火锅四人餐 16 行 / **188.00 元**。
   ⇒ 跨平台求和的任何指标（套餐销售额、单品销量）**必须先对齐口径**，否则美团被系统性高估。
3. **堂食菜品表混入非菜品 SKU**（鞋刷 / 抽纸 / 棒棒糖 / 碎冰冰 / 雪糕 / 瓶装饮料…）
   ⇒ 口径：**食材成本率、菜品毛利率只对"厨房出品"计算**，需按白名单/黑名单过滤。
4. **快照类指标不可求和**：`上架商品数`（44~45）、`有交易商品数`（1~15）、
   `近7日/近30日复购人数`（0~5 / 19~23）都是**逐日快照**，7 日行**相加无意义**。
   ⇒ 解析器必须把它们标为 snapshot，聚合时取**末值或均值**。
5. **`投入产出比` / `营销力度` 口径未定**（与 R226 存疑同源）：
   由「营业额 ÷ 投入产出比」反推的基数 = 53.03 / 388.41 / 94.67 / 128.02 / 62.97 / 268.96 / 173.41，
   与「活动总补贴」「商家活动成本」**均不相等** ⇒ **本数据判不了，不许当前置依赖**。
