## 1 M2 锚点（本轮已实现 · 已上云）

### 1.1 它是什么

用户填一个「预计月营业额」⇒ 云端按各指标参考带的**中值**反算各项参考**金额**，
显示成输入框的**灰字起点**（placeholder）+ 参考区间卡上的「参考 ¥X」。

### 1.2 🔴 边界（本轮的**设计红线**）

> **参考值只当提示，绝不替你填。**

理由：M2 是"开店前的前瞻沙盘"，参考值来自**行业平均**。一旦自动填进 `yuan`，
用户不核对就直接得到一份"全绿、保本点很健康"的结论，而他的真实租约/人工可能完全是另一个量级
⇒ 结论从"参考"变成"误导"，**比不给还坏**（等于替用户自证合理）。

这条红线**在落地时是零守卫的**（见 §3 R128）。

### 1.4 反算口径（为什么中值要先定标）

```
const mid = round1((b.lo + b.hi) / 2);   // ⚠️ 先定标到 1 位小数
out.push({ key, indKey, pct: round1(mid), fen: Math.round(rev * mid / 100) });
```
若不定标，展示 22.5% 而金额按 22.45% 算 ⇒ **客户拿计算器对不上**（自洽性缺陷，本轮自查发现）。

### 1.5 双键归属（最易错处）

`key` = 固定项 key（`rent|labor|utility|manage`，供输入行匹配）
`indKey` = 指标 key（`rent|labor|energy|manage`，供区间卡匹配）
⚠️ **能耗**：固定项叫 `utility`、指标叫 `energy`。映射**单源留在后端**，前端不得自己猜。

### 1.6 手算核对（脚本算，非手抄）

| 场景 | 房租 11.5% | 人工 19.5% | 能耗 4% | 管理 7.5% |
|---|---|---|---|---|
| 正餐·二三线·10 万 | ¥11500 ✓ | ¥19500 ✓ | ¥4000 ✓ | ¥7500 ✓ |
| 一线（房租×1.2 / 人工×1.15） | 13.8% → ¥13800 ✓ | 22.5% → ¥22500 ✓ | — | — |

未填 / 零 / 负数 / NaN ⇒ `[]`（不编造）；红警（利润为负）时参考值**仍在**（它是"行情参照"不是"结论"）。

## 2 M1 结果页转型（**本轮只登记 · 未动工**）

### 2.1 对「你觉得对吗」的回答：**对**

这是产品从「工具」变「顾问」的关键一步。**但补四条边界**（已写入主计划 §3）：

1. **不许变成承诺**——「你 3 个月内把房租谈到 X 就能盈利」是**不可给的**。只给方向与量级。
2. **必须过禁用词守卫**——整改话术最容易写出「保证 / 一定 / 稳赚」，须挂 `TERMS.forbidden`。
3. **时间窗须有依据**——租约到期、账期、摊销年限都能推出时间；凭感觉写「1 个月」= 编造。
4. 🔴 **优先级不许平铺罗列**——房租超标但租约还剩 8 个月 ⇒ 应先拉毛利率，**而不是**去谈房租。
   平铺 5 条"整改方向"等于把判断责任推回给用户（= 没做顾问）。

## 4 🔴 P0 真缺陷：round113 的参考区间在真机**零生效**

### 4.1 现象（实测，非推测）

用 `_probe_r114.js` 直调 `calcSandbox`，空表单 → 返回：
```json
{"error":"INVALID_PARAM","msg":"fixed_items 至少要有一项（房租/人工等）"}
```
即 round113 特意"前移"到填表页顶部的行业参考带，用户**根本看不到**——进页面就被拒，
还收到一句带英文 key 的报错。**round113 的门禁 100/100 全绿，因为没有任何套件跑过"空表单"这条路径。**

### 4.2 修法

删掉 `validate.js` 的 `if (!fixed_items.length) return err(...)`，
换成 9 行注释说明**为什么这不违反 fail-closed**：

- 「**没填够**」是**页面语义**（由前端 `hasFixed` 控制不展示测算结果），**不是入参非法**；
- 放宽的只是**非空**，**白名单 / 重复 / 类型**校验一条没松（仍然 fail-closed）。

## 5 两处体验缺陷（本轮自查发现并修）

| 缺陷 | 症状 | 修法 |
|---|---|---|
| 整页 `loading` 闪烁 | 每改一个数就整页"加载中"，输入框重绘、**易丢光标** | `loading` **只首算置位**（`onCalc(true)`） |
| **请求乱序** | 云函数有网络延迟，**旧响应可能晚于新结果返回** ⇒ 屏幕显示旧值 | 加 `_seq` 序号，`if (seq !== this._seq) return;` 丢弃过期响应 |
