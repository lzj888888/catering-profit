## 二、整体优化思路（三条主张）

**主张 A：给 M3 建一个"枢纽首页"，入口不再寄生。**
点首页 M3 → 先进 M3 首页（4 张分区卡），再进各功能。以后加"套餐分析""外卖分析"＝加第 5、6 张卡，**列表页顶部不再膨胀**（直击 P2/P7）。

**主张 B：列表页顶部只留"找东西"，跳转按钮全部撤走。**
顶部 = 搜索 + 筛选 + 结果计数，「新增」改为**常驻顶部**（右上角圆钮或吸顶条），解决 P5。

**主张 C：按钮尺寸不动，只减数量。**
🔴 `.btn-small { min-height: 88rpx }` 是触控硬红线（老人机/手抖场景），**缩小按钮＝引入误触**，所以正解不是排版压缩，而是**收纳**：5 个平铺 → 1 个「⋯」浮层。20 张卡省掉约 20 行噪音（直击 P3/P4）。

## 三、分区详细方案

### 3.1 新增 M3 首页（枢纽页）

四张分区卡，**左侧 6rpx 色条 + 标题 + 一行副文案**（说清"它是干什么的"）：

| 分区卡 | 副文案（说清用途） |
|---|---|
| **菜品及套餐成本卡** | 建卡 · 查卡 · 算成本　|　已有 N 张 |
| **原料库（价格档案）** | 改一次价，用到它的菜全部跟着变 |
| **外卖菜品成本及利润** | 一单卖出去，到手多少、赚多少 |
| **对账** | 账本上的数 vs 菜品卡推出来的数 |

副文案必须回答"我能拿它干什么"，而不是重复标题。

### 3.2 成本卡列表页（改后）

- 顶部：`搜索框 + [+]新增`（同一行，右侧圆钮）；下一行 `筛选▾ + 共 23 张 · 套餐 4`；批量同步降级为**右上角文字链**
- 卡片：`[色条] 菜名 + 标签` / `成本 ¥18.60 · 毛利 62% · v3`（**三行压一行**）/ 右侧 `⋯`
- 「⋯」浮层：置顶 → 版本历史 → 复制这张卡 → 同步至原料最新价 → **删除**（红色、沉底、上方加分隔线）

### 3.3 原料库列表（同构改造）

4 个平铺 → 右侧「⋯」：置顶 / 影响面 / 编辑 / 删除（红）。

### 3.4 成本卡编辑页

现状底部只有「保存」。建议补一条**底部操作条**：`删除` 走「⋯」或确认弹窗；「版本历史」「同步最新价」从列表页「⋯」进入，编辑页不重复放。

## 九、可迁移的方法论（下次直接套用）

1. **"页面松垮"先分辨是「尺寸问题」还是「数量问题」**：触控尺寸是硬约束时，只能减数量（收纳），不能压尺寸。
2. **入口寄生是分类混乱的头号成因**：功能入口挂在别的业务页顶部，做得再整齐也说不清；给它一个枢纽页。
3. **每张卡重复的操作区，成本是 N 倍**：列表里"看起来只是一个卡片"的改动，乘以 N 张卡就是整页噪音。
