## §2 前面卡了两次，两个都不是"功能没做完"，而是我操作上的问题

### ① 入口找不到（我给了错的路径）

我上一轮说"底部「成本」"，实际底部是**「配方」**。正确路径：
**配方 → 外卖每单赚多少（说明写着"销量表也在这里导入"）→ 顶部「数据导入」tab → 选择销量文件**。

### ② 「云调用失败」（我的部署把依赖抹掉了）

`cli cloud functions deploy` 有 `-r`（云端 npm install）。**我三次部署都没带**：

```
不带 -r：只上传 22 个源码文件（88.8 KB）⇒ 把线上 node_modules 抹掉
        ⇒ require('xlsx') 失败 ⇒ 整个函数起不来
        ⇒ callFunction fail ⇒ 前端弹「云调用失败 · importSalesBill」
```

判据（可复用）：`cloud functions download` 把线上包拉下来看文件数 ——
**22 个 = 缺依赖；6664 个 = 正常**。

修复后，用「线上代码 + 线上 node_modules」在本地跑了一遍解析链，结果与真机一致。
