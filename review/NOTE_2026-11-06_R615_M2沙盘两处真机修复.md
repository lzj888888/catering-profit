## ② 场景矩阵测算输入框裁掉数字上半部分

- 根因：`matrix.wxss` 的 `.minp`（矩阵页 20 个 input）和 `.real-in`（实际营业额框）
  只给 `padding` + `font-size`，**没有 `line-height` / `min-height`**。
  小程序 `input` 默认行盒按字号算，叠加 14rpx 上下 padding 后，部分机型/系统字号下
  文字上下被裁（上半部尤其明显）。不报错、静态守卫看不见，只有真机看得见。
- 修法：`.minp` / `.real-in` 补 `line-height:40rpx` + `min-height:64rpx`，padding 略收紧。
  **刻意不写死 height** —— 写死高度在用户调大系统字体时会再裁一次。
  字号 28rpx 守 AD-G1；同页 `.cash-inp`（height:64rpx / 30rpx）是既有正常对照。
- 覆盖盘点：矩阵页 25 个 input = 20 个 `.minp` + 1 个 `.real-in` + 4 个 `.cash-inp`，
  全部落在已修/本就正常的类里，没有漏网裸 input。
