## 0 一句话

设计稿里「AI 三方」的**判**这一半（授权写 R403 / 读 R405 已落）此前是空的 ——
有授权就等于能出站。本轮补上 `canSendToModel`：授权态 → 用途 → 样本量三关，任一不过就拒，并显式给降级路 `fallback:'L0'`。

## 1 为什么要这道门槛（不是加个校验那么简单）

k-匿名失效的形态是**聚合值退化成原始值**：单店 1 个 SKU、单日 1 笔订单时，
"均价 / 偏离度"反推回去就是那一笔的原始金额 —— 此时的"聚合"等于没脱敏。
所以门槛判的不是"能不能存"（结论本身已聚合，存不受限），而是**"这批样本够不够大到看不出单笔"**，只放在出站那一刻。

## 2 落点为什么是 `cloudfunctions/common/aiGate.js`

| 候选 | 为什么不选 |
|---|---|
| `utils/`（小程序侧） | 客户端门槛 = 改个包就绕过；隐私门槛必须在发数据的那一侧。 |
| 某个云函数的 `service.js` | 出站函数**还不存在**（#29 授权页也 blocked），写进某个读侧函数 ⇒ 将来出站函数 require 不到，必然复制第二份。 |
| `common/` 单源（**已选**） | 未来任何出站函数 `require('./common')` 即可命中；由 `sync_common` 派生，与 `indicatorRef` / `salesBillId` 同一范式。 |

代价（已实测）：`sync_common` 使 55 个函数目录各多一份 `cx_aiGate.js` + `cx_index.js` 多一行导出 = **110 个文件**。
按 R389 结论，**没有引用该符号的函数带旧副本无害**，本步**不部署任何云函数**（没有调用方）。

## 3 三关 + 为什么不在本函数里再判一遍四态

```
① 授权态：consent.state 必须 'active'，且 policy_stale/need_regrant 不得为真
② 用途  ：purpose ∈ {diagnose, pricing, expand} 且 ∈ consent.effective_scope
③ 样本量：lineCount ≥ 5 且 supplierCount ≥ 3
```

🔴 `consent` 入参**必须是 `getAiConsent` 的出参**（含 `state` / `effective_scope` / `policy_stale`），不是原始 doc：
四态判定（含"revoked 优先于 expired"、`expire_at=0` 不当作过期）已在读侧落过一份。
本函数再判一遍 `revoked_at/expire_at` 就是**同一语义的第二份实现** —— 改一处漏一处那天，
会出现"读侧说已撤回、出站侧说还能用"，而老板只会看到其中一个。
⇒ 传原始 doc（无 `state`）直接判 `consent_unjudged`：**不猜、不兜底**。

## 4 出参契约（纯函数，零 IO）

```js
canSendToModel({ consent, sample: {lineCount, supplierCount}, purpose })
→ { allow: boolean, reason: string, fallback: 'L0' | '', need?: {lineCount, supplierCount}, got?: {...} }
```

- `reason`：`ok` / `input_invalid` / `consent_unjudged` / `consent_not_active` / `policy_stale` /
  `purpose_invalid` / `purpose_not_granted` / `sample_shape_invalid` / `below_line_floor` / `below_supplier_floor`
- 🔴 拒时 `fallback` 恒为 `'L0'`：退回规则话术（"这项偏离你自己的历史，请核对单据"）是**有答案**的；
  留空会让上游自己编同业对比 —— 那等于拿别家区间套这家店，凭空造数。
- 非法计数（字符串 `'5'` / 小数 / 负数 / NaN / 缺字段）一律 `sample_shape_invalid`，**不做 `Number()` 静默归一** ——
  与 `yuanToFen` 把 `"12,000"` 读成 0 同族：静默归一是"值错了但零报错"，而这里是隐私门槛，宁可拒。
