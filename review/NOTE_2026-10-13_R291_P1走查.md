### 问题 1：**运行路径不可达**（首页 data.mode 永远不等于 `'reverse'`）
- `pages/sandbox/index.js:326` `mode: 'forward'`（初值）
- 全页**唯一**一处 `setData({ mode })` 在 `:630`
- 但 `:626-629` 在 `mode === 'reverse'` 时**提前 return**：
  ```js
  if (mode === 'reverse') { wx.navigateTo({ url: '/pages/sandbox/matrix?mode=reverse' }); return; }
  ```
  （R290 v5 李老师拍板：找店 = 直接进场景矩阵页，首页恒为 forward）
- **实测（a2）**：首页点「找店」→ `before{route:pages/sandbox/index, dataMode:forward}` → `after{route:pages/sandbox/matrix, dataMode:reverse, title:"场景矩阵测算 · 寻找铺面", subtitle:"还没拿铺子：扫一批房租档位，看哪个档位扛得住"}`
⇒ 首页永远不会进入 reverse 分支，**这两个 Rev 文案在运行路径上无用武之地**。

### 问题 2：**即便可达也取不到值**（`t` 白名单漏登记）
- `pages/sandbox/index.js:213-214` 装配视图模型时只登记了 `l1Title` / `l1Guide`，**没有** `l1TitleRev` / `l1GuideRev`
- **实测（a3，强制 `setData({mode:'reverse'})`）**：
  ```

  hasL1TitleRev    = false          ← 键根本不在 data.t 里
  hasL1GuideRev    = false
  l1TitleRev       = "<undefined>"
  tKeysL1          = ["l1Title","l1Guide"]
  ```
- **渲染层证据（03 截图 OCR）**：切到 reverse 态后，标题行「**你这家店，先答5个**」与引导行**双双消失**，且「想开的店，先填5项」/「按你打算的业态和预算填，5个好估」**均未出现** ⇒ 该位置渲染为**空白**
