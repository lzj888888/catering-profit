## 二、补的真缺口：影响面页下拉刷新

`pages/metrics/impact.json` 一直是 `enablePullDownRefresh: false`，页面也没有 `onPullDownRefresh`。

后果很具体：老板在原料页把采购价从 6 元/斤改成 7 元/斤 → 回到「涨价影响面」→ **看到的是上一次
dry_run 的结果**（页面没有任何时间戳）⇒ 会把旧影响当成新影响，这正是它存在的意义（改价前先看影响谁）。

改法（两行配置 + 一个 handler）：

```json
"enablePullDownRefresh": true
```
```js
onPullDownRefresh() {
  const done = () => wx.stopPullDownRefresh();
  this.load().then(done, done);   // load 内部已 catch，两路都停刷新，不会转圈不停
}
```

- 没做"自动刷新"：dry_run 要走云端算全店受影响卡，进页就刷会拖慢首屏；
- 没做"数据时间戳"：属于另一个改动（要后端回 `computed_at`），先记着。
