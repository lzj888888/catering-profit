## 3 判定：打包费归属

| 平台 | 判定依据 | 结论 |
|---|---|---|
| A | 「商品折后总价」= 菜品 + 包装费；**且有一单无包装费时恰等于菜品** | **含** |
| B | 「商品折后总价」= 菜品 + 打包费（两单同值） | **含** |
| C | 「商品优惠后金额」= 菜品 + 打包费 − 商家活动补贴（两单） | **含** |

**⇒ 商户端「商品总额」栏 = 含打包费。三个平台一致，6 个样本零反例。**

**证据层级（必须分层看）**

- **L1（强 · 本件新增）**：三平台商户端**订单详情页**的计价链 —— 截图实证。
- **L2（中 · 既有）**：美团官方 API 文档措辞「`商品金额 = 商品原价 + 包装盒费用`」（§7 已记）—— 与 L1 同向。
- **L3（弱 · 仍是推断）**：**账单 Excel 的列名与口径** —— 上轮 WebSearch 得，**未经任何真实账单验证**。

⇒ **L1 + L2 同向，但都不等于 L3**（订单页 ≠ 账单导出）。V2 **不能据此判「已闭合」**。

## 4 附带发现（5 条，均可直接用于规范细化）

1. **三平台佣金「基数 + 费率」三者互不相同**（推导）：
   - A ≈ **3.5%** × 商家优惠后金额（22.63 / 24.30）
   - B = **5.0%**（页面自证）× （商品折后总价 − 商家订单优惠 − 商家配送补贴）
   - C ≈ **6%** × 商品优惠后金额（20.51 / 21.08）
   ⇒ **佣金绝不可能由客户自算** ⇒ 反向印证我方「佣金一律从账单取数（手填 / 粘贴）」的设计是对的，
   且**不应在任何文案里写死费率**。

2. **平台展示值之间存在「小额不闭合差」**（实测 5 处）：
   A1 `0.06`、A2 `0.60`、B1 `0.33`（待核）、C1 `0.30`、C2 `0.50`。
   ⇒ ① A.11.4(b) 设「阈值 50 元 / 不判错」**是必要的**，不是宽松；
   ② **对账口径应以平台「结算金额 / 商家应收款」为准**，不得用展示字段自行推导 —— 否则会永远差几毛。

3. **「平台对顾客的补贴」只在顾客视角弹窗出现、不进商家账**
   （A：平台红包 −2.33；B：神券·平台补贴 −6.0；C：包装费实付 0.00）
   ⇒ 反向印证我方**总额法不记平台补贴**是对的（记了会虚增收入与费用两边）。

4. **「商家配送补贴」是独立字段**（A：−3.70 / −4.00；B：−3.3 / −3.6）
   ⇒ A.11.3 的 `exp_mkt_takeaway_delivsub`（sort 40）现有取数路径写作「账单中商家承担的固定配送费 / 距离加价」，
   建议**对准订单页可见名**「**商家给顾客的配送补贴**」，客户才找得到。

5. **同店不同单，打包费可有可无**（A1 有 2.00 / A2 无）
   ⇒ 打包费必须**逐单求和后从账单取**；任何「按菜品金额 × 固定比例」的估算都会算错。

## 5 与我方口径的关系（结论：**口径本体不动**，只提可见性）

**现行口径**（`terms.js:296` `fastHint` / `:323` `scopeGuide`）：`商品总价 + 打包费 + 商家活动补贴`。

**风险**：若账单「商品总价」列**已含**打包费（L1/L2 倾向此），客户照此相加 ⇒ **收入多算一次打包费** ⇒ **利润虚高**。

**但本轮不改口径**，理由有三：

1. **L3 未闭合** —— 订单页 ≠ 账单。若账单确实「商品总价 / 打包费」**分列且不含**，
   现行三项口径就是**正确的**；此时改动反而会**漏记**打包费。
2. **A.11.4(c) 已经把这个风险设计成可观测**：`reconcile()` 的 `packaging` 态
   （差额恰等于打包费 ⇒ 提示「请核对账单『商品总价』是否已含打包费」）**已在代码里**（`utils/takeaway.js`）。
   ⇒ 口径未证实 ≠ 方案不能用 —— **把不确定做成可观测**即可（与 §7 既有纪律一致）。
3. 改口径要动**术语双副本 + 规格 + 断言 + 页面**，而**没有账单就无法验证改动是否正确** ⇒ **不许靠推理改口径**（A.11.7 原话）。

  而**默认路径是快速模式**（round96 已记的洞）⇒ 最主流的用法**看不到这条自检**。

## 7 拿到账单 Excel 后要核的清单（一次可定案）

1. 账单是否**存在**「商品总价」列？是否有独立「餐盒费 / 打包费」列？
2. **取任意一行**，看 `商品总价` 是否 = `该行菜品金额之和 + 该行打包费`：
   - 等 ⇒ **已含** ⇒ 收入口径应改为「商品总价（含打包费）+ 商家活动补贴」，**打包费框只作为拆解展示**；
   - 不等 ⇒ **不含** ⇒ 现行三项口径正确，**不动**。
3. 用 A.11.4(b) 配平式**反证**：客户按三项填完 + 填「结算金额」⇒ 看差额是否**恰等于打包费合计**。
4. 顺带确认 A.11.7 的 **V1（账单列名）/ V3（商家应收款可取用）/ V4（账期）** —— 同一份账单可一并核掉。
