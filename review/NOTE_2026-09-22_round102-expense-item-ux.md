## 1 改动清单（4 个页面文件 + 2 个守卫）

### 1.1 预设项**可删**（诉求①）

| 位置 | 改法 |
|---|---|
| `pages/month/input.wxml` 费用段删除键 | `wx:if="{{g.expanded && !r.fixed && g.rows.length > 1}}"` → `{{g.expanded && g.rows.length > 1}}` |
| `pages/month/input.wxml` 收入非堂食段删除键 | 同上（两处一次性放开） |
| **堂食渠道行** | **保持不动**（`wx:if="{{!r.fixed}}"`）—— 那里的预设渠道**确实**会被 `normalizeDineRows` 补回 |
| 预设项**名字** | **仍只读**（`sub-item-inp` 的 `!r.fixed` 保留）—— 防同一笔费用出现两个名字 |

**为什么原判据是错的**（本轮实测）：原注释写「清单是单一数据源，装配时必然补回」，但两条装配口 ——
`initGroups` **只铺一个空行**、`rebuildFromItems` **只按后端 `sub_items` 重建** —— **从不补回预设项**。
那套「删了会回来」的逻辑只在**堂食渠道**（`normalizeDineRows`）成立，属**误移植**。
依据：规范 A.2 第 71 行明文「费用项支持老板自定义增删」。

### 1.2 「未用预设项」只读提示行（诉求②的可发现性）

- **JS**（`input.js::decorateRows`，🔒 唯一装配口）：顺带算 `g.unused` / `g.unusedText`
  —— 该类「还没用上的预设项」；堂食排除在外（`dine_in` ⇒ 空数组）；清单取自 `g.items`（不写死）。
- **terms 双副本**：新增 `presetHintPrefix: '还没加的有：'` / `presetHintSep: '、'`（js 只做 join，页面零硬编码）。
- **WXML**：费用段与收入非堂食段各加一行 `.hint.preset-hint`，点击 `catchtap="onOpenPresetPick"` **直开**已有的预设面板。
- **WXSS**：`.preset-hint { margin: 4rpx 0 0; }` —— ⚠️ 初版写了 `font-size: 24rpx`，被 `ad-gates G1`（字号 ≥28rpx）**当场判红**，已去掉（字号继承 `.hint`）。**这是真缺陷，不是误报。**

**为什么不做「全铺 23 项 + 隐藏机制」**：全铺与「能自由删除」逻辑冲突（删了下次又回来），
要兼得必须再加一套「隐藏项」持久化字段 —— 成本高一档。**先要简单对，再要好**：
本轮把「能删 + 有提示」做扎实，等实际用出「确实想一眼看全」再上隐藏机制。

### 1.3 分平台佣金小计**移到佣金行之后**（诉求③）

- 现状：`mk-plat` 块**嵌套在 `.group-ops` 里**（即挂在「+ 添加细项」按钮之后），离它汇总的「外卖平台佣金」隔了 8 项。
- 改法：块移入 `.sub-block` 的**行循环内**，按 `ri === g.mkPlatAfterRi` 定位（js 单源算出的**行下标**）。
- 兜底：营销组**没有**佣金行时（老板删了 / 从没加过），该下标退化为**末行下标** ⇒ 块仍可见、功能不丢。
- 项名单源：`terms.takeawayMode.reconcileRoles.commission`（页面零硬编码）。
- **只动渲染位置，不动数据顺序** —— 9 项 `sort_order` 是建库单源锁定的、有守卫守着，不会撞单源。

## 4 未做 / 改主意（如实登记）

**「核算方式」标题保留 —— 我撤回了上一轮的建议。**

上一轮我建议「去掉『核算方式』标题，让食材与装修设备各自成为平级段」。
本轮读源码发现该标题的**实际文案是**：

```
calcMethod.secTitle: '这两笔钱怎么算'
calcMethod.secHint:  '随时能改，改了不影响已经填好的数字'
```

它不是行政标题，而是**面向老板的大白话**，且正好回答诉求④的困惑
—— 把「食材消耗 / 装修设备」明确定位成**「两笔钱」**（不是费用）。删掉它反而会让人以为「装修设备」是新的一类费用。
⇒ **保留**，原建议撤回。

**「摊销算不算费用」的答案**（规范 M1 第 38 行原文）：

```
全要素真实利润 = 营业收入 − 总费用 − 真实消耗 − 当月摊销总费用
```

| 层 | 摊销在不在 |
|---|---|
| 毛利 | 不在（毛利只扣食材） |
| 经营参考利润 | 不在 |
| **全要素真实利润** | **在，但是独立减项** |
| 费用合计 / 费用行 | **不进** |

⇒ **实质是费用，形式上是独立减项**；所以它**不该排进「费用」段**，现在放在「这两笔钱怎么算」段是正确的。
