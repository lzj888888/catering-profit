## 二、契约交叉核对结论（云出参 ↔ 页面消费 ↔ wxml 渲染，逐字对齐，无错配）

### 2.1 读侧排名 `rankReview` 出参 ↔ 页面 `fmtRanked` 消费

`cloudfunctions/getDishReview/service.js` 的 `rankReview` 输出：

```
{dish_key, name, card_code, qty, amountFen, totalCostFen, grossFen, marginPct, snapshot_month, zeroAmount}
```

页面 `index.js` 的 `fmtRanked` 与 `setData` 逐字读取上述字段：`amountFen`（金额分）、`totalCostFen`（成本分）、`grossFen`（毛利分）、`marginPct`、`snapshot_month`（快照月）、`zeroAmount`（零金额标记）——**字段名、命名风格、单位（分）全部对齐**，无缺失、无多余、无拼写漂移。

### 2.2 合计 `totals` 六字段 ↔ 页面渲染

`service.js` 的 `totals{qty, amountFen, costFen, grossFen, dishCount, unmatchedCount}` 与 `TOTALS_FIELDS` 六字段常量一致；页面 `setData` 后由 `index.wxml` 的合计区渲染，字段键逐字对应。外卖分平台 `by_platform[p].{ranked, unmatched, totals}` 结构也与页面 `wx:for` 遍历口径一致。

### 2.3 外卖 `takeaway`、未匹配 `unmatched`、映射 `mapping`、区间 `range`、覆盖 `coverageC`、自助 `buffet`

- `takeaway`：空则 `null`，页面以 `wx:if="{{takeaway}}"` 安全承接；非空时字段键与堂食对称。
- `unmatched`：循环内仅 `<text>`/`<picker>`，无受控 `<input>`，`wx:key="name"` 安全。
- `mapping`：`wx:key="dishKey"`；读侧 `mapIndex` 键与写侧落库键逐字对齐（见 §四）。
- `range{from,to,days,covered_days,has_interval,has_unknown}`：页面区间标签消费完整，无遗漏字段。
- `coverageC.*`：粒度感知覆盖天数（R574/#110），页面覆盖率分子/分母口径与云出参一致。
- `buffet.benchmark.*`：自助餐基准成本结构渲染字段与云出参对齐。

**结论：读侧全量出参字段 ↔ 页面消费 ↔ wxml 渲染三层逐字对齐，未发现任何字段错配或口径漂移。**

## 四、`saveDishMapping` 省略 `platform` 的有意设计说明（非缺陷）

读侧 `getDishReview` 的 `mapIndex` 以 `'|'+k` 兜底键匹配；写侧 `saveDishMapping` **有意省略 `platform`**（页面 `onPickCard`/`onUnlinkMap`/`onSaveBatch` 三处写入口均不传 `platform`），其效果为：**映射对所有平台生效（跨平台兜底）**，而非按平台分别映射。

配套一致性核对：

- 键口径逐字对齐：`buildMapKey = normKeyPart(platform)+'|'+normKeyPart(dishKey)`；落库 `external_ref_id` = 原始 `dish_key`（**不归一**），与读侧 `mapIndex` 键逐字对齐。
- `api.call` 注入 `shop_id` 与 `getDishReview` 读侧一致，保证读写同店上下文。
- `BATCH_CHUNK=20`（`dishMapSuggest.js`）≡ `MAX_BATCH=20`（`saveDishMapping/service.js`）：由 `check_dish_mapping_write.js` 的 D-② 判据钉死，防止前端分批粒度与云批量上限漂移。
- `findBatchConflicts` 批内去重（整批拒）；`judgeMappingAction` 四态 `created/updated/cleared/noop`；`RATE_STORE` 模块级单例限流；幂等预检——写侧健壮性与读侧口径一致。

**结论：省略 `platform` 是有意设计（跨平台兜底），非契约缺陷；键口径、批量粒度、店铺上下文三方均对齐。**
