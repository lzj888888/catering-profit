## A 段 · 今天新增的五处（最高优先，约 6 分钟）

### A1 · 三项刚性卡（M1 月度结果页）

**怎么到**：底部「核算」→ 点一个**已经录过账**的月份 → 结果页 → 往下滚，
找标题为「**三项刚性压了多少**」的卡片（在损益表下面、指标区里）。

| | 你会看到 |
|---|---|
| ✅ 对的样 | 一张卡片，标题「三项刚性压了多少」；标题右边一个大百分比（如 `72.3%`）；下面两行灰字：一行是「警戒线以内 / 已过警戒线」之类 + 行业区间，另一行是「房租 + 人工 + 食材，三项占了营业额的几成。这条线过了，再忙也是白忙」 |
| ❌ 不对① | **整张卡片完全没有**（滚动到底也找不到）→ 判据写错或条件不满足，要查 |
| ❌ 不对② | 百分比显示 `0%`，但你这个月**房租和人工都填了** → 缺项被按 0 补了，是错账 |
| ❌ 不对③ | 显示「待补」之类，说某项没填，但你在录入页确实填了 → 取值链路断了 |
| ❌ 不对④ | 百分比是 `NaN` / `undefined` / `--%` |

> 顺带看：这张卡的百分比，跟你**自己心算**的（食材成本率 + 房租率 + 人工率）差不差太多。
> 差 1 个点以内正常（四舍五入），差 5 个点以上要停下来告诉我。

### A2 · 会员占比报警行（同一页）

**怎么到**：A1 同一页，找「会员销售占比」那一栏。

| 你上个月填的会员占比 | ✅ 对的样 | ❌ 不对的样 |
|---|---|---|
| **留空**（没填） | 什么都不显示 | 显示「低于 20%...」→ 在罚没有会员体系的店，是错的 |
| 填 **15%** | 出现一行红/橙字：「低于 20%，老客没被留住（有会员体系却不卖会员，等于把钱留在桌上）」 | 不出现 → 报警失灵 |
| 填 **恰好 20%** | **不出现**这行 | 出现了 → 边界判错（20% 不该报警） |
| 填 **45%** | 不出现报警 | 出现了 → 判反了 |

### A3 · 底部兜底声明（同一页）

**怎么到**：A1 同一页，**一直滚到最底部**。

| | 你会看到 |
|---|---|
| ✅ 对的样 | 最后有一句灰字：「**仅供参考，经营决策请结合实情。**」 |
| ❌ 不对 | 滚到底**看不到这句话** |

> 这条看着不起眼，但它是**合规要求**（避免被当成财务承诺），必须常驻。

### A4 · M2 净利率提示（选址沙盘）

**怎么到**：底部「配方」→ 找到「开店测算 / 选址沙盘」入口 → 选 **A 区（店已经在开）** → 往下填到「预计月营业额」和「目标月利润」→ 点计算。

**要故意填一个偏高的数来触发它**：

| 怎么填 | ✅ 对的样 | ❌ 不对的样 |
|---|---|---|
| 预计月营业额 **10 万**，目标月利润 **5 万**（= 50%） | 结果区出现一行提示：「目标净利率 50%，高于中小门店常见的 **1~5%**。这个预期偏乐观 —— 不妨把目标利润调低再算一遍，看保本线还扛不扛得住。」 | ① 提示完全不出现 → 接线断了<br>② 提示里的区间和业态不符（正餐应是 1~5%） |
| 同上，但目标月利润改成 **3000**（= 3%，正常） | **不出现**提示 | 出现了 → 条件是"只要填就提"，判反了 |
| 预计月营业额 **留空**，只填目标利润 | **不出现**提示 | 出现「目标净利率 0%」之类 → 除以 0 没兜住 |

> 顺带确认：**它不该改你填的数**。提示出现后，你填的「5 万」还在输入框里，没被自动改成别的。
