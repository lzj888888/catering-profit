## 1. 债一：库存 / 资产页弹窗文案硬编码 → 收归 terms 单源

**问题**：R594 给库存/资产页加的拦截弹窗，标题+正文是**硬编码中文字面量**；而 R595 的矩阵页走的是
`TERMS.matrix.amountBadTitle/amountBadBody`。同一件事两套说法，且术语改名时硬编码那两页**静默失灵**
（弹窗还是老话术），任何"文案单源"守卫也扫不到它们。

**改法**：文案上提到 `TERMS.ui`，三个页面共用：

| 键 | 用途 |
|---|---|
| `amountBadTitle` | 弹窗标题（三页共用） |
| `amountBadBodySave` | 保存态正文，`{list}` 由页面换真实栏名 |
| `amountBadBodyGen` | 生成态正文（矩阵：会被"按 0 **或跳过**"） |
| `amountBadBodyCount` | 函数，栏太多时只报数量（M1 用） |
| `amountBadGoFix` / `amountBadSaveAnyway` | 「去修改」/「仍保存」 |

- `matrix.matrix.amountBadTitle/amountBadBody` **已删除**（含注释说明勿再引用），矩阵改用 `TERMS.ui.*`；
- 库存页栏名取 `t.opening/purchase/closing`（页面原文「期初库存/本月采购/期末盘点」）；
- 资产页栏名取 `T.fAmount`；

## 2. 债二：M1 录入页「只有页顶横幅、保存不拦」

**问题**：`checkAmounts()` 只把计数写进 `data`、**没有返回值**；横幅在 `input.wxml:8`（页顶），
保存按钮在页底 ⇒ 老板滑到按钮时横幅早出视野 ⇒ 读不成的金额**被按 0 存进去、零报错**。
与 R599b 修的外卖页是同一族病（"点了没反应/静默按 0"），只是这条藏在主录入页。

**为什么不用硬拦**：M1 费用行允许**负数**（冲红/退款），`classifyAmount` 把 `NEGATIVE` 判为不可读；
硬拦会把合法录入堵死。⇒ 用**确认弹窗**，默认动作是去核对，但不夺走保存权：

```
title  : TERMS.ui.amountBadTitle
content: TERMS.ui.amountBadBodyCount(n)   // "有 N 处金额栏…保存后会被按 0 计算"
confirm: 「去修改」(不保存)     cancel: 「仍保存」(proceed())
fail   : proceed()                          // 弹窗失败绝不阻断保存（与缺项提示同纪律）
```

- `checkAmounts()` 末尾 `return n;`（原先是 `undefined`）；
- 位置：`onSave()` 里 `proceed` 定义之后、缺项软提示之前 ⇒ **数字错优先于"漏填"**；
- 放在 `proceed()` 之前而非 `save()` 之前：这样「仍保存」仍会照常走缺项提示与归档宽限确认，原流程不被绕过。
