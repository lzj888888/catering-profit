## 1 队列里那条「前置缺口」是错的（先纠记录）

队列 #13 备注写：`getLedger` 只取当月+上月、`listMonths` 零命中 ⇒ 无历史月列表能力，第一步要先扩出参。
实查：仓里**已有** `cloudfunctions/getMonthList/index.js`（批次 4 上线），返回该店**全部**已建档月份 + `is_archive`；
`listMonths` 零命中的原因是**名字猜错了**（真实名 `getMonthList`）。
⇒ 不需要新造接口、不需要改云函数、不需要部署：N 个月历史 = `getMonthList` 拿月份 + 逐月 `getLedger`。

## 2 N 个月历史的输入契约（传输侧照这个拼）

```js
// 1) 月份列表
const ml = await api.call('getMonthList', { shop_id });   // { list: [{ month:'YYYY-MM', is_archive:bool }] }
// 2) 逐月取账（并行；每月的出参就是 getLedger 的 ok 数据）
const res = await Promise.all(months.map((m) => api.call('getLedger', { shop_id, month: m })));
// 3) 直接喂规则层（toSnapshot 认的字段）
const r = buildChecklist({ month: targetMonth, months: res });
```

`month_snapshot` 只用到这几个字段（缺字段 = 没有这一项，不猜）：

| 字段 | 来自 getLedger | 用途 |

| `month` | 同名 | 对齐目标月 / 排序 |
| `account_id` | 同名 | **空 = 未建档月** ⇒ 必须排除，否则「首月之前」全成断档 |
| `income_items[] {category,name,amount_fen}` | 同名 | 收入侧比较 |

| `result.gross_margin_pct` | 同名 | 整店毛利率偏离 |

## 3 规则与阈值（单源 `THRESHOLDS`，改口径只改这里）

| 规则 | 触发 | 方向 | attention |
|---|---|---|---|
| `r1_up` | 本月 ≥ 历史中位数 × 2 且绝对差 ≥ 200 元 | `up` | 费用=high / 收入=normal |
| `r2_down` | 本月 ≤ 历史中位数 × 0.5 且绝对差 ≥ 200 元 | `down` | 收入=high / 费用=normal |
| `r3_missing` | 历史有（≥2 个月有金额）、本月 0 元 | `missing` | high |
| `r4_new` | 历史从未出现、本月 ≥ 200 元 | `new` | normal |
| `r5_margin` | 毛利率偏离历史中位数 ≥ 8 个**百分点** | `up`/`down` | high |

三条口径决定（都是防"误报把清单看废"）：
1. **中位数不用均值**：一次性支出（修设备/年会）会把均值抬高，下个月正常支出就全变异常。
2. **绝对差 + 倍数双门槛**：只判倍数时，50 元 → 120 元也会报（翻倍但只差 70 元），老板核一次就懒得再看。
3. **历史的"有金额月数" < 2 ⇒ 不比**：只有 1 个月做基线，等于拿一次偶然支出当常态。

幅度只给两样：`ratio_pct`（相对自店历史中位数的百分比；毛利率走 `ratio_unit:'pt'` 百分点）+ `band` 档位。
**没有** `amount_diff` / `loss` / `saved` 这类键 —— 也不许后加（自测 E-③ 守着）。

## 4 取证的"两难"与处理

- **会报**：手算锚点 5 项（人工 +150% / 水电断档 / 堂食 −60% / 推广费新增 / 毛利率 −15pt）逐项断言命中。
- **不会报**：房租与历史一致；1.9 倍不报；150 元小额不报；绝对差 120 元不报；只有 1 个月历史时 10 倍涨幅也不报。
- **反恒真**：把 `upFactor` 调到 4 ⇒ 同一输入人工不再报；`downFactor` 调到 0.1 ⇒ 堂食不再报；
  `minHistoryMonths` 调到 4 ⇒ 整体不出项；`marginDeltaPct` 调到 20 ⇒ 毛利率项消失。
  （判据若与阈值无关，这四条会一起绿 —— 那才是假绿。）
- **判据自己踩的坑**：初版 E-①/E-② 拿**带注释的原文**去 grep「挽损」「行业对标」，
  而这两个词恰恰是头注里写的**禁令** ⇒ 禁令把判据喂红。改成扫**剥注释后的代码**即绿。
  与 R298Y「注释把守卫喂成恒真」同一族，只是方向反过来（恒假）。
