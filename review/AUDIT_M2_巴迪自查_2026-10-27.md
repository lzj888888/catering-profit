## 6. 巴迪对 forward 审计员报告的复核（只复核最要命的两条）

### H1「空表单照样出保本数」—— ✅ 成立（已独立复现）
跑 `_audit_m2fwd_engine.js` 场景 A（一个字没填）：
```
fixed_items = ["labor:0","utility:3500"]
保本月营收=5556 保本日均=185 目标月营收=5556 回本=null
指标@目标 = [grossMargin=65%/ok, rent=null%/na, labor=0%/good, energy=63%/bad, manage=null%/na, mkt=2%/good]
```
⇒ 房租没填、人工没填，系统照样给保本数 5,556 元；**人工占比 0% 被判 good（绿色）**。
与 M1「食材没填 ⇒ 毛利率 100% + 判绿带」是**同一类病**：缺输入 ⇒ 最乐观结论 + 零拒绝。

### H3「单页 vs 矩阵管理费口径相反」—— ✅ 成立，但性质是"有意设计 + 跨页不一致"
- `index.js:1822`：`fixedYuan: isReverse ? {} : { rent, manage }`（单页正向带 manage 键 ⇒ 留空=0，不派生）
- `matrix.js:680`：`fixedYuan: { rent: rentYuan }`（矩阵不带 manage 键 ⇒ 走房租×占比派生）
- `index.js:1817-1820` 注释**明写这是有意设计**：`fixed_opt` 以"键是否存在"判用户是否作答，矩阵不传 ⇒ 走兜底（找店小白友好）。

⚠️ 但它**会真撞上**：`goMatrix()`（index.js:1140+）用 `q = ['mode=' + d.mode]`，而 `d.mode` 恒 `'forward'`
⇒ 老板在单页（已有铺面）填完房租 8000 点「场景矩阵」⇒ 矩阵走 forward ⇒ 管理费派生 6,400（单页 0）
⇒ **同一个店、两个页面、保本差约 11,034 元，两边都不报错**。
⇒ 定性：不是"谁算错"，是**跨页口径不一致且不告知**。需李老师拍板：统一成单页口径（矩阵补 manage 键）还是保留双口径但在矩阵页写明"管理费按行业参考值估"。

## 7. 巴迪对 reverse 审计员报告的复核（报告已完成，只是子代理发消息时撞 429）

### P2「现金卡『能撑几个月』被放大」—— ✅ 成立，且比报告说的更严重（代码级铁证）
- `matrix.js:930`：`fixedExAmort = api.fenToYuan(res.fixed_ex_amort_fen, 0)`；而 `utils/api.js:88-92`
  `fenToYuan` 返回 **`v.toFixed(d)` = 字符串**。
- `matrix.js:491-492`：`const rentDelta = rentYuan - (Number(best.rent) || 0); return Math.round(best.fixedExAmort + rentDelta);`
- 实跑：`"14250" + 0` = `"142500"` ⇒ **放大 10 倍**；`"14250" + 3000` = `"142503000"` ⇒ **放大 1 万倍**（正确值 17250）。
- ⇒ 现金卡「每月净流出」→「能撑几个月」**恒不正**：真值 6.5 个月/safe 会被算成「撑不到一个月/危险」。
  **老板会被自己的工具吓退。**
- 修法（1 行）：`Number(best.fixedExAmort)`。

### P1「可承受最高月租恒等于你扫的最高档」—— ✅ 成立（逻辑缺陷，非算错）
- `matrix.js:1008-1013`：`filtered = rows.filter(r => !r.red && marginPct === fixVal)`；`bestVal = Math.max(...filtered.map(r => r.rent))`。
- `red` 来自引擎 `red_alert`，而 `cloudfunctions/calcSandbox/service.js:18` 明写：
  「红警（**唯一**强制指标）：综合变动成本率 ≥ 100% → red_alert=true」⇒ **与房租无关**。
- ⇒ 只要该毛利率不红，**所有租金档都不红** ⇒ `max(rent)` 恒 = 该毛利率下的最高租金档 = dims 上限。
- 实测（审计员）：毛利率 5%、目标利润 50 万，仍报「可承受最高月租 ¥10000」。
- ⇒ 这张卡不是在判断"能不能扛这个租"，是**把老板自己填的上限回显一遍**。
