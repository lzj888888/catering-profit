### 3.2 补齐方式（**扩展既有套件**，零元守卫成本）

挂载点选 **`tools/check_pages.js`**（页面声明守卫），理由三条：
1. 它**已在** `verify_all.js` 的 SUITES 里（line 531）；
2. 它**不在**「套件断言数口径」声明名单 ⇒ 扩展它**不触发** `check_suite_assert_counts` / `check_suite_count_claims` 两座元守卫；
3. 语义贴（"页面面"的守卫管页面面的事），且不改套件数。

新增 ③④⑤ 三族判据 + **反恒真设计**：
- **正负样本互证 ×4**：不存在的 handler 必须被点名、已定义的不得误杀；重复 id 必须被点名、唯一 id 不得误判；
- **四条扫描面下界**：页数 ≥20、绑定总数 ≥100、`api.call` 命中 ≥20、`cloudfunctions/` 目录 ≥30。

**实测**：`✅ 页面声明校验通过（app.json 声明 27 页…；③ 死绑定 **306** 个绑定 0 命中、④ **29** 个云函数调用 0 幽灵、⑤ 0 重复 id）`

**变异回灌**（`_probe_tmp/mut_check_pages.js`）：**3/3 抓到且字节级还原干净**
| 变异 | 病灶 | 结果 |
|---|---|---|
| M1 | `wxml` 绑定不存在的 handler | ✅ rc=1 且点名 `__ghostHandler__` |
| M2 | `api.call('__ghostFn__')` | ✅ rc=1 且点名 |
| M3 | 同页两个相同 `id` | ✅ rc=1 且点名 `__mut_dup__` |

> 🔴 **变异还验出守卫自身一个盲区**：首版判据正则要求函数名首字符 `[A-Za-z]`，
> 而变异样本用下划线开头（`__ghostFn__`）**漏抓** ⇒ 已放宽为 `[A-Za-z_]`。
> 教训：变异不只验"抓不抓得到"，还能验**判据的覆盖面**。
