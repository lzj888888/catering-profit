## 1. 建一道菜能不能 3 分钟看到毛利（R624 / R625）
**怎么走**：配方 → 成本卡 → 新增 → 填菜名 → 加一行料（选原料或填临时原料名 + 单价 + 用量）。

**该看到**
- 停手约 1 秒后，底部横条的成本/毛利率**自己变**（不用点任何按钮）
- 没填完时横条会说「还差哪个数」（第 N 行还差用量 / 填上售价就能看毛利）
- 改了用量不点保存，横条也跟着变

**不对的样子**
- 数字一直不变（→ 自动重算没生效）
- 每打一个字符横条就闪一下（→ 900ms 节流太短，要调长）
- 明明齐了还说"还差用量"（→ 提示判据错）
- 点了「添加」但还没填的空行，报「第 1 行还差用量」（→ 空行判据错，这是设计上不允许的）

## 2. 保存回执会不会报「排第几」（R628）
**怎么走**：接上一步，填售价 → 保存。

**该看到**
- 弹窗：成本 / 毛利 / 毛利率 + **「在你 N 道菜里排第 K」**
- 只有一张卡时，**不出现**排名那一行（只报成本毛利毛利）
- 卡数很多（>1000）时不出现排名 —— 但暂时验不出来，知道有这条就行

**不对的样子**：排名数字与列表里实际高低不符（→ 截断保护失效）

## 3. 成本卡 100 张怎么找（R629）
**怎么走**：成本卡列表 → 点某张卡名字后面的小标签 → 再在搜索框输「牛肉」。

**该看到**
- 点小标签后该卡跳到最前，标签变深色「**已置顶**」
- 点已置顶的标签能取消
- 搜索「牛肉」能搜出**分类或标签**里含牛肉的菜（不只是名字）
- 点标签不会误跳进编辑页（用 catchtap 防冒泡）

**不对的样子**：点标签直接进了编辑页（→ catchtap 被改成 bindtap）

## 4. 导入表认不出时说不说「缺哪几列」（R631）
**怎么走**：渠道营收 → 导入 → 传一张**故意缺列**的表（比如只有日期和总额、没有现金/扫码两列）。

**该看到**
- 弹窗不是「这张看着不像你记的收款日报」这一句就完事
- 而是明确说：**缺：现金收款、扫码收款** + **表里读到这些列：…**
- 若商品挤在一列，会指名是哪一列并教按逗号分列

**不对的样子**：还是那句通用话（→ 诊断没接上，或者云端没返回 diagnosis）

## 5. 团购价在不在正确的位置（R626）
**怎么走**：成本卡 → 打开任一菜 → 切到「专业」模式（或点"更多"）→ 找团购相关。

**该看到**
- 菜品卡上**没有任何团购价/佣金率输入框**
- 只有一行蓝字指路「要算这个上团购到手多少？去团购页算」，点了能跳团购页
- 团购页里能选卡 + 填团购价 + 填佣金率 + 出到手

**不对的样子**：菜品卡上还能填团购价（→ 移除没生效）
