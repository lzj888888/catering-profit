## 2. 方案选择

**选 D 做主方案；B 降级为隐藏高级入口；不做 C，暂不 A。**

- 默认结果页只读 M1，展示平台费用率、到手率/贡献；外卖食材成本率只有能按外卖拆分或合理分摊时才展示。
- 形态 C 放到“高级/我有商品销量明细表”，有数据才出单品榜；无数据时空态直接引导到 M1 整体和单均测算。
- M1 缺费用字段就在 M1 补，这仍算 D；C 的问题是重复采集、制造双口径。
- 订单/结算账单入口继续关，不要恢复；形态 C 用独立开关控制。
- A 只作为后续低使用、维护成本高且数据无恢复可能时的退出动作。

2. **数据回归机制**：按平台/用户灰度恢复，先验数据源，不全局一键打开。

4. **中长期数据源**：官方 API、ISV 授权或第三方聚合只做预研，不承诺时间。
