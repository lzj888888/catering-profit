## 2. 直接把最显眼数字当成“本月外卖收入”，会高估多少？

以下计算先按“最显眼数字 = 优惠前/订单原价口径”测算。高估率公式为：

```text
高估率 =（显眼金额 - 实际到手金额）÷ 实际到手金额
```

### 2.1 美团：【确定】计算结果，【不确定】前提

若老板抄的是“优惠前总额”3166.20，并以 xlsx 的“到手”1826.64 为基准：

```text
（3166.20 - 1826.64）÷ 1826.64 = 73.33%
```

即**高估 73.33%**。

如果以扣除广告、保险后的“账单金额”1747.95 为基准：

```text
（3166.20 - 1747.95）÷ 1747.95 = 81.14%
```

即**高估 81.14%**。

补充：如果美团实际最显眼的是“营业收入”1747.96，则：

- 相对于账单金额 1747.95，基本没有高估；
- 相对于订单到手 1826.64，反而**低估约 4.31%**。

---

### 2.2 淘宝闪购：【确定】计算结果，【推测】App 显眼数前提

```text
（6585.08 - 3779.65）÷ 3779.65 = 74.22%
```

若把“优惠前/营业额”当成收入，**高估 74.22%**。

---

### 2.3 京东秒送：【确定】计算结果，【推测】App 显眼数前提

```text
（1101.31 - 555.96）÷ 555.96 = 98.09%
```

若把“订单原价”当成收入，**高估 98.09%**，接近翻倍。

# 最终答案

1. **手机首页最显眼的数通常偏经营规模口径，但美团“营业概览”里的“营业收入”是净账单口径；仅凭现有资料不能确认三平台当前版本最大字号的具体字段。**
2. 若把优惠前金额当收入：
   - 美团相对“到手”1826.64 **高估 73.33%**；相对账单金额 1747.95 **高估 81.14%**；
   - 淘宝闪购 **高估 74.22%**；
   - 京东秒送 **高估 98.09%**。
3. 最准的数在**财务/账单/结算模块**，找“已结算、账单金额、结算金额、应结金额”；具体菜单路径和名称会随版本变化，需以实测截图为准。
4. 只填一个数时，应抄**当月已结算净金额**。若必须填“营业额 + 补贴”，则抄**优惠前营业额 + 商家承担补贴**，但这两个数无法推算真正到手金额，不能替代结算金额。
