# 云开发控制台 · smokeTest 探针执行脚本（实测 2026-09-18）

> 配套：`examples/cloudbase_index/`（批量建索引）、`SKILL.md` 硬教训 21~23、`references/pitfalls.md`。
> 实战战绩：一次跑通「验一」——拿到真云返回 JSON 全文（3204 字符）+ 12 张截图 + 环境门禁证据，
> 并当场抓出两个新缺陷（冷启动 3 秒超时 / 线上部署件落后于仓库）。

## 为什么需要它

`smokeTest` 只能从**控制台 GUI** 触发（CLI 无 `invoke`），返回值要当**原文证据**存档 ⇒ 必须可靠地把
界面上的 JSON 取回来。**OCR 不行**（把 `-501001` 读成 `一501991`、还整行丢），只能用剪贴板回读。

## 脚本

| 文件 | 用途 |
|---|---|
| `cdb.py` | 公共层：窗口原点现取、png↔屏幕坐标换算、`shot()`、`verify_click()`（点前后比 md5 判"点击是否生效"） |
| `parse_result.py` | 剪贴板原文 → 结构化证据 JSON（切第一个完整 `{}` 对象；**解析失败即抛**，fail-closed，不写半截证据） |

## 操作顺序（照抄）

1. 控制台**先核对环境**：点环境下拉 → 确认列表里只有 dev、ID 与单源 `DEV_ENV_ID` **逐字符一致**（截图放大留证）。
2. 云函数 → `smokeTest` → 右侧「**云端测试**」（不是「本地调试」！两者相邻）。
3. 入参编辑器：点进框内 → `Ctrl+A` → `Delete` → 粘贴 `{}` → 截图确认。
4. **点「运行测试」**（绿色按钮）—— 坐标用**颜色实测**（`g>140 and g-r>50`）拿中心，别目测。
5. 读结果：
   - ⚠️ 界面上「测试结果：成功」= **调用**成功，**不等于函数跑完**；要看 `返回结果` 里的 `errorCode`。
   - **冷启动大概率 3 秒超时**（默认超时 3s）⇒ **再点一次**（热启动约 0.7s 稳过），或先把超时调到 ≥10s。
   - 取全文：点进「返回结果」文本框 → `Ctrl+A` → `Ctrl+C` → `get_clipboard()`。**复制图标点不动，别试。**
6. `parse_result.py` 落结构化证据；原文另存 `_clip_raw.txt`。
7. 跑完去数据库页截图（确认 `probe_tmp` 现状），**删除前先问人**（不可逆的云侧操作）。

## 硬约束

1. **坐标来源**：`ocr_screen.py find <kw>` 或像素实测；**绝不按 Read 回显图的宽度换算**（那是缩放图，会偏 1.6–1.7 倍）。
2. **每次点击比 md5**：`verify_click()` → `changed=False` 就是"没点中"，别读成"界面没反应"。
3. **文字一律走剪贴板**：JSON / 长文本 / 代码块，OCR 只用于"定位控件"。
4. **`VK` 里没有 `END`/`HOME`**：要原始码 `key(0x23, ctrl=True, shift=True)`。
5. **别删文件**：本机 `os.remove` 会 SIGTERM、`Remove-Item` 静默失败 ⇒ 用 `os.rename` 归档到 `_debug/`。
6. 「云端测试」与「本地调试」相邻，点之前**用 OCR 拿 `云端测试` 的中心**（实测 png `(1477.9, 387.6)`，窗口原点 `(60,0)`）。
