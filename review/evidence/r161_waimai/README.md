## 复现要点

- **xlsx 读法**：走表格子代理读表（全表 0 个公式单元格）；金额列**按列求和**，等式**逐行验证**。
- **截图读法**：像素裁切 + 放大后**人眼判读**（OCR 对小号数字不稳定；`zoom_*` 即为此保留原图）。数字一律以放大图为准。
- **账期**：结算日期 = 账单日期 + 3 天。归月一律用**账单日期 / 订单完成时间**。
