## 踩到并已修的四个坑
- `agent-desktop screenshot` 参数是**位置参数**（`screenshot <path>`），不是 `--output`。
- `find --role button --name 关闭` 有 2 个同名 ⇒ `click` 报 `AMBIGUOUS_TARGET`，改用像素法坐标点击。
- Python 子进程找不到全局 npm 命令（PATH）⇒ 用绝对路径 + `.cmd` 包装调用。
- `status=Updating` 是保存后的短暂中间态，**不是失败**；判据只认 timeout，最后统一全量复核 Active。
