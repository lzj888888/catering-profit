下面是我们产品的《标准导入格式》列定义。请严格按它，把【原料】整理成标准表。

只输出 CSV 文本：第一行是列名，逗号分隔，不要解释、不要 markdown 代码块标记、不要合计行。

===== 格式要求（S1 商品明细）=====
列名与顺序必须逐字一致：日期,渠道,平台,商品名称,销量,销售额,备注

| 列 | 列名 | 类型 | 必填 | 规则 |
|---|---|---|---|---|
| A | 日期 | 文本 | 是 | YYYY-MM-DD，必须是营业日 |
| B | 渠道 | 枚举 | 是 | 只能是「堂食」或「外卖」 |
| C | 平台 | 文本 | 外卖必填 | 美团/淘宝闪购/京东/其他；堂食留空 |
| D | 商品名称 | 文本 | 是 | 与收银系统一致，不加序号不截断 |
| E | 销量 | 数值 | 是 | 允许小数（称重类）；退款填负数 |
| F | 销售额 | 数值 | 是 | 单位元，最多两位小数，优惠前原价侧，不含补贴和打包费 |
| G | 备注 | 文本 | 否 | 随意 |

三条必须遵守的口径：
1. 一行 = 某一天 × 一个商品。同一天同一商品出现两次要合并成一行（销量相加）。
2. 销量与销售额**都允许负数**（退款/退单填负，不要删行、不要转正）。
3. 称重类（如"1.5斤"）销量填 1.5 这种小数，不要自己取整。

硬性校验（任一不满足整表会被拒）：
- 日期必须能解析成 YYYY-MM-DD（2026/9/7 要转成 2026-09-07；"9月8日"要按原料里的年份补全）
- 渠道只能是「堂食」或「外卖」两个字
- 销量、销售额必须是纯数字，不带「元」「¥」「斤」等单位
- 必须删掉合计行
