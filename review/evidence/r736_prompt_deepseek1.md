# 现状数据结构

**表 `shop_amortize`**（资产台账，一行 = 一笔支出）：
- `value_fen` 总额（分）
- `start_month` 开始月份
- `total_months` 摊多少期（一次性行恒 1）
- `mode`：`'amort'` = 分期摊销 / `'lump'` = 一次算清
- `terminate_month` 提前报废月份、`group_id`/`batch_seq` 多次采购分组

**表 `shop_switch`**（店铺级布尔开关）：
- `amortize_switch` = 摊销要不要计入本月利润

**引擎**（`calcMonthlyProfit/service.js`）：
```js
effectiveAmortizeFen   = amortizeSwitchOn ? amortizeFen : 0
effectiveLumpSumFen    = lumpSumFen                  // round107 定案：与摊销不互斥
operationRefProfitFen  = 收入 - 费用 - 参考消耗 - effectiveLumpSumFen
totalFactorRealProfitFen = 收入 - 费用 - 真实消耗 - effectiveAmortizeFen - effectiveLumpSumFen
```

**归档机制**：每月归档时把当月的 `{inventorySwitchOn, amortizeSwitchOn}` 冻结成快照 `switch_used` 存进 `shop_ledger`。归档月读快照、未归档读实时开关。（这是已建立的纪律：归档月的展示值不能因为事后改设置而变。）
