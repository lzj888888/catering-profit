# 第 1 轮 · 堂食收入到底让老板填哪个数

## 背景（我们是谁）
餐饮老板用的**月度盈利**小程序。堂食收入现在有两种填法：
- 快速录入：只填「堂食总收入」一个数（现提示：当月堂食全部消费营收，店内折扣、会员价**按折后成交额**填，含现金/微信/支付宝/刷卡/储值买单/挂账/团购核销）
- 分项渠道录入：按 7 个渠道分行填（现金收款、微信扫码收款、支付宝收款、银行卡/POS刷卡、储值卡消费、个人/单位挂账消费、团购/代金券核销）

外卖侧刚定案（别推翻）：收入 = **优惠前总额**（商品总价+打包费），商家承担补贴放费用侧扣一次。理由是老板在账单/手机上一眼能看到「商品总价」，而补贴另有一列。

## 收银系统手机端实有字段（已查官方文档，是事实不是推测）
- **美团管家 APP** 月报：实收金额、订单数；店内：应收金额、实收金额、就餐人数、单均价；优惠指标：优惠合计、店内优惠、会员优惠、免单、减免、抹零；**收款构成**（各支付方式占比）；财务概览含**支付方式流水明细**、收入明细（微信扫码枪/银行卡记账/微信记账）
- **客如云掌上 APP**：首页「营业收入」**包含已结账 + 未结账 + 会员卡余额支付 + 挂账支付**；每日对账单有总收款、实际打款、**团购核销额、外卖平台金额、现金及记账金额、预付金抵扣、手续费**；跨天营业有「打款尾差」
- **哗啦啦老板通**：按日/周/月统计；**实收**达成；**收入分类 = 营业额按支付构成/业务构成/渠道构成/收入构成拆分**

## 行业口径（连锁品牌做法）
净营业额 = 含税销售额 − 退款 − 折让，**排除储值卡充值**；实收金额按支付成功时间；**储值充值 ≠ 消费**，把充值当营业额是最常见坑。

## 现实（老板不会按教科书填）
1. 很多小店**现金、个人微信/支付宝收款根本不进收银系统**，系统里只有一部分
2. 有的老板把现金和扫码**混在一起**，只记得一个大概数
3. 老板基本不会为了填我们的表去系统里做复杂的筛选/导出

## 问你四个问题（给判断，别客套，别写代码）
1. 堂食收入让老板填**折后成交额（应收/实收，已扣店内优惠）**还是**优惠前订单金额**？哪个更「填得省事 + 利润不会算错」？注意我们外卖侧填的是优惠前，两边不一致会不会在「营业收入总额/成本率」上误导老板？如果不一致可接受，界面上怎么一句话说清？
2. 收银系统首页那个「营业收入」（客如云含未结账、挂账、会员卡余额）**能不能让老板直接抄**？不能的话，一句提示该怎么写？
3. 现金/个人码收款不走系统、且和系统里的数混在一起时，怎么引导老板填最不容易**漏记或重复记**？
4. 跨天营业、团购次月到账这类**消费月 ≠ 到账月**，月度表按哪个月记？
