# R186 · 销量样例「要哪几类 + 从哪儿拿」—— 取证留档

## 一 起因

李老师 2026-10-01 追问：

> 菜品销售那个数值还需要吗？如果需要，需要哪一类的，比如 堂食的 还是团购的，还是外卖的或者其他的？
> 或者你知道从哪里获得，比如美团收银 或者外卖哪里 获得具体路径给我亦可以。

三个子问题：① 还要不要 ② 要哪一类 ③ 从哪儿拿（要**具体路径**）。

## 二 结论（成文于 `review/PLAN_2026-10-01_销量样例获取指南_分渠道导出路径.md`）

| 子问题 | 结论 |
|---|---|
| ① 还要不要 | **要** —— 但要的是**菜品级销量表**（含菜名），不是订单级结算账单（已核实两份归档账单**不含菜名**） |
| ② 要哪一类 | **堂食 + 外卖两类都要**（🔴 只导一类 = 系统性漏掉另一半）；**团购券核销暂不要**（M1 已有 `income_dine_groupon` 收入项） |
| ③ 从哪儿拿 | 逐渠道路径（美团管家 / 美团外卖 / 饿了么·淘宝闪购 / 其他收银），见指南 §三 |

🔴 **套餐那份最想要** —— 李老师指出「外卖卖爆的常是套餐」⇒ 平台名 / POS 名 / 我方卡名三处对不上 ⇒ 须 `shop_dish_mapping` 映射、**未匹配不静默归零**。

## 三 关键路径摘要（完整版见指南）

- **堂食 · 美团收银**：`pos.meituan.com` → 报表中心 → 菜品报表 → 菜品销售统计 / **套餐销售统计（统计方式选「套餐明细」）** → 右上【导出】
  - ⚠️ **导出只能 PC 端**（POS 端只能打印、App 只能看）
  - ⚠️ 菜品销售统计**不含**打包费/配送费（在「销售品项统计」）
- **外卖 · 美团**：`waimai.meituan.com` → 经营分析/数据中心 → 商品分析 → 导出（🔴 别点「订单明细/账单/结算」）
- **外卖 · 饿了么/淘宝闪购**：商家后台 → 数据中心 → 销售数据/商品销量 → 导出
