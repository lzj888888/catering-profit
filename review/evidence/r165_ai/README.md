## 关键判据（别省）

- **发出去了吗** = 对话区 OCR 出现特征词 **且** 输入框空（Enter 会变"引用条"，不是发送）。
- **蓝色发送钮坐标每次现测**：新会话页 (1783,920) / 有历史的老会话 (1453,920)。
- **读长回答走剪贴板**（点对话区 → Ctrl+A → Ctrl+C），OCR 仅兜底：实测剪贴板 2510 字符无损 vs OCR 同区 237 字符。
- **外部 AI 给的数字一律自行重算**：豆包算的单次成本 0.0036 元，实算 0.0030 元，且与它自己给的月成本自相矛盾。
