### 1. R161-6 · 归月口径句（结算日 = 账单日 + 3 天，按结算日导月必串月）

**为什么必须钉在界面上**：淘宝闪购实测「结算日期 = 账单日期 + 3 天」。客户导出月度账单时若按「结算账单」口径，月初 1–3 号的单会被算进上个月，月末 29–31 号的单会被挤到下个月 —— 这是**静默串月**，不报错、看不出来。

**我方现状（正确，未改）**：`incomeHint` 已是权责发生制，归月逻辑本身没问题；缺的只是**告诉客户按哪个日期归月**。

新增术语 `periodNote`（外卖专段，挂在口径句之后）：

```
归月口径：按「账单日期 / 订单完成时间」归到本月，不要按「结算日期」归月 ——
结算日通常比账单日晚 3 天，按它归会把月初几天的单串到上个月。
```

落点：`miniprogram/i18n/terms.js`（+ 同步 `specs/dev-specs/i18n/terms.js`）、`pages/month/input.js`（注入 `twPeriodNote`）、`input.wxml`（渲染）、`input.wxss`（`.tw-period`）。

## 三、🔴 新发现三条（本轮最值钱的）

### R163-A · 打包费是**加项**，不是减项

- **现象**：脚本第一版把 `gross` 映到「商品金额」、把打包费漏掉 ⇒ 逐行差**恒为 2.00**、汇总差 **167.00**。
- **判据**：167.00 ≡ 打包费合计；2.00 ≡ 单均打包费。差额恒定不是噪声，是漏项。
- **结论**：`到手 = 商品金额 + 打包费 − 商家承担补贴 − 佣金 − 配送服务费 − 其他支出`。
- **对我方：无错，不用改**。§A.11 配平式里的「外卖收入合计」本就含打包费（三框相加，打包费是加项），与平台同构。
- **但录入侧有隐患**：客户若把打包费当成"成本"填进费用页，会**既算收入又算成本**（方向反了，反而是利润虚高）。现有 `scopeGuide` 已写明"这一个数 = 商品总价 + 打包费 + 补贴"，本轮不另加。

### R163-B · 退单行的符号是**冲回**（反号）

- 口径A 剩下 4 行不符，**全部是退单**（优惠前为负）；这些行的补贴/佣金是**正数返还**，不是扣减。
- 例：第 140 行 `优惠前 −36.00 / 补贴 +7.70 / 佣金 +0.18 ⇒ 到手 −28.12`（脚本按"一律取绝对值相减"算得 −43.88，差 15.76 = 2×7.70 + 2×0.18，符号反了）。
- **修法**：改成**先探测平台符号约定、再带符号相加** ⇒ 不符降到 **0 行**。
- **对录入的意义**：有效订单数必须**排除退单**（淘宝 156 行 = 150 外卖订单 + 6 退单）。我方 `ordersHint` 已写「退单不算」✔ —— 与实测一致，不用改。

### R163-C · 符号约定由脚本自动探测（为美团准备）

淘宝记负数（负 661 / 正 0）；**美团未知**（可能记正数）。脚本不再硬编码，而是扫描 `gross>0` 的正常行决定 `factor`：

- 扣减列多数为负 ⇒ `factor=+1`，原样相加；
- 多数为正 ⇒ `factor=−1`，取反相减。

退单行天然反号，**不参与探测**（否则会把约定探反）。明早美团表不管哪种记法，跑就出结果，不用改代码。

### 🔴 本轮第二个坑：**变异脚本自己把门禁打红**（不是代码错）

- 现象：`R102-⑤`（batch8b）在变异回灌之后由绿转红，且它检查的东西我压根没碰过。
- 根因：变异脚本用 `io.open(p, encoding='utf-8').read()` 读、再 `newline=''` 写回 ——
  python 文本模式默认 **universal newlines**，读时把 `\r\n` 吞成 `\n`，写回时 `newline=''` 不再还原
  ⇒ **`pages/month/input.wxml` 的 CRLF 被永久改成 LF**（445 处全丢）。
  而 `R102-⑤` 恰好用含 `\r\n` 的串做精确匹配 ⇒ 匹配不上 ⇒ 假红。
- 修法：① 把 wxml 二进制转回 CRLF；② 变异脚本**读写两侧都加 `newline=''`**。
- 教训（已进 PITFALLS §14）：**变异/改档脚本一律二进制或显式 `newline=''` 读写**，
  否则"证明守卫有效"的工具本身会制造一次假红，且极难归因（红的地方与你改的内容无关）。
- 顺带确认：全仓 1511 个 tracked 文件里只有 `input.wxml` 是 CRLF，其余本就是 LF —— 所以只有这一条断言会中招。
