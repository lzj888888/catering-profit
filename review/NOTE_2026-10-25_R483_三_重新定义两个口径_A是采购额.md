# R483 续三 · 重新定义两个口径：**A = 当月采购额**（不是"手填的消耗"）

- 日期：2026-10-25 12:05
- 触发：李老师讲清设计初衷：「不想盘点的老板就按当月采购记（买 20,005 就记 20,005），
  盘点的按库存变动算更准；差异 = 这个月实际采购 与 实际消耗（含库存）之间的依赖关系」
- 结论：**李老师的定义成立且数学自洽**；**当前实现跟这个定义对不上**，这就是大家看不懂的根因。

---

## 一、李老师的定义（我复算验证过）

| 口径 | 含义 | 谁用 |
|---|---|---|
| **A** | **这个月买食材花了多少**（采购额，收付实现制：钱花出去多少） | 图省事、不盘库的老板 |
| **B** | **这个月实际耗用多少**（期初 + 采购 − 期末，权责发生制：用了多少） | 盘了库的老板 |
| **差异** | **A − B = 库存变动**（买回来还没用的货，压在库里） | —— |

**数学验证（2026-10 真云数据）**：
```
采购 35,000 − 耗用 7,000 = 28,000
期末 28,000 − 期初     0 = 28,000     → 两者**严格相等** ✅
```
⇒ 按这个定义，差异**不是误差**，是**"有多少货压在库里"**，老板一听就懂。

## 二、⚠️ 当前实现跟这个定义对不上（关键发现）

现状的 A 是**「老板手填的消耗」**，不是采购额。10 月真值：

| 数 | 值 |
|---|---|
| 采购额（库存页已填） | **35,000** |
| 老板手填的"消耗" | **22,000** |
| 倒轧实际耗用 | **7,000** |

⇒ **手填的 22,000 既不是采购额，也不是耗用量**，是个"凭感觉填的第三个数"。
于是差异 = 7,000 − 22,000 = **−15,000 —— 这个数既不等于库存变动（28,000），也不代表任何业务事实**。

**这就是"好多人不知道差在哪"的真正原因**：差异本身没有业务含义，因为它的一端是个定义不清的数。

## 三、我的改法：把 A 的来源换成"采购额"

| 模式 | A 取什么 | 是否需要老板手填 |
|---|---|---|
| 库存**关**（不盘点） | 老板手填的消耗（买多少算多少，此时≈采购） | 需要（现状不变） |
| 库存**开**（盘了库） | **当月采购额**（库存页已填的客观数） | **不需要** ✅ |

**改后 10 月的数**（本地复算，与真云口径一致）：

| | 现状 | 改后 |
|---|---|---|
| 🟢 参考利润（按买/记的成本算） | 29,900 | **16,900** |
| 🔵 真实利润（按实际耗用算） | 44,900 | 44,900 |
| 差异 | −15,000（无含义） | **−28,000（= 压在库里的货）** ✅ |

**老板能读懂的一句话**：
> 这个月买食材花了 35,000，但实际只用掉 7,000 —— 差的 28,000 是**压在库里的货，下个月用了才算成本**。
> 所以：按"钱花出去多少"算是赚 16,900；按"实际用了多少"算是赚 44,900。

## 四、为什么这样改更好

1. **A 有了客观来源**（采购额，库存页已经填过）⇒ 老板不用再凭感觉填 ⇒ **不会再填错**
2. **差异有了业务含义**（库存变动）⇒ 不用再解释"为什么差一万五"
3. **符合"老板只能出一个数"** —— 主推 🔵真实利润（44,900，权责发生制更准）；
   🟢参考利润降级为"钱花出去的视角"，差异解释成"压在库里的货"
4. **不用删功能**（李老师说"差异你留着也行"）—— 只改 A 的取数来源 + 差异的解释文案

## 五、要不要改？我的建议

**要改，但改的是"数"，得您点头**：10 月参考利润会从 29,900 变成 16,900（因为 A 从手填 22,000 变成采购 35,000）。

改动面（比 L3 小得多）：
- 三份引擎副本：`refMaterialFen` 在「库存开」时取 `purchaseFen`（有采购数）→ 否则回落倒轧（R477 现状）
- 展示：差异解释改成大白话"买回来还没用的货"
- 守卫生：新增"库存开时 A 必须来自采购额"
