# 餐饮毛利核算小程序

微信小程序：录入菜品（售价 / 单位成本 / 销量）与日固定成本（房租 / 人工 / 水电），自动核算营收、食材成本、毛利、毛利率、净利。数据本地保存。

## 功能
- 菜品管理：售价、单位成本、销量
- 日固定成本：房租、人工、水电
- 自动核算：营收、食材成本、毛利、毛利率、净利
- 本地存储（wx.setStorage），无需后端

## 运行
用微信开发者工具 →「导入项目」选择本目录即可预览（纯预览可用游客模式；**云开发功能必须用真 AppID**，本项目已配 `wx33c110dc57a9c8dc`）。

## 目录结构
- `app.js` / `app.json` / `app.wxss`：小程序框架与全局配置
- `pages/index`：汇总与录入首页
- `pages/dish`：菜品明细
- `utils/calc.js`：毛利核算计算逻辑（纯函数，可单测）
